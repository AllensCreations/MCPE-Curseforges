# OneBlock Dirtbound Kingdom Beta — Build Status

Dirtbound is a complete-world project. **The Creative `.mcworld` is the only designated tester.** Standalone `.mcaddon` and `.mcpack` tester packages are retired and are not distributed from this folder.

The current source is v0.1.20. The committed Creative, Survival, and Hardcore `.mcworld` files remain the previous archives and may not include the latest source changes. New world archives will be generated together only after the Creative mechanics have been tested in Minecraft and rebuilding is approved.

For the current Creative test world and source files, see the [Dirtbound map folder](../../MCPEDL/maps/OneBlock-Dirtbound-Kingdom-Beta/).
