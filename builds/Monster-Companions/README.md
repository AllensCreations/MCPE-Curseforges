## 🚀 Quick Install Instructions

1. **Click the Download Link** above to save `Monster_Companions_AllensCreations.mcpack`.
2. **Open / Tap the file**: Minecraft Bedrock will launch automatically and import the pack.
3. **Activate in World Settings**:
   - Go to your World Settings $\rightarrow$ **Behavior Packs**.
   - Select **Monster Companions by AllensCreations** and click **Activate**.
   - Craft Primal Beast Biscuits, weaken monsters in combat, and build your loyal monster bodyguard squad!
