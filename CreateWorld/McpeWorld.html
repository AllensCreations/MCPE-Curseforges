How to Import Void Worlds into MCPE (Bedrock 1.26+)

Android Import
  1. Download the generated .mcworld file.
  2. Open your Android File Manager (e.g., ZArchiver or CX File Explorer).
  3. Tap on the .mcworld file and select **Open with Minecraft**.
  4. Minecraft will launch and display **"World Import Started"** followed by **"World Import Successful"**.
iOS / iPhone / iPad
  1. Download the world file in Safari.
  2. Open the **Files** app and navigate to your **Downloads** folder.
  3. Tap the .mcworld file directly.
  4. iOS will automatically boot Minecraft Bedrock Edition and import the level.
Windows Bedrock
  1. Download the .mcworld file to your PC.
  2. Double-click the downloaded file in File Explorer.
  3. Minecraft Windows Edition will open and import the world into your main world list instantly.
