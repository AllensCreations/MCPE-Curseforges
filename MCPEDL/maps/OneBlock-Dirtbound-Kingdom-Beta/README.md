## Test Instructions

1. Import the Creative world by opening its downloaded `.mcworld` file with Minecraft.
2. Confirm Dirt appears at **0 64 0**, Bedrock is directly below at **0 63 0**, and world spawn is **0 65 0**.
3. Break the central block and verify that it returns and advances through the stages correctly.
4. Test the Trader Post and Trader Ledger, OneCoins balance, Dirt selling, purchases, and progression.
5. Check that the block remains in place without teleporting players.
6. Report any failure before treating the mechanics as verified.

For gameplay details and known testing limitations, read [DESCRIPTION.md](DESCRIPTION.md).
