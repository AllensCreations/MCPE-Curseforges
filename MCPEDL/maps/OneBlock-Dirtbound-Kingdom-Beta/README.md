## Dirtbound Setup Coordinates

- OneBlock core: `0 0 0`
- Bedrock footing: `0 -1 0`
- World spawn: `0 1 0`
- Trader lectern: `2 1 0`
- The first-join Void Cleaner clears only the 33 × 33 square from `-16 -64 -16` through `16 -64 16` on the single layer `Y = -64`.

## Installation

1. Download the Creative world first.
2. Open the downloaded .mcworld file with Minecraft Bedrock Edition to import it.
3. Use Creative as the only test world. Importing a world file does not update a world already saved in Minecraft.

For gameplay details, setup coordinates, and current testing limitations, read the [full description](https://github.com/AllensCreations/MCPE-Curseforges/blob/main/MCPEDL/maps/OneBlock-Dirtbound-Kingdom-Beta/DESCRIPTION.md).
