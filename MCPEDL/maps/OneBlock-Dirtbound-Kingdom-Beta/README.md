## Test Instructions

1. Download and open the Tester Build with Minecraft to import both packs.
2. Create a new, disposable test world and enable the imported Behavior Pack and Resource Pack.
3. Check that Dirt appears at the center, Bedrock is directly below it, and the world spawn is set to the intended starting location without teleporting players.
4. Break the central block and verify that it returns and advances through the stages correctly.
5. Check the Trader item and permanent Trader Post, selling, OneCoins, purchases, and progression.
6. Only mark testing complete after these mechanics have been verified in Minecraft.

For full gameplay details and current testing limitations, read [DESCRIPTION.md](DESCRIPTION.md).
