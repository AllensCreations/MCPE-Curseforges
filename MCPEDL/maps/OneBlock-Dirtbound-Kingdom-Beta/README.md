## Installation

1. Download and open the `.mcaddon` file with Minecraft to import both packs.
2. Create a **new, disposable test world** and enable both imported packs.
3. Enter the world and allow the starting block, Bedrock footing, and exact world spawn to initialize at the center.
4. Use the permanent Trader Post barrel or the OneBlock Trader item to open the shop.

This is a troubleshooting add-on, not a prebuilt world. Read [DESCRIPTION.md](DESCRIPTION.md) for gameplay details and known testing limits.
