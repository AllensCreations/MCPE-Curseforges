# OneBlock Void Survival (v1.2.17)

Download the current release of **OneBlock Void Survival** for Minecraft Bedrock Edition.

## Download

- **Version:** 1.2.16
- **Package format:** `.mcworld`
- **Direct download:** [Download the world (.mcworld)](https://github.com/AllensCreations/MCPE-Curseforges/raw/main/builds/OneBlock-Void-Survival/OneBlock%20Void%20Survival%20by%20AllensCreations%20%28V1.2.16%29.mcworld)

## Installation

1. Download the file using the link above.
2. Open it with Minecraft to import it.
3. Find the imported world in your Worlds list and open it.

## Requirements

- Minecraft Bedrock Edition 1.21.50 or newer.
- The map is built as two worlds: Creative and Survival. Difficulty and game mode are not locked, and normal respawning applies.
- Each world is a separate file. Import the one you want to play.
