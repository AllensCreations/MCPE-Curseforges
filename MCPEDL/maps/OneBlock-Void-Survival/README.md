# OneBlock Void Survival (v1.2.14)

Download the current release of **OneBlock Void Survival** for Minecraft Bedrock Edition.

## Download

- **Version:** 1.2.6
- **Package format:** `.mcworld`
- **Direct download:** [Download the world (.mcworld)](https://github.com/AllensCreations/MCPE-Curseforges/raw/main/builds/OneBlock-Void-Survival/OneBlock%20Void%20Survival%20by%20AllensCreations%20%28V1.2.6%29.mcworld)

## Installation

1. Download the file using the link above.
2. Open it with Minecraft to import it.
3. Find the imported world in your Worlds list and open it.

## Requirements

- Minecraft Bedrock Edition 1.21.50 or newer.
- The map is built as three worlds: Creative, Survival, and Hardcore. In the Hardcore world the difficulty is locked to Hard, and if you die you are placed in Spectator Mode permanently.
