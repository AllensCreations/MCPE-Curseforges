# OneBlock Sovereign Market (source v1.0.0) (v1.0.0)

Download the current published OneBlock Sovereign Market world for Minecraft Bedrock Edition.

## World Downloads

- **Creative:** [Download Creative World (.mcworld)](https://github.com/AllensCreations/MCPE-Curseforges/raw/main/MCPEDL/maps/OneBlock-SM/OneBlock%20Sovereign%20Market%20-%20Creative.mcworld)
- **Survival:** [Download Survival World (.mcworld)](https://github.com/AllensCreations/MCPE-Curseforges/raw/main/MCPEDL/maps/OneBlock-SM/OneBlock%20Sovereign%20Market%20-%20Survival.mcworld)
- **Hardcore:** [Download Hardcore World (.mcworld)](https://github.com/AllensCreations/MCPE-Curseforges/raw/main/MCPEDL/maps/OneBlock-SM/OneBlock%20Sovereign%20Market%20-%20Hardcore.mcworld)

All three world archives contain the current Behavior Pack version (1.0.0) and matching world pack links.
Archive checks confirm package structure only; they do not prove gameplay has been tested in Minecraft.

## Installation

1. Download the Creative world first.
2. Open the downloaded .mcworld file with Minecraft Bedrock Edition to import it.
3. Use Creative as the only test world. Importing a world file does not update a world already saved in Minecraft.

For gameplay details, setup coordinates, and testing limitations, read the [full description](https://github.com/AllensCreations/MCPE-Curseforges/raw/main/MCPEDL/maps/OneBlock-SM/DESCRIPTION.md).
