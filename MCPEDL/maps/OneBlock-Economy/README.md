# OneBlock Economy (v1.0.7)

Download the current release of **OneBlock Economy** for Minecraft Bedrock Edition.

## Download

- **Version:** 1.0.7
- **Package format:** `.mcworld`
- **Direct download:** [Download the world (.mcworld)](https://github.com/AllensCreations/MCPE-Curseforges/raw/main/builds/OneBlock-Economy/OneBlock%20Economy%20by%20AllensCreations%20%28V1.0.7%29.mcworld)

## Installation

1. Download the file using the link above.
2. Open it with Minecraft to import it.
3. Find the imported world in your Worlds list and open it.
