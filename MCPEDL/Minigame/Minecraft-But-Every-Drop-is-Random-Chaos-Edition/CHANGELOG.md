# Changelog — Minecraft, But Every Drop is Random: Chaos Edition

---

## [1.0.0] - 2026-11-15 - Chaos Edition Launch

### Added
- **Random Drops Challenge**: Every item dropped by a broken block or a defeated mob is replaced by a different item while a game is running, and each replacement keeps the original stack size.
- **Run Table**: Each item always turns into the same replacement during a run, and every Start shuffles a new table for a new run.
- **Chaos Drop Feed**: Rare swaps, such as a Diamond or an Elytra, show the original item and the new item on the action bar.
- **Reshuffle Command and Book**: Outside a game, the aln:reshuffle command or sneaking while using a Book reshuffles the table.
- **Controller**: The host opens a menu with Start and How to play, and ends the game from the same item.
- **Dragon Win**: Defeating the Ender Dragon during a game wins the run and ends the game.
