# Changelog — Minecraft, But Every Drop is Random: Chaos Edition

---

## [v2] - 2026-11-15

**What's new in v1.0.4:** Packed with 2 updates, from v1.0.3 through v1.0.4. Includes: Burst Smoothing; Smoother Drops.

### Fixed

- **Lag Spikes**: Large bursts of drops, such as a big tree, TNT or a mob farm, are now swapped a few at a time instead of all in one moment, so the game stays smooth.
- **Lag Spikes**: Drop swapping no longer scans the area around every broken block or defeated mob, so mining and fighting stay smooth.

### Removed

- **Chaos Drop Feed**: Rare swaps no longer show the original and the new item on the action bar.

### Improved & Balanced

- **Mystery Messages**: Starting and reshuffling now show scrambled text that signals something is happening, instead of an item count and a run code.

## [1.0.2] - 2026-11-15

**What's new in v1.0.2:** Packed with the v1.0.2 update. Includes: Controller Auto Destroy.

### Improved & Balanced

- **Controller Auto Destroy**: The Controller is now used up when a game starts (Creative mode keeps it), and the host receives a new one when the game ends.



## [1.0.1] - 2026-11-15 - Import Fix

### Fixed
- **Pack Import**: The packs now import in Minecraft. The minimum game version they declared was higher than Minecraft accepts.





## [1.0.0] - 2026-11-15 - Chaos Edition Launch

### Added
- **Random Drops Challenge**: Every item dropped by a broken block or a defeated mob is replaced by a different item while a game is running, and each replacement keeps the original stack size.
- **Run Table**: Each item always turns into the same replacement during a run, and every Start shuffles a new table for a new run.
- **Chaos Drop Feed**: Rare swaps, such as a Diamond or an Elytra, show the original item and the new item on the action bar.
- **Reshuffle Command and Book**: Outside a game, the aln:reshuffle command or sneaking while using a Book reshuffles the table.
- **Controller**: The host opens a menu with Start and How to play, and ends the game from the same item.
- **Dragon Win**: Defeating the Ender Dragon during a game wins the run and ends the game.
