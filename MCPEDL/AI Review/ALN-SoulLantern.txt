````markdown
# mcpe-pack-update: Update Spec Delivery

## Authority

- `INSTRUCTIONS.md` is the policy source. `PACK_GENERATOR_INSTRUCTIONS.md` is its standalone copy for generation. The script flow is `INSTRUCTIONS.md` "Termux Script Rules", built with `scripts/make_update_script.py`. Where to look each rule up: the `mcpe-context7` skill. This skill is a short working checklist and never restates or overrides them.
- **Precedence** (as in `PACK_GENERATOR_INSTRUCTIONS.md`): factual accuracy and the user's requested scope, then Part 1, then Part 2, then this skill. Part 4 of the generator file never overrides Parts 1 and 2.
- If these files disagree with each other or with a script in `scripts/`, tell the user exactly what differs instead of choosing silently. If `INSTRUCTIONS.md` cannot be read, stop and report it instead of working from memory.
- Achievements line (every project type): always `Yes, achievement-friendly.` Keep any cheats or world-setting caveat as a following sentence.

## Scope

- Use for changes to an existing project (`MCPEDL/Addons|Maps|Script|Minigame/<Name>/`), a workflow, a script, a catalog or any repo doc.
- Read-only audit or report: use `checkrm`.
- New project from an idea: follow `PACK_GENERATOR_INSTRUCTIONS.md` Part 4 (ask the type first, base64 payload).

## Procedure

1. Read `INSTRUCTIONS.md` Parts 1 and 2 before writing anything, through Context7 as the `mcpe-context7` skill says. `make_update_script.py` and `apply_update.py` are complete in the pack's review zip (`<Pack>.zip`) under `files/`; run them from there.
2. Find the destination folder: the path the user named, otherwise the matching project folder. Do not substitute a similar name; report ambiguity or a missing target. Ask at most one question, and only if the answer changes gameplay, compatibility, distribution, data loss or versioning.
3. Read the real source (manifests, scripts, items, recipes, loot tables, functions, lang files) before writing any claim. Source priority when sources disagree, and report the disagreement: the project's own files, Mojang Bedrock Samples, official Minecraft Creator Documentation, Minecraft Wiki, Bedrock Wiki.
4. Make the smallest possible change. No unrelated rewrites. Never invent features, versions, links, assets, test results or compatibility. Never write comments in shipped `.js`, `.mcfunction` or `.json` files.
5. Write the spec (below), test it (below), then reply (below). For changes to an existing project, never deliver a .sh: this overrides any older "deliver the .sh" wording. A NEW pack still follows `mcpe-new-pack` and delivers its generated .sh.

## The spec

File name: `spec_vN.txt`, a downloadable file. N = CURRENT VERSION + 1, read from the attached repo export, never guessed. The user builds the .sh on their phone with `scripts/make_update_script.py`.

Format (`scripts/apply_update.py`):

- Start: `@@ version vN`, then `@@ project MCPEDL/<Category>/<Name>`, then one `@@ file <path relative to the project>` block per file.
- Directives: replace/with, replace-all, insert-after, insert-before, delete, append, create, overwrite, changelog. Remove files with `@@ delete-file <repo-root path>`.
- Small change: replace/insert only. Anchors are copied from the attached export, never from memory, and must occur exactly once. Do not end an anchor with a newline.
- Large redesign: `@@ overwrite` (new content must exceed 60% of the old file) or `@@ create` for new files. Never many fragile edits.
- A content line that starts with `@@` is written `@@@`.
- End with `@@ changelog <Update Name>` using `### Added`, `### Improved & Balanced`, `### Fixed` and `- **Title**: text`. Never touch manifest versions or README links.
- New pixel textures: `@@ create` the pixel JSON under `texture_sources/`, then add the PNG step to the Termux commands.
- Keep README.md and DESCRIPTION.md accurate (INSTRUCTIONS Part 2 template). Never claim an in-game test.

**Test before delivering.** Apply the spec to the export text in the sandbox with `apply_update.py` (`--dry-run`, then a real run on a copy). Check every anchor, validate each changed JSON, run `node --check` on JS. Report every check not run.

## Versions

- N is the current version from the attached export plus one. `apply_update.py` rejects a stale version, so a stale spec cannot run on a newer repo.
- Never edit manifest versions or the README version or download link. The auto-version-bump workflow does that on push.

## Docs

- The changelog entry is mandatory on every update and is written with the final `@@ changelog <Update Name>` directive. Never edit or delete older entries; correct them in the new entry.
- After the change, check the README.md and DESCRIPTION.md in the destination. Edit them only if the change makes them inaccurate or incomplete. Never remove verified content.
- Follow the Part 2 templates in `INSTRUCTIONS.md` exactly (`scripts/doc_template.py` fails the build on deviation): same headings, same heading text, same order, same labels, no added sections, no boilerplate, no placeholders. README is version-free and DESCRIPTION has no release version in its title.
- Writing, layout, attribution, keywords and the README and DESCRIPTION templates are defined in `INSTRUCTIONS.md` Part 2. Read them there; do not copy them into the script from memory.
````

```
# scripts/lib

scripts/lib/ holds no .js files yet. Everything lives in scripts/main.js.

## Files

- scripts/main.js: registers all Soul Lantern behavior. Depends on @minecraft/server and @minecraft/server-ui.
- scripts/lib/README.md: this file.

## What main.js does

- Before-event on player interaction with an entity: a sneaking player holding aln:soul_lantern seals the target mob. The mob is saved with a world structure (entities only), its id and display facts are stored on the item as dynamic properties, and the item becomes aln:soul_lantern_filled.
- Before-event on player interaction with a block: aln:soul_lantern_filled places the saved structure on top of the clicked block, renames the mob if a lantern name was set, deletes the structure, and returns an aln:soul_lantern.
- After-event on item use: aln:soul_lantern_filled opens the Spirit menu (details, Project Spectral Ally, Rename Captured Mob). aln:soul_lantern shows a hint.
- Repeating timer every 2 ticks: ends spectral allies after 400 ticks, orbits them around the owner, spawns the particle trail, and damages one nearby monster every 15 ticks.
- World load: removes leftover entities tagged aln_spirit.

## Ids

- Items: aln:soul_lantern, aln:soul_lantern_filled.
- Recipes: aln:soul_lantern_soil, aln:soul_lantern_sand.
- Dynamic properties on the filled item: aln_sid, aln_type, aln_name, aln_hp, aln_max_hp, aln_baby, aln_details, aln_rename.
- Entity: aln:spirit, tag aln_spirit. Structure ids: aln:soul_<random>.

## Known limits

- Bosses (Ender Dragon, Wither, Warden, Elder Guardian), players, armor stands, NPCs and agents cannot be sealed.
- The Spectral Ally is a light-blue, slightly transparent spirit entity that never attacks players. It does not copy the captured mob's model; its name shows the species.
- Villager profession is kept by the saved structure but is not shown in the menu.
- Cooldowns and active allies reset when the world reloads.
- Not tested in game.
```

```
const COOLDOWN_TICKS = 1200;
const DEBOUNCE_TICKS = 8;
const VERSION = "1.0.1";

const BOSSES = new Set(["minecraft:ender_dragon", "minecraft:wither", "minecraft:warden", "minecraft:elder_guardian"]);
const NOT_SEALABLE = new Set(["minecraft:player", "minecraft:armor_stand", "minecraft:npc", "minecraft:agent"]);
const DYES = ["White", "Orange", "Magenta", "Light Blue", "Yellow", "Lime", "Pink", "Gray", "Light Gray", "Cyan", "Purple", "Blue", "Brown", "Green", "Red", "Black"];
const AXOLOTLS = ["Lucy", "Wild", "Gold", "Cyan", "Blue"];

const KEY = {
  sid: "aln_sid",
  type: "aln_type",
  name: "aln_name",
  hp: "aln_hp",
  maxHp: "aln_max_hp",
  baby: "aln_baby",
  details: "aln_details",
  rename: "aln_rename",
};

const spirits = new Map();
const cooldowns = new Map();
const lastAction = new Map();

const tell = (player, color, text) => {
  try {
    player.onScreenDisplay.setActionBar(`${color}${text}`);
  } catch (e) {}
};

const play = (player, id) => {
  try {
    player.playSound(id);
  } catch (e) {}
};

const containerOf = (player) => player.getComponent(EntityComponentTypes.Inventory)?.container;

const component = (entity, id) => {
  try {
    return entity.getComponent(id);
  } catch (e) {
    return undefined;
  }
};

const prettyType = (typeId) =>
  String(typeId)
    .replace(/^[^:]*:/, "")
    .split("_")
    .map((w) => w.charAt(0).toUpperCase() + w.slice(1))
    .join(" ");

const newStructureId = () => `aln:soul_${system.currentTick.toString(36)}${Math.floor(Math.random() * 1679616).toString(36)}`;

const busy = (player) => {
  const last = lastAction.get(player.id);
  return last !== undefined && system.currentTick - last < DEBOUNCE_TICKS;
};
const mark = (player) => lastAction.set(player.id, system.currentTick);

function colorLabel(typeId, value) {
  if (typeId === "minecraft:axolotl") return `Variant ${AXOLOTLS[value] ?? value}`;
  if (typeId === "minecraft:sheep") return `Wool ${DYES[value] ?? value}`;
  if (typeId === "minecraft:wolf" || typeId === "minecraft:cat") return `Collar ${DYES[value] ?? value}`;
  return `Color ${DYES[value] ?? value}`;
}

function readInfo(entity) {
  const health = component(entity, "minecraft:health");
  const details = [];
  const color = component(entity, "minecraft:color")?.value;
  if (color !== undefined) details.push(colorLabel(entity.typeId, color));
  const variant = component(entity, "minecraft:variant")?.value;
  if (variant !== undefined && entity.typeId !== "minecraft:axolotl") details.push(`Variant ${variant}`);
  const mark2 = component(entity, "minecraft:mark_variant")?.value;
  if (mark2 !== undefined) details.push(`Pattern ${mark2}`);
  if (component(entity, "minecraft:is_tamed")) details.push("Tamed");
  return {
    type: entity.typeId,
    name: entity.nameTag ?? "",
    hp: health ? Math.round(health.currentValue * 10) / 10 : 0,
    maxHp: health ? Math.round(health.effectiveMax * 10) / 10 : 0,
    baby: component(entity, "minecraft:is_baby") !== undefined,
    details: details.join(", "),
  };
}

function readStack(stack) {
  const get = (k, fallback) => {
    const v = stack.getDynamicProperty(k);
    return v === undefined ? fallback : v;
  };
  const type = get(KEY.type, "minecraft:unknown");
  const rename = get(KEY.rename, "");
  return {
    sid: get(KEY.sid, ""),
    species: prettyType(type) + (get(KEY.baby, false) ? " (Baby)" : ""),
    name: rename || get(KEY.name, ""),
    hp: get(KEY.hp, 0),
    maxHp: get(KEY.maxHp, 0),
    details: get(KEY.details, ""),
    rename,
  };
}

function refreshDisplay(stack) {
  const d = readStack(stack);
  stack.nameTag = `§b§lSoul Lantern§r §3- §b${d.name || d.species}`;
  stack.setLore([
    `§7Species: §f${d.species}`,
    `§7Name: §f${d.name || "None"}`,
    `§7Health: §f${d.hp}/${d.maxHp}`,
    `§7Details: §f${d.details || "None"}`,
  ]);
}

function swirl(dim, center) {
  for (let step = 0; step < 10; step++) {
    system.runTimeout(() => {
      const radius = 1.4 - step * 0.13;
      for (let k = 0; k < 4; k++) {
        const angle = step * 0.7 + (k * Math.PI) / 2;
        try {
          dim.spawnParticle("minecraft:blue_flame_particle", {
            x: center.x + Math.cos(angle) * radius,
            y: center.y + step * 0.05,
            z: center.z + Math.sin(angle) * radius,
          });
        } catch (e) {}
      }
    }, step * 2);
  }
}

function burst(dim, center) {
  for (let k = 0; k < 12; k++) {
    const angle = (k * Math.PI) / 6;
    try {
      dim.spawnParticle("minecraft:endrod", {
        x: center.x + Math.cos(angle) * 0.6,
        y: center.y + 0.3 + (k % 3) * 0.3,
        z: center.z + Math.sin(angle) * 0.6,
      });
    } catch (e) {}
  }
}

function nearbyIds(dim, center) {
  try {
    return new Set(dim.getEntities({ location: center, maxDistance: 8 }).map((e) => e.id));
  } catch (e) {
    return new Set();
  }
}

function freshEntities(dim, center, before) {
  try {
    return dim.getEntities({ location: center, maxDistance: 8 }).filter((e) => !before.has(e.id));
  } catch (e) {
    return [];
  }
}

function tryCapture(player, target, slot) {
  const container = containerOf(player);
  const held = container?.getItem(slot);
  if (!container || held?.typeId !== EMPTY_ID) return;
  if (target.isValid === false) return;
  if (BOSSES.has(target.typeId)) {
    play(player, "random.break");
    tell(player, "§c", "The Soul Lantern trembles. This soul is too powerful to seal.");
    return;
  }
  if (NOT_SEALABLE.has(target.typeId) || target.hasTag(SPIRIT_TAG) || !component(target, "minecraft:health")) {
    tell(player, "§e", "The Soul Lantern cannot seal this.");
    return;
  }
  const info = readInfo(target);
  const loc = target.location;
  const dim = target.dimension;
  const cell = { x: Math.floor(loc.x), y: Math.floor(loc.y), z: Math.floor(loc.z) };
  const sid = newStructureId();
  try {
    world.structureManager.createFromWorld(sid, dim, cell, cell, {
      includeBlocks: false,
      includeEntities: true,
      saveMode: StructureSaveMode.World,
    });
  } catch (e) {
    tell(player, "§c", "The soul slipped away. Try again.");
    return;
  }
  const stack = new ItemStack(FILLED_ID, 1);
  stack.setDynamicProperty(KEY.sid, sid);
  stack.setDynamicProperty(KEY.type, info.type);
  stack.setDynamicProperty(KEY.name, info.name);
  stack.setDynamicProperty(KEY.hp, info.hp);
  stack.setDynamicProperty(KEY.maxHp, info.maxHp);
  stack.setDynamicProperty(KEY.baby, info.baby);
  stack.setDynamicProperty(KEY.details, info.details);
  refreshDisplay(stack);
  target.remove();
  container.setItem(slot, stack);
  swirl(dim, { x: loc.x, y: loc.y + 0.8, z: loc.z });
  play(player, "block.amethyst_block.chime");
  tell(player, "§b", `Sealed: ${info.name || prettyType(info.type)}`);
}

function tryRelease(player, dim, blockLoc, slot) {
  const container = containerOf(player);
  const held = container?.getItem(slot);
  if (!container || held?.typeId !== FILLED_ID) return;
  const d = readStack(held);
  if (typeof d.sid !== "string" || !d.sid) {
    tell(player, "§c", "This lantern holds no soul.");
    return;
  }
  let cell;
  for (let up = 1; up <= 4 && !cell; up++) {
    const c = { x: blockLoc.x, y: blockLoc.y + up, z: blockLoc.z };
    const low = dim.getBlock(c);
    const high = dim.getBlock({ x: c.x, y: c.y + 1, z: c.z });
    if (low?.isAir && high?.isAir) cell = c;
  }
  if (!cell) {
    tell(player, "§e", "There is no free space to release the soul here.");
    return;
  }
  const center = { x: cell.x + 0.5, y: cell.y + 0.5, z: cell.z + 0.5 };
  const before = nearbyIds(dim, center);
  try {
    world.structureManager.place(d.sid, dim, cell, { includeBlocks: false, includeEntities: true });
  } catch (e) {
    tell(player, "§c", "The soul could not be released.");
    return;
  }
  container.setItem(slot, new ItemStack(EMPTY_ID, 1));
  burst(dim, center);
  play(player, "random.orb");
  tell(player, "§b", `Released: ${d.name || d.species}`);
  system.runTimeout(() => {
    if (d.rename) {
      for (const e of freshEntities(dim, center, before)) {
        try {
          e.nameTag = d.rename;
        } catch (err) {}
      }
    }
    try {
      world.structureManager.delete(d.sid);
    } catch (err) {}
  }, 4);
}

function cooldownLeft(player) {
  const until = cooldowns.get(player.id);
  return until === undefined ? 0 : Math.max(0, until - system.currentTick);
}

function endSpirit(id, message) {
  const s = spirits.get(id);
  if (!s) return;
  spirits.delete(id);
  try {
    if (s.entity.isValid !== false) {
      burst(s.entity.dimension, s.entity.location);
      s.entity.remove();
    }
  } catch (e) {}
  if (message && s.owner) tell(s.owner, "§b", message);
}

function summon(player, slot) {
  const container = containerOf(player);
  const held = container?.getItem(slot);
  if (held?.typeId !== FILLED_ID) return;
  const left = cooldownLeft(player);
  if (left > 0) {
    tell(player, "§e", `The lantern is recharging: ${Math.ceil(left / 20)}s`);
    return;
  }
  for (const [id, s] of spirits) {
    if (s.owner.id === player.id) endSpirit(id, undefined);
  }
  const d = readStack(held);
  const dim = player.dimension;
  const p = player.location;
  let spirit;
  try {
    spirit = dim.spawnEntity(SPIRIT_ID, { x: p.x + 1.5, y: p.y + 0.8, z: p.z });
  } catch (e) {
    tell(player, "§c", "The spirit could not take shape.");
    return;
  }
  try {
    spirit.addTag(SPIRIT_TAG);
    spirit.nameTag = `§b${d.name || d.species} §3(Spirit)`;
    spirit.addEffect("resistance", SPIRIT_TICKS + 40, { amplifier: 4, showParticles: false });
  } catch (e) {}
  spirits.set(spirit.id, { entity: spirit, owner: player, end: system.currentTick + SPIRIT_TICKS, nextHit: 0 });
  cooldowns.set(player.id, system.currentTick + COOLDOWN_TICKS);
  burst(dim, spirit.location);
  play(player, "block.amethyst_block.chime");
  tell(player, "§b", "Spectral Ally projected for 20 seconds.");
}

async function renameCaptured(player, slot) {
  const container = containerOf(player);
  const held = container?.getItem(slot);
  if (held?.typeId !== FILLED_ID) return;
  const d = readStack(held);
  const form = new ModalFormData()
    .title("§bRename Captured Mob")
    .textField("New name (leave empty to clear)", "Soul name", { defaultValue: d.rename || "" });
  let res;
  try {
    res = await form.show(player);
  } catch (e) {
    return;
  }
  if (!res || res.canceled) return;
  const value = String(res.formValues?.[0] ?? "").trim().slice(0, 32);
  const fresh = container.getItem(slot);
  if (fresh?.typeId !== FILLED_ID) return;
  fresh.setDynamicProperty(KEY.rename, value === "" ? undefined : value);
  refreshDisplay(fresh);
  container.setItem(slot, fresh);
  tell(player, "§b", value === "" ? "The soul's name was cleared." : `The soul is now named ${value}.`);
}

async function openMenu(player) {
  const slot = player.selectedSlotIndex;
  const held = containerOf(player)?.getItem(slot);
  if (held?.typeId !== FILLED_ID) return;
  const d = readStack(held);
  const left = cooldownLeft(player);
  const body = [
    `§7Species: §f${d.species}`,
    `§7Name: §f${d.name || "None"}`,
    `§7Health: §f${d.hp}/${d.maxHp}`,
    `§7Details: §f${d.details || "None"}`,
    `§7Spectral Ally: §f${left > 0 ? `recharging ${Math.ceil(left / 20)}s` : "ready"}`,
  ].join("\n");
  const form = new ActionFormData()
    .title(`§l§6@ALNStudios §eSoul Lantern §r§7(v${VERSION})`)
    .body(body)
    .button("§bProject Spectral Ally (20s)")
    .button("§bRename Captured Mob")
    .button("Close");
  let res;
  try {
    res = await form.show(player);
  } catch (e) {
    return;
  }
  if (!res || res.canceled) return;
  if (res.selection === 0) summon(player, slot);
  else if (res.selection === 1) renameCaptured(player, slot);
}

world.beforeEvents.playerInteractWithEntity.subscribe((ev) => {
  const { player, target, itemStack } = ev;
  if (itemStack?.typeId !== EMPTY_ID || !player.isSneaking) return;
  ev.cancel = true;
  if (busy(player)) return;
  mark(player);
  const slot = player.selectedSlotIndex;
  system.run(() => tryCapture(player, target, slot));
});

world.beforeEvents.playerInteractWithBlock.subscribe((ev) => {
  const { player, block, itemStack, isFirstEvent } = ev;
  if (itemStack?.typeId !== FILLED_ID) return;
  ev.cancel = true;
  if (!isFirstEvent || busy(player)) return;
  mark(player);
  const slot = player.selectedSlotIndex;
  const dim = block.dimension;
  const loc = { x: block.location.x, y: block.location.y, z: block.location.z };
  system.run(() => tryRelease(player, dim, loc, slot));
});

world.afterEvents.itemUse.subscribe(({ source, itemStack }) => {
  if (itemStack?.typeId === FILLED_ID) {
    if (busy(source)) return;
    mark(source);
    openMenu(source);
  } else if (itemStack?.typeId === EMPTY_ID) {
    tell(source, "§7", "Sneak and interact with a mob to seal it.");
  }
});

system.runInterval(() => {
  const now = system.currentTick;
  for (const [id, s] of spirits) {
    let gone = s.entity.isValid === false || now >= s.end;
    if (!gone) {
      try {
        gone = s.owner.isValid === false;
      } catch (e) {
        gone = true;
      }
    }
    if (gone) {
      endSpirit(id, "Your Spectral Ally fades back into the lantern.");
      continue;
    }
    try {
      const dim = s.owner.dimension;
      const p = s.owner.location;
      const angle = now * 0.08;
      const target = {
        x: p.x + Math.cos(angle) * 1.7,
        y: p.y + 0.8 + Math.sin(now * 0.15) * 0.25,
        z: p.z + Math.sin(angle) * 1.7,
      };
      s.entity.teleport(target, { dimension: dim, facingLocation: { x: p.x, y: p.y + 1.2, z: p.z } });
      dim.spawnParticle("minecraft:endrod", { x: target.x, y: target.y + 0.5, z: target.z });
      if (now >= s.nextHit) {
        const foes = dim.getEntities({ location: target, maxDistance: 6, families: ["monster"] });
        const foe = foes.find((e) => e.id !== s.entity.id && !e.hasTag(SPIRIT_TAG));
        if (foe) {
          foe.applyDamage(3, { cause: EntityDamageCause.entityAttack, damagingEntity: s.owner });
          dim.spawnParticle("minecraft:blue_flame_particle", { x: foe.location.x, y: foe.location.y + 1, z: foe.location.z });
          s.nextHit = now + 15;
        }
      }
    } catch (e) {}
  }
}, 2);

world.afterEvents.worldLoad.subscribe(() => {
  for (const name of ["overworld", "nether", "the_end"]) {
    try {
      for (const e of world.getDimension(name).getEntities({ tags: [SPIRIT_TAG] })) e.remove();
    } catch (e) {}
  }
});
```

```
# ALN SoulLantern — Seal mobs in a relic and release them anywhere

**By ALNStudios**

[![Minecraft Bedrock](https://img.shields.io/badge/Minecraft%20Bedrock-Stable%20Release-brightgreen?style=flat-square&logo=minecraft)](https://github.com/AllensCreations/MCPE-Curseforges)

**Seal any mob in a Soul Lantern, then release it or project a 20-second Spectral Ally.**

> Craft the lantern from glass panes, iron nuggets, soul soil or soul sand, and an amethyst shard, then carry a trapped creature with you.

## Overview

ALN SoulLantern adds one relic with two looks. The Empty Soul Lantern holds a faint pale-blue mist, and the Soul-Bound Soul Lantern glows with turquoise soul fire and floating embers.

Sneak and interact with a mob to seal it inside. The lantern shows the creature's name, health, and variant, and you can release it later on any block.

## Key Features

### Soul Lantern Crafting
- **What Happens**: Craft the lantern with 2 glass panes, 4 iron nuggets, 1 amethyst shard, and 1 soul soil or soul sand.

### Mob Capture
- **What Happens**: Sneak and interact with a mob while holding an Empty lantern. The mob vanishes in a swirl of soul particles and the lantern turns turquoise.

### Boss Protection
- **What Happens**: The Ender Dragon, Wither, Warden, and Elder Guardian cannot be sealed. The lantern trembles and a warning appears above the hotbar.

### Saved Mob State
- **What Happens**: The lantern keeps the mob's health, custom name, age, color, tamed state, equipment, and villager trades, and updates its own name and lore to match.

### Block Release
- **What Happens**: Interact with a block while holding a Soul-Bound lantern to place the saved mob on top of it. The lantern returns to the Empty state.

### Spirit Menu
- **What Happens**: Use a Soul-Bound lantern in the air to open a menu with the species, name, health, and variant of the trapped soul.

### Spectral Ally
- **What Happens**: The menu can project a light-blue, slightly transparent spirit for 20 seconds, whichever mob is trapped. It circles you, leaves a particle trail, strikes nearby hostile mobs, never attacks you, then fades back into the lantern, with a 60-second cooldown.

### Rename Captured Mob
- **What Happens**: Give the trapped creature a custom name from the menu without using a Name Tag.

## How to Use

1. Craft a Soul Lantern at a crafting table.
2. Hold the Soul Lantern, sneak, and interact with a mob to seal it.
3. Use the Soul-Bound lantern in the air to open the Spirit menu.
4. Choose Project Spectral Ally to summon a temporary helper, or Rename Captured Mob to rename the soul.
5. Interact with a block while holding the Soul-Bound lantern to release the mob on top of it.
```
