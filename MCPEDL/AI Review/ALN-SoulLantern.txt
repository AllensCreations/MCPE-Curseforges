# scripts/lib

scripts/lib/ holds no .js files yet. Everything lives in scripts/main.js.

## Files

- scripts/main.js: registers all Soul Lantern behavior. Depends on @minecraft/server.
- scripts/lib/README.md: this file.

## What main.js does

- Before-event on player interaction with an entity: a sneaking player holding aln:soul_lantern seals the target mob. The mob is saved with a world structure (entities only), its id and display facts are stored on the item as dynamic properties, and the item becomes aln:soul_lantern_<kind> (or aln:soul_lantern_filled for mobs without an icon).
- Before-event on player interaction with a block: a sneaking player holding a filled lantern places the saved structure on top of the clicked block, waits until a mob has appeared, then deletes the structure and returns an aln:soul_lantern. A failed placement keeps the soul, and a structure that no longer exists empties the lantern.
- After-event on item use: a sneaking player releases the mob in front of them in open air. A player who is not sneaking calls the Spectral Ally, or recalls it when one is already out. Each lantern (by saved structure id) has one spirit and a 10-second recharge that starts when the spirit leaves.
- Repeating timer every 4 ticks: ends spirits after 400 ticks, teleports one back to its owner when it strays, spawns the particle trail, regrows a shrunken Kamikaze Spirit, and detonates it next to a monster.
- World load: removes leftover entities tagged aln_spirit.

## Ids

- Items: aln:soul_lantern, aln:soul_lantern_filled, aln:soul_lantern_<kind> for creeper, skeleton, zombie, spider, pig, cow, sheep, chicken, wolf, villager, iron_golem, enderman, blaze, snow_golem, cat, horse, bee, axolotl, fox, witch, slime, ghast, rabbit, polar_bear.
- Recipes: aln:soul_lantern_soil, aln:soul_lantern_sand.
- Dynamic properties on a filled item: aln_sid, aln_type, aln_name, aln_hp, aln_max_hp, aln_baby, aln_details.
- Entity: aln:spirit, tag aln_spirit, property aln:size, events aln:mode_<mode> and aln:fig_<n>. Structure ids: aln:soul_<random>.

## Known limits

- Bosses (Ender Dragon, Wither, Warden, Elder Guardian), players, armor stands, NPCs and agents cannot be sealed.
- The Spectral Ally floats, never attacks players, and uses an attack mode (melee, fast, heavy, kamikaze, archer, snow) from the captured mob type.
- Villager profession is kept by the saved structure but is not shown anywhere.
- Cooldowns and active allies reset when the world reloads.
- A saved mob stays in the world if its lantern is lost.
- Not tested in game.

    return;

    tell(player, "§e", "The Soul Lantern cannot seal this.");
    return;

  const loc = target.location;
  const dim = target.dimension;
  const cell = { x: Math.floor(loc.x), y: Math.floor(loc.y), z: Math.floor(loc.z) };
  const sid = newStructureId();
  try {
    world.structureManager.createFromWorld(sid, dim, cell, cell, {
      includeBlocks: false,
      includeEntities: true,
      saveMode: StructureSaveMode.World,
    });
  } catch (e) {
    tell(player, "§c", "The soul slipped away. Try again.");
    return;
  }
  const stack = new ItemStack(lanternFor(info.type), 1);
  stack.setDynamicProperty(KEY.sid, sid);
  stack.setDynamicProperty(KEY.type, info.type);

  container.setItem(slot, stack);

  play(player, "block.amethyst_block.chime");
  tell(player, "§b", `Sealed: ${info.name || prettyType(info.type)}`);
}

function confirmRelease(player, dim, center, before, d, attempt) {
  system.runTimeout(() => {
    const found = freshEntities(dim, center, before).length > 0;
    if (!found && attempt < 2) {
      confirmRelease(player, dim, center, before, d, attempt + 1);
      return;

        tell(player, "§c", "The soul could not take shape here. Try another spot.");
        return;
      }
      const lantern = findLantern(player, d.sid);
      if (lantern) lantern.container.setItem(lantern.slot, new ItemStack(EMPTY_ID, 1));
      endSpirit(d.sid, undefined, false);
      burst(dim, center);
      play(player, "random.orb");
      tell(player, "§b", `Released: ${d.name || d.species}`);
    } catch (e) {}
    if (found) {
      try {
        world.structureManager.delete(d.sid);
      } catch (e) {}
    }
  }, attempt === 0 ? 2 : 8);
}

function tryRelease(player, dim, base, slot) {
  const container = containerOf(player);
  const held = container?.getItem(slot);
  if (!container || !isFilled(held?.typeId)) return;
  const d = readStack(held);
  if (typeof d.sid !== "string" || !d.sid) {
    container.setItem(slot, new ItemStack(EMPTY_ID, 1));
    tell(player, "§e", "This lantern held no soul and was emptied.");
    return;
  }
  if (releasing.has(d.sid)) return;
  const cell = findFree(dim, base, 3);
  if (!cell) {
    tell(player, "§e", "There is no free space to release the soul here.");
    return;
  }
  const center = { x: cell.x + 0.5, y: cell.y + 0.5, z: cell.z + 0.5 };
  const before = nearbyIds(dim, center);
  releasing.add(d.sid);
  try {
    world.structureManager.place(d.sid, dim, cell, { includeBlocks: false, includeEntities: true });
  } catch (e) {
    releasing.delete(d.sid);
    container.setItem(slot, new ItemStack(EMPTY_ID, 1));
    endSpirit(d.sid, undefined, false);
    tell(player, "§e", "This soul is gone. The lantern was emptied.");
    return;
  }
  confirmRelease(player, dim, center, before, d, 0);
}

function toggleSpirit(player, slot) {
  const container = containerOf(player);
  const held = container?.getItem(slot);
  if (!isFilled(held?.typeId)) return;
  const d = readStack(held);
  if (typeof d.sid !== "string" || !d.sid) return;
  if (spirits.has(d.sid)) {
    endSpirit(d.sid, "Your Spectral Ally returns to the lantern.");
    return;
  }
  const left = cooldownLeft(d.sid);
  if (left > 0) {
    tell(player, "§e", `The lantern is recharging: ${Math.ceil(left / 20)}s`);
    return;
  }
  const plan = SPECIES[d.type] ?? { fig: 0, mode: "melee" };
  const dim = player.dimension;
  const p = player.location;
  let spirit;
  try {
    spirit = dim.spawnEntity(SPIRIT_ID, { x: p.x + 1.2, y: p.y + 1.2, z: p.z });
  } catch (e) {
    tell(player, "§c", "The spirit could not take shape.");
    return;
  }
  try {
    spirit.triggerEvent(`aln:mode_${plan.mode}`);
    if (plan.fig > 0) spirit.triggerEvent(`aln:fig_${plan.fig}`);
  } catch (e) {}
  try {
    spirit.addTag(SPIRIT_TAG);
    spirit.nameTag = `§b${d.name || d.species} §3(Spirit)`;
    spirit.addEffect("resistance", SPIRIT_TICKS + 40, { amplifier: 4, showParticles: false });
  } catch (e) {}
  spirits.set(d.sid, { entity: spirit, owner: player, end: system.currentTick + SPIRIT_TICKS, mode: plan.mode, size: 1 });
  burst(dim, spirit.location);
  play(player, "block.amethyst_block.chime");
  tell(player, "§b", "Spectral Ally called. Hold again to recall it.");
}

function setSize(entity, value) {
  try {
    entity.setProperty("aln:size", value);
  } catch (e) {}
}

world.beforeEvents.playerInteractWithEntity.subscribe((ev) => {
  const { player, target, itemStack } = ev;

  const dim = block.dimension;

world.afterEvents.itemUse.subscribe(({ source, itemStack }) => {
  const id = itemStack?.typeId;

system.runInterval(() => {
  const now = system.currentTick;

    let gone = s.entity.isValid === false || now >= s.end;

> Craft the lantern from glass panes, iron nuggets, soul soil or soul sand, and an amethyst shard, then carry a trapped creature with you.

## Overview

ALN SoulLantern adds one relic with two looks. The Empty Soul Lantern holds a faint pale-blue mist, and the Soul-Bound Soul Lantern glows with turquoise soul fire and floating embers.

Sneak and interact with a mob to seal it inside. The lantern takes an icon for that mob and shows its name, health, and variant. Sneak and click to release it, or use the lantern to call a floating Spectral Ally.

## Key Features

### Soul Lantern Crafting
- **What Happens**: Craft the lantern with 2 glass panes, 4 iron nuggets, 1 amethyst shard, and 1 soul soil or soul sand.

### Mob Capture
- **What Happens**: Sneak and interact with a mob while holding an Empty lantern. The mob vanishes in a swirl of soul particles and the lantern turns turquoise, with a different icon for each kind of mob.

### Boss Protection
- **What Happens**: The Ender Dragon, Wither, Warden, and Elder Guardian cannot be sealed. The lantern trembles and a warning appears above the hotbar.

### Saved Mob State
- **What Happens**: The lantern keeps the mob's health, custom name, age, color, tamed state, equipment, and villager trades, and updates its own name and lore to match.

### Block Release
- **What Happens**: Sneak and click with a Soul-Bound lantern to place the saved mob on top of the block you aim at, or in front of you in open air. The lantern returns to the Empty state.

### Spectral Ally
- **What Happens**: Use a Soul-Bound lantern to call a floating, light-blue, slightly transparent spirit with a tiny figure of the trapped mob inside. It fights nearby hostile mobs like a pet for 20 seconds, never attacks you, then fades back into the lantern. Use it again to recall it early. Each lantern has one spirit and a 10-second recharge.

### Mob-Specific Attacks
- **What Happens**: A trapped Creeper becomes a kamikaze that explodes beside its target, then shrinks and slowly grows back. A Skeleton fires arrows, a Snow Golem throws snowballs, Spiders, wolves, and chickens attack fast, and Iron Golems and Endermen hit hard.

## How to Use

1. Craft a Soul Lantern at a crafting table.
2. Hold the Soul Lantern, sneak, and interact with a mob to seal it.
3. Sneak and click with the Soul-Bound lantern to release the mob where you aim.
4. Use the Soul-Bound lantern to call its floating Spectral Ally, and use it again to recall it.
5. Wait 10 seconds after the spirit leaves before calling it again.
