# mcpe-pack-update: Update Spec Delivery

## Authority

- `INSTRUCTIONS.md` is the policy source. `PACK_GENERATOR_INSTRUCTIONS.md` is its standalone copy for generation. The script flow is `INSTRUCTIONS.md` "Termux Script Rules", built with `scripts/make_update_script.py`. Where to look each rule up: the `mcpe-context7` skill. This skill is a short working checklist and never restates or overrides them.
- **Precedence** (as in `PACK_GENERATOR_INSTRUCTIONS.md`): factual accuracy and the user's requested scope, then Part 1, then Part 2, then this skill. Part 4 of the generator file never overrides Parts 1 and 2.
- If these files disagree with each other or with a script in `scripts/`, tell the user exactly what differs instead of choosing silently. If `INSTRUCTIONS.md` cannot be read, stop and report it instead of working from memory.
- Achievements line (every project type): always `Yes, achievement-friendly.` Keep any cheats or world-setting caveat as a following sentence.

## Scope

- Use for changes to an existing project (`MCPEDL/Addons|Maps|Script|Minigame/<Name>/`), a workflow, a script, a catalog or any repo doc.
- Read-only audit or report: use `checkrm`.
- New project from an idea: follow `PACK_GENERATOR_INSTRUCTIONS.md` Part 4 (ask the type first, base64 payload).

## Procedure

1. Read `INSTRUCTIONS.md` Parts 1 and 2 before writing anything, through Context7 as the `mcpe-context7` skill says. `make_update_script.py` and `apply_update.py` are complete in the pack's review zip (`<Pack>.zip`) under `files/`; run them from there.
2. Find the destination folder: the path the user named, otherwise the matching project folder. Do not substitute a similar name; report ambiguity or a missing target. Ask at most one question, and only if the answer changes gameplay, compatibility, distribution, data loss or versioning.
3. Read the real source (manifests, scripts, items, recipes, loot tables, functions, lang files) before writing any claim. Source priority when sources disagree, and report the disagreement: the project's own files, Mojang Bedrock Samples, official Minecraft Creator Documentation, Minecraft Wiki, Bedrock Wiki.
4. Make the smallest possible change. No unrelated rewrites. Never invent features, versions, links, assets, test results or compatibility. Never write comments in shipped `.js`, `.mcfunction` or `.json` files.
5. Write the spec (below), test it (below), then reply (below). For changes to an existing project, never deliver a .sh: this overrides any older "deliver the .sh" wording. A NEW pack still follows `mcpe-new-pack` and delivers its generated .sh.

## The spec

File name: `spec_vN.txt`, a downloadable file. N = CURRENT VERSION + 1, read from the attached repo export, never guessed. The user builds the .sh on their phone with `scripts/make_update_script.py`.

Format (`scripts/apply_update.py`):

- Start: `@@ version vN`, then `@@ project MCPEDL/<Category>/<Name>`, then one `@@ file <path relative to the project>` block per file.
- Directives: replace/with, replace-all, insert-after, insert-before, delete, append, create, overwrite, changelog. Remove files with `@@ delete-file <repo-root path>`.
- Small change: replace/insert only. Anchors are copied from the attached export, never from memory, and must occur exactly once. Do not end an anchor with a newline.
- Large redesign: `@@ overwrite` (new content must exceed 60% of the old file) or `@@ create` for new files. Never many fragile edits.
- A content line that starts with `@@` is written `@@@`.
- End with `@@ changelog <Update Name>` using `### Added`, `### Improved & Balanced`, `### Fixed` and `- **Title**: text`. Never touch manifest versions or README links.
- New pixel textures: `@@ create` the pixel JSON under `texture_sources/`, then add the PNG step to the Termux commands.
- Keep README.md and DESCRIPTION.md accurate (INSTRUCTIONS Part 2 template). Never claim an in-game test.

**Test before delivering.** Apply the spec to the export text in the sandbox with `apply_update.py` (`--dry-run`, then a real run on a copy). Check every anchor, validate each changed JSON, run `node --check` on JS. Report every check not run.

## Versions

- N is the current version from the attached export plus one. `apply_update.py` rejects a stale version, so a stale spec cannot run on a newer repo.
- Never edit manifest versions or the README version or download link. The auto-version-bump workflow does that on push.

## Docs

- The changelog entry is mandatory on every update and is written with the final `@@ changelog <Update Name>` directive. Never edit or delete older entries; correct them in the new entry.
- After the change, check the README.md and DESCRIPTION.md in the destination. Edit them only if the change makes them inaccurate or incomplete. Never remove verified content.
- Follow the Part 2 templates in `INSTRUCTIONS.md` exactly (`scripts/doc_template.py` fails the build on deviation): same headings, same heading text, same order, same labels, no added sections, no boilerplate, no placeholders. README is version-free and DESCRIPTION has no release version in its title.
- Writing, layout, attribution, keywords and the README and DESCRIPTION templates are defined in `INSTRUCTIONS.md` Part 2. Read them there; do not copy them into the script from memory.

## Reply

1. `spec_vN.txt` as a downloadable file.
2. These Termux commands, with N and the project filled in:

```
cd ~/MCPE-Curseforges && git checkout -- Package changelog_views && git pull --rebase --autostash
python3 scripts/make_update_script.py ~/storage/downloads/spec_vN.txt --out-dir ~/storage/downloads --verify ~/MCPE-Curseforges
bash ~/storage/downloads/<Name>_vN_*.sh
```

Only when textures changed, then:

```
python3 scripts/pixel_json_to_png.py MCPEDL/<Category>/<Name>
git add MCPEDL/<Category>/<Name>/resource_pack/textures
git commit -m "<short>" && git pull --rebase --autostash && git push
```

3. Two or three sentences: what changed, which checks ran, what is unverified. Add `Docs queried (YYYY-MM-DD): <library IDs and topics>`.

import { EntityComponentTypes, EquipmentSlot, GameMode, ItemComponentTypes } from "@minecraft/server";

export function isCreative(player) {
  return player.getGameMode() === GameMode.Creative;
}

function mainHandSlot(player) {
  return player.getComponent(EntityComponentTypes.Equippable)?.getEquipmentSlot(EquipmentSlot.Mainhand);
}

export function heldItem(player) {
  return player.getComponent(EntityComponentTypes.Equippable)?.getEquipment(EquipmentSlot.Mainhand);
}

export function clearHeldItem(player) {
  mainHandSlot(player)?.setItem(undefined);
}

export function inventoryOf(player) {
  return player.getComponent(EntityComponentTypes.Inventory)?.container;
}

export function findAmmo(player, typeIds) {
  const container = inventoryOf(player);
  if (!container) return undefined;
  for (const typeId of typeIds) {
    for (let slot = 0; slot < container.size; slot++) {
      if (container.getItem(slot)?.typeId === typeId) return { slot, typeId };
    }
  }
  return undefined;
}

export function takeOne(player, slot) {
  const container = inventoryOf(player);
  const item = container?.getItem(slot);
  if (!item) return;
  if (item.amount > 1) {
    item.amount -= 1;
    container.setItem(slot, item);
  } else {
    container.setItem(slot, undefined);
  }
}

export function wearHeldItem(player, amount) {
  if (isCreative(player)) return false;
  const slot = mainHandSlot(player);
  const item = slot?.getItem();
  const durability = item?.getComponent(ItemComponentTypes.Durability);
  if (!durability) return false;
  if (durability.damage + amount >= durability.maxDurability) {
    slot.setItem(undefined);
    player.playSound("random.break");
    return true;
  }
  durability.damage += amount;
  slot.setItem(item);
  return false;
}

export function muzzle(player, distance) {
  const head = player.getHeadLocation();
  const dir = player.getViewDirection();
  return { x: head.x + dir.x * distance, y: head.y + dir.y * distance - 0.1, z: head.z + dir.z * distance };
}

export function shoot(projectile, owner, direction, speed) {
  const component = projectile.getComponent("minecraft:projectile");
  component.owner = owner;
  component.shoot({ x: direction.x * speed, y: direction.y * speed, z: direction.z * speed });
}

import { world, system, ItemStack, ItemComponentTypes, EntityDamageCause } from "@minecraft/server";
import { isCreative, heldItem, clearHeldItem, findAmmo, takeOne, wearHeldItem, muzzle, shoot } from "./lib/common.js";

const PLAYER = "minecraft:player";
const CLUB = "aln:wooden_club";
const DAGGER = "aln:copper_dagger";
const SPEAR = "aln:flint_spear";
const SPEAR_PROJECTILE = "aln:flint_spear_projectile";
const BLOWGUN = "aln:blowgun";
const DART = "aln:blowgun_dart";
const SPIDER_EYE = "minecraft:spider_eye";
const SEEDS = ["minecraft:wheat_seeds", "minecraft:beetroot_seeds", "minecraft:melon_seeds", "minecraft:pumpkin_seeds"];

const CLUB_PUSH = 0.9;
const CLUB_LIFT = 0.25;
const SLOWNESS_TICKS = 30;
const DAGGER_DAMAGE = 4;
const BACKSTAB_MULTIPLIER = 1.5;
const BACKSTAB_DOT = 0.5;
const SPEAR_MIN_HOLD = 10;
const SPEAR_FULL_HOLD = 25;
const SPEAR_SPEED_MIN = 1.4;
const SPEAR_SPEED_MAX = 2.4;
const SPEAR_LIFETIME = 200;
const WEAR_TAG = "aln_wear_";
const DART_SPEED = 2.2;
const DART_GAP = 9;
const DART_LIFETIME = 60;
const POISON_TICKS = 60;

const spearStart = new Map();
const spears = new Map();
const darts = new Map();
const lastBlow = new Map();

function horizontal(vector) {
  const length = Math.hypot(vector.x, vector.z);
  return length > 0.001 ? { x: vector.x / length, z: vector.z / length } : undefined;
}

function clubHit(attacker, target) {
  const push = horizontal(attacker.getViewDirection());
  if (push) {
    try {
      target.applyKnockback({ x: push.x * CLUB_PUSH, z: push.z * CLUB_PUSH }, CLUB_LIFT);
    } catch (error) {
      return;
    }
  }
  try {
    target.addEffect("slowness", SLOWNESS_TICKS, { amplifier: 0 });
  } catch (error) {
    return;
  }
}

function daggerHit(attacker, target) {
  let behind = false;
  try {
    const a = horizontal(attacker.getViewDirection());
    const t = horizontal(target.getViewDirection());
    behind = a !== undefined && t !== undefined && a.x * t.x + a.z * t.z > BACKSTAB_DOT;
  } catch (error) {
    return;
  }
  if (!behind) return;
  try {
    target.applyDamage(DAGGER_DAMAGE * BACKSTAB_MULTIPLIER, { cause: EntityDamageCause.entityAttack, damagingEntity: attacker });
    target.dimension.spawnParticle("minecraft:critical_hit_emitter", target.getHeadLocation());
  } catch (error) {
    return;
  }
}

world.afterEvents.entityHitEntity.subscribe(({ damagingEntity, hitEntity }) => {
  if (damagingEntity.typeId !== PLAYER || !hitEntity.isValid) return;
  const typeId = heldItem(damagingEntity)?.typeId;
  if (typeId === CLUB) clubHit(damagingEntity, hitEntity);
  else if (typeId === DAGGER) daggerHit(damagingEntity, hitEntity);
});

function throwSpear(player, held) {
  const item = heldItem(player);
  if (item?.typeId !== SPEAR) return;
  const durability = item.getComponent(ItemComponentTypes.Durability);
  const wear = (durability?.damage ?? 0) + 1;
  const breaks = durability !== undefined && wear >= durability.maxDurability;
  const creative = isCreative(player);
  const power = Math.min(held, SPEAR_FULL_HOLD) / SPEAR_FULL_HOLD;
  const speed = SPEAR_SPEED_MIN + (SPEAR_SPEED_MAX - SPEAR_SPEED_MIN) * power;
  const projectile = player.dimension.spawnEntity(SPEAR_PROJECTILE, muzzle(player, 1));
  try {
    shoot(projectile, player, player.getViewDirection(), speed);
  } catch (error) {
    if (projectile.isValid) projectile.remove();
    return;
  }
  spears.set(projectile.id, { wear, returns: !creative && !breaks });
  if (!creative) clearHeldItem(player);
  if (breaks && !creative) player.playSound("random.break");
  player.playSound("random.bow");
  system.runTimeout(() => {
    const info = spears.get(projectile.id);
    if (info && projectile.isValid) finishSpear(projectile.id, projectile.dimension, projectile.location, projectile);
  }, SPEAR_LIFETIME);
}

function finishSpear(id, dimension, location, projectile) {
  const info = spears.get(id);
  spears.delete(id);
  if (projectile?.isValid) projectile.remove();
  if (!info || !info.returns) return;
  const stack = new ItemStack(SPEAR, 1);
  const durability = stack.getComponent(ItemComponentTypes.Durability);
  if (durability) durability.damage = info.wear;
  dimension.spawnItem(stack, location);
}

function backOff(location, vector) {
  const length = Math.hypot(vector.x, vector.y, vector.z);
  if (length < 0.001) return { x: location.x, y: location.y + 0.2, z: location.z };
  const k = 0.4 / length;
  return { x: location.x - vector.x * k, y: location.y - vector.y * k + 0.1, z: location.z - vector.z * k };
}

world.afterEvents.itemStartUse.subscribe(({ source, itemStack }) => {
  if (itemStack?.typeId === SPEAR) spearStart.set(source.id, system.currentTick);
});

world.afterEvents.itemReleaseUse.subscribe(({ source, itemStack }) => {
  if (itemStack?.typeId !== SPEAR) return;
  const started = spearStart.get(source.id);
  spearStart.delete(source.id);
  if (started === undefined) return;
  const held = system.currentTick - started;
  if (held >= SPEAR_MIN_HOLD) throwSpear(source, held);
});

world.afterEvents.projectileHitBlock.subscribe(({ projectile, location, hitVector, dimension }) => {
  const id = projectile.id;
  if (spears.has(id)) finishSpear(id, dimension, backOff(location, hitVector), projectile);
  darts.delete(id);
});

world.afterEvents.projectileHitEntity.subscribe((event) => {
  const id = event.projectile.id;
  if (spears.has(id)) {
    finishSpear(id, event.dimension, event.location, event.projectile);
    return;
  }
  const poison = darts.get(id);
  darts.delete(id);
  if (!poison) return;
  const target = event.getEntityHit()?.entity;
  if (!target?.isValid) return;
  try {
    target.addEffect("poison", POISON_TICKS, { amplifier: 0 });
  } catch (error) {
    return;
  }
});

function fireBlowgun(player) {
  const creative = isCreative(player);
  const order = player.isSneaking ? [SPIDER_EYE, ...SEEDS] : [...SEEDS, SPIDER_EYE];
  const ammo = findAmmo(player, order);
  if (!ammo && !creative) {
    player.onScreenDisplay.setActionBar("§cNo seeds or Spider Eyes");
    player.playSound("random.click");
    return;
  }
  const poison = ammo ? ammo.typeId === SPIDER_EYE : player.isSneaking;
  const dart = player.dimension.spawnEntity(DART, muzzle(player, 0.9));
  try {
    shoot(dart, player, player.getViewDirection(), DART_SPEED);
  } catch (error) {
    if (dart.isValid) dart.remove();
    return;
  }
  darts.set(dart.id, poison);
  if (ammo && !creative) takeOne(player, ammo.slot);
  wearHeldItem(player, 1);
  player.playSound("random.pop");
  system.runTimeout(() => {
    darts.delete(dart.id);
    if (dart.isValid) dart.remove();
  }, DART_LIFETIME);
}

world.afterEvents.itemUse.subscribe(({ source, itemStack }) => {
  if (itemStack?.typeId !== BLOWGUN) return;
  const now = system.currentTick;
  if (now - (lastBlow.get(source.id) ?? -DART_GAP) < DART_GAP) return;
  lastBlow.set(source.id, now);
  fireBlowgun(source);
});

world.afterEvents.playerLeave.subscribe(({ playerId }) => {
  spearStart.delete(playerId);
  lastBlow.delete(playerId);
});

import { world, system } from "@minecraft/server";
import { isCreative, heldItem, findAmmo, takeOne, wearHeldItem, muzzle, shoot } from "./lib/common.js";

const SLINGSHOT = "aln:slingshot";
const PEBBLE = "aln:slingshot_pebble";
const FLINT = "minecraft:flint";
const COBBLESTONE = "minecraft:cobblestone";
const STAGE_START = [0, 1, 9, 19];
const STAGE_SPEED = [0, 0.9, 1.6, 2.4];
const STAGE_EVENT = [undefined, undefined, "aln:set_damage_4", "aln:set_damage_6"];
const FLINT_EVENT = "aln:set_damage_8";
const STATES = ["aln_slingshot_0", "aln_slingshot_1", "aln_slingshot_2", "aln_slingshot_3"];
const BAR_REFRESH = 40;
const PEBBLE_LIFETIME = 100;

const charging = new Map();
let timer;

function stageOf(held) {
  let stage = 0;
  for (let i = 1; i < STAGE_START.length; i++) {
    if (held >= STAGE_START[i]) stage = i;
  }
  return stage;
}

function showBar(player, stage) {
  player.onScreenDisplay.setActionBar("§7Slingshot: §a[" + "|".repeat(stage) + " ".repeat(3 - stage) + "]");
}

function setStateTag(player, stage) {
  for (const tag of STATES) player.removeTag(tag);
  player.addTag(STATES[stage]);
}

function clearState(id) {
  const state = charging.get(id);
  charging.delete(id);
  if (state?.player.isValid) {
    for (const tag of STATES) state.player.removeTag(tag);
  }
}

function holdingSlingshot(player) {
  return heldItem(player)?.typeId === SLINGSHOT;
}

function stopTimerIfIdle() {
  if (charging.size === 0 && timer !== undefined) {
    system.clearRun(timer);
    timer = undefined;
  }
}

function tick() {
  const now = system.currentTick;
  for (const [id, state] of charging) {
    const player = state.player;
    if (!player.isValid || !holdingSlingshot(player)) {
      clearState(id);
      continue;
    }
    const stage = stageOf(now - state.startTick);
    if (stage !== state.stage) {
      state.stage = stage;
      setStateTag(player, stage);
      if (stage === 3) player.playSound("random.click");
      showBar(player, stage);
      state.nextBar = now + BAR_REFRESH;
    } else if (stage > 0 && now >= state.nextBar) {
      showBar(player, stage);
      state.nextBar = now + BAR_REFRESH;
    }
  }
  stopTimerIfIdle();
}

function launch(player, stage) {
  const creative = isCreative(player);
  const ammo = findAmmo(player, [FLINT, COBBLESTONE]);
  if (!ammo && !creative) {
    player.onScreenDisplay.setActionBar("§cNo Flint or Cobblestone");
    player.playSound("random.click");
    return;
  }
  const flint = ammo?.typeId === FLINT;
  const direction = player.getViewDirection();
  const pebble = player.dimension.spawnEntity(PEBBLE, muzzle(player, 0.9));
  try {
    const event = stage === 3 && flint ? FLINT_EVENT : STAGE_EVENT[stage];
    if (event) pebble.triggerEvent(event);
    shoot(pebble, player, direction, STAGE_SPEED[stage]);
  } catch (error) {
    if (pebble.isValid) pebble.remove();
    return;
  }
  if (ammo && !creative) takeOne(player, ammo.slot);
  wearHeldItem(player, 1);
  player.playSound("random.bow");
  system.runTimeout(() => {
    if (pebble.isValid) pebble.remove();
  }, PEBBLE_LIFETIME);
}

world.afterEvents.itemStartUse.subscribe(({ source, itemStack }) => {
  if (itemStack?.typeId !== SLINGSHOT) return;
  clearState(source.id);
  charging.set(source.id, { player: source, startTick: system.currentTick, stage: 0, nextBar: 0 });
  setStateTag(source, 0);
  if (timer === undefined) timer = system.runInterval(tick, 1);
});

world.afterEvents.itemReleaseUse.subscribe(({ source, itemStack }) => {
  const state = charging.get(source.id);
  if (!state || itemStack?.typeId !== SLINGSHOT) return;
  const stage = stageOf(system.currentTick - state.startTick);
  clearState(source.id);
  stopTimerIfIdle();
  if (stage > 0) launch(source, stage);
});

# Expanded Basic Arsenal — Five early-game weapons for Minecraft Bedrock

**By ALNStudios**

[![Minecraft Bedrock](https://img.shields.io/badge/Minecraft%20Bedrock-Stable%20Release-brightgreen?style=flat-square&logo=minecraft)](https://github.com/AllensCreations/MCPE-Curseforges)

**Five early-game weapons: Slingshot, Wooden Club, Flint Spear, Blowgun and Copper Dagger, crafted from sticks, string, flint, bamboo, logs and copper.**

> Expanded Basic Arsenal adds a three-stage Slingshot, a knockback Wooden Club, a throwable Flint Spear, a Blowgun and a Copper Dagger with a backstab bonus. All five are craftable before iron and suit the first days of a survival world.

## Overview

Craft a weapon from first-day materials, then pick the one that fits the fight. The Slingshot fires Flint or Cobblestone at range, the Wooden Club pushes mobs away and slows them, and the Flint Spear can be thrown and picked up again. The Blowgun fires seeds or poison darts, and the Copper Dagger hits harder from behind. Every weapon wears down with use.

## Key Features

### Slingshot
- **What Happens**: Hold the use button to pull the Slingshot back, then release to fire. A pull under 0.45 seconds deals 2 damage, a pull of 0.45 to 0.9 seconds deals 4, and a full pull of 0.95 seconds or more deals 6.
- **How It Works**: At full pull a click sounds and the Action Bar shows three charge pips. Craft it with 4 Sticks and 1 String: two Sticks on the top corners, String between them, and two Sticks below.
- **Good To Know**: Each shot uses one Flint, or one Cobblestone when no Flint is carried. A full-pull Flint shot deals 2 extra damage for 8 total. Creative mode uses no ammo. Durability is 180 and each shot costs 1.

### Wooden Club
- **What Happens**: Each hit deals 5 damage, pushes the target back farther than a normal hit and applies Slowness for 1.5 seconds.
- **How It Works**: Craft it with 2 Stripped Logs stacked above 1 Stick. Oak, Spruce, Birch, Jungle, Acacia, Dark Oak, Mangrove and Cherry Stripped Logs all work.
- **Good To Know**: Durability is 150.

### Flint Spear
- **What Happens**: As a melee weapon it deals 5 damage. Hold the use button for at least 0.5 seconds and release to throw it. A thrown spear deals 6 damage and flies faster the longer it was held, up to 1.25 seconds.
- **How It Works**: A thrown spear drops as an item where it lands or hits, and you pick it up by walking over it. Craft it with 1 Flint at the top right and 2 Sticks running diagonally below it.
- **Good To Know**: Durability is 120 and each throw costs 1. A spear with no durability left breaks on the throw. Creative mode does not drop a spear after a throw.

### Blowgun
- **What Happens**: Use the Blowgun to fire a dart, with a 0.5 second gap between shots. Each dart deals 1 damage and uses one Wheat, Beetroot, Melon or Pumpkin Seed.
- **How It Works**: A Spider Eye fires a poison dart that applies Poison I for 3 seconds. Sneak while firing to use Spider Eyes before seeds. Craft it with 3 Bamboo in the top row and 1 String below the left end.
- **Good To Know**: Without sneaking, Spider Eyes are used only when no seeds are carried. Durability is 150 and each shot costs 1.

### Copper Dagger
- **What Happens**: Each hit deals 4 damage. Hitting a target from behind, while both of you face roughly the same direction, deals 50% more damage for 6 total and shows critical hit particles.
- **How It Works**: Craft it with 1 Copper Ingot above 1 Stick.
- **Good To Know**: Durability is 190. The backstab bonus depends on the target's facing, so mobs that turn to face you take normal damage.

## How to Use

1. Gather Sticks, String, Flint, Bamboo, Stripped Logs and Copper Ingots.
2. Craft a weapon at a crafting table. All recipes appear in the recipe book from the start.
3. Hold the Slingshot's use button with Flint or Cobblestone in your inventory, release after about one second, and watch the pebble fly.
4. Right-click the Blowgun with seeds in your inventory to fire darts, or hold and release the Flint Spear to throw it.
