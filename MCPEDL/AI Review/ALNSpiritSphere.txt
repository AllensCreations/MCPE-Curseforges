# mcpe-pack-update: Update Delivery

## Authority

- `INSTRUCTIONS.md` is the policy source. `PACK_GENERATOR_INSTRUCTIONS.md` is its standalone copy for generation. The script flow is `INSTRUCTIONS.md` "Termux Script Rules", built with `scripts/make_update_script.py`. Where to look each rule up: the `mcpe-context7` skill. This skill is a short working checklist and never restates or overrides them.
- **Precedence** (as in `PACK_GENERATOR_INSTRUCTIONS.md`): factual accuracy and the user's requested scope, then Part 1, then Part 2, then this skill. Part 4 of the generator file never overrides Parts 1 and 2.
- If these files disagree with each other or with a script in `scripts/`, tell the user exactly what differs instead of choosing silently. If `INSTRUCTIONS.md` cannot be read, stop and report it instead of working from memory.
- Achievements line (every project type): always `Yes, achievement-friendly.` Keep any cheats or world-setting caveat as a following sentence.

## Scope

- Use for changes to an existing project (`MCPEDL/Addons|Maps|Script|Minigame/<Name>/`), a workflow, a script, a catalog or any repo doc.
- Read-only audit or report: use `checkrm`.
- New project from an idea: follow `PACK_GENERATOR_INSTRUCTIONS.md` Part 4 (ask the type first, base64 payload).

## Procedure

1. Read `INSTRUCTIONS.md` Parts 1 and 2 before writing anything, through Context7 as the `mcpe-context7` skill says. `make_update_script.py`, `apply_update.py`, and `pixel_json_to_png.py` are complete in the pack's review zip (`<Pack>.zip`) under `files/`; run them from there.
2. Find the destination folder: the path the user named, otherwise the matching project folder. Do not substitute a similar name; report ambiguity or a missing target.
3. Read the real source (manifests, scripts, items, recipes, loot tables, functions, lang files) before writing any claim. Source priority when sources disagree: the project's own files, Mojang Bedrock Samples, official Minecraft Creator Documentation, Minecraft Wiki, Bedrock Wiki.
4. Make the smallest possible change. No unrelated rewrites. Never invent features, versions, links, assets, test results or compatibility. Never write comments in shipped `.js`, `.mcfunction` or `.json` files.
5. Generate the spec, convert it with `make_update_script.py` into a single self-contained `<Pack>_v<Version>_<rand>.sh` file, and provide the one-line run command for the user.

## The update script

Generate the spec with `apply_update.py` directives (replace, replace-all, insert-after, insert-before, create, overwrite, delete, changelog).
Then build the single `.sh` using:
```bash
python3 files/scripts/make_update_script.py spec.txt --out-dir .
```
This produces ONE single `.sh` file (`<PackName>_v<Version>_<rand>.sh`) that contains the embedded update payload, ANSI colored status UI, automated git rebase, validation checks, commit, and push.

## Reply

2. Give the single Termux command:
```bash
bash ~/storage/downloads/<PackName>_v<Version>_*.sh
```
3. Brief summary of what changed and what checks ran.
4. **Save in AI memory**: Every finished output, applied change summary, and spec version must be retained in AI memory/scratch notes so context is preserved across turns without relying on session replay.

import { world } from "@minecraft/server";
import { MODES, ORB_ID, FULL_TICKS, OVER_TICKS, MAX_ORB_AGE } from "./elements.js";
import { sound, impactBurst, orbTrail, handPoint, voidSwirl } from "./visuals.js";

const orbs = new Map();
const PLAYER_ID = "minecraft:player";

function nearby(dimension, at, distance) {
  try {
    return dimension.getEntities({ location: at, maxDistance: distance });
  } catch (e) {
    return [];
  }
}

function explode(dimension, at, radius, breaks, fire) {
  try {
    dimension.createExplosion(at, radius, { breaksBlocks: breaks, causesFire: fire, allowUnderwater: true });
  } catch (e) {}
}

function shove(entity, from, strength, lift) {
  try {
    const l = entity.location;
    const dx = l.x - from.x;
    const dz = l.z - from.z;
    const d = Math.hypot(dx, dz) || 1;
    entity.applyKnockback({ x: (dx / d) * strength, z: (dz / d) * strength }, lift);
  } catch (e) {}
}

function shoveAll(dimension, at, reach, strength, lift) {
  for (const e of nearby(dimension, at, reach)) {
    if (e.typeId === ORB_ID) continue;
    try {
      const l = e.location;
      const d = Math.hypot(l.x - at.x, l.y - at.y, l.z - at.z);
      const falloff = Math.max(0.15, 1 - d / reach);
      shove(e, at, strength * falloff, lift * falloff);
    } catch (err) {}
  }
}

function freeze(dimension, at, radius) {
  const R = Math.min(7, Math.ceil(radius));
  const bx = Math.floor(at.x);
  const by = Math.floor(at.y);
  const bz = Math.floor(at.z);
  for (let dx = -R; dx <= R; dx++) {
    for (let dy = -R; dy <= R; dy++) {
      for (let dz = -R; dz <= R; dz++) {
        if (dx * dx + dy * dy + dz * dz > R * R) continue;
        const p = { x: bx + dx, y: by + dy, z: bz + dz };
        try {
          const b = dimension.getBlock(p);
          if (b && (b.typeId === "minecraft:water" || b.typeId === "minecraft:flowing_water")) {
            dimension.setBlockType(p, "minecraft:ice");
          }
        } catch (e) {}
      }
    }
  }
}

function detonate(s, at) {
  const d = s.dimension;
  const f = s.f;
  const r = (1.6 + 4.4 * f) * (s.over ? 1.25 : 1);
  const reach = r * 2.2;
  const strength = 0.8 + 2.6 * f;
  const lift = 0.35 + 0.8 * f;
  impactBurst(d, at, r, s.mode.color);
  sound(d, "random.explode", at);
  if (s.mode.id === "aero") {
    explode(d, at, r, true, false);
    shoveAll(d, at, reach, strength * 1.6, lift * 1.3);
  } else if (s.mode.id === "blaze") {
    explode(d, at, r * 0.9, true, true);
    for (const e of nearby(d, at, r * 1.5)) {
      try {
        if (e.typeId !== ORB_ID) e.setOnFire(6, true);
      } catch (err) {}
    }
    shoveAll(d, at, reach, strength * 0.8, lift);
  } else if (s.mode.id === "frost") {
    explode(d, at, r * 0.6, false, false);
    freeze(d, at, r * 1.2);
    for (const e of nearby(d, at, r * 1.6)) {
      try {
        if (e.typeId !== ORB_ID) e.addEffect("slowness", 160 + Math.round(160 * f), { amplifier: 3 });
      } catch (err) {}
    }
    shoveAll(d, at, reach, strength * 0.5, lift * 0.5);
  } else if (s.mode.id === "storm") {
    explode(d, at, r * 0.7, true, false);
    try {
      d.spawnEntity("minecraft:lightning_bolt", at);
    } catch (e) {}
    shoveAll(d, at, reach, strength, lift);
  } else {
    explode(d, at, r * 1.1, true, false);
    shoveAll(d, at, reach, strength * 0.6, lift * 0.6);
  }
}

const VOID_PULL_RADIUS = 10;
const VOID_HOLD_TICKS = 100;
const anchors = new Map();

function pull(a) {
  let found;
  try {
    found = a.dimension.getEntities({ location: a.at, maxDistance: VOID_PULL_RADIUS, families: ["mob"] });
  } catch (e) {
    return;
  }
  for (const e of found) {
    if (e.id === a.owner || e.typeId === PLAYER_ID || e.typeId === ORB_ID) continue;
    try {
      const l = e.location;
      const dx = a.at.x - l.x;
      const dy = a.at.y - l.y;
      const dz = a.at.z - l.z;
      const d = Math.hypot(dx, dy, dz) || 1;
      const k = (0.16 + 0.1 * a.f) * Math.min(1, d / 2.5);
      e.applyImpulse({ x: (dx / d) * k, y: (dy / d) * k + 0.03, z: (dz / d) * k });
    } catch (err) {}
  }
}

function anchorOrb(id, s, at) {
  anchors.set(id, {
    dimension: s.dimension,
    mode: s.mode,
    f: s.f,
    over: s.over,
    owner: s.owner,
    at: { x: at.x, y: at.y + 0.5, z: at.z },
    age: 0,
  });
  sound(s.dimension, "mob.warden.sonic_boom", at);
}

function tickAnchors() {
  for (const [id, a] of anchors) {
    a.age++;
    try {
      voidSwirl(a.dimension, a.at, VOID_PULL_RADIUS, a.mode.color, a.age);
      pull(a);
      if (a.age >= VOID_HOLD_TICKS) {
        anchors.delete(id);
        detonate(a, a.at);
      }
    } catch (e) {
      anchors.delete(id);
    }
  }
}

export function launchOrb(player, modeIndex, held) {
  const mode = MODES[modeIndex];
  const f = Math.min(1, held / FULL_TICKS);
  const dimension = player.dimension;
  const view = player.getViewDirection();
  const start = handPoint(player, view);
  const orb = dimension.spawnEntity(ORB_ID, start);
  const speed = (0.55 + 2.45 * f) * mode.speed;
  orb.applyImpulse({ x: view.x * speed, y: view.y * speed, z: view.z * speed });
  orbs.set(orb.id, {
    orb,
    dimension,
    mode,
    f,
    over: held >= OVER_TICKS,
    owner: player.id,
    age: 0,
    last: start,
    lob: f < 0.35 ? 0.035 * (1 - f / 0.35) : 0,
  });
  sound(dimension, "mob.ghast.fireball", start);
}

export function tickOrbs() {
  tickAnchors();
  for (const [id, s] of orbs) {
    try {
      const loc = s.orb.location;
      s.last = loc;
      s.age++;
      orbTrail(s.dimension, loc, s.mode.color, s.age);
      if (s.lob > 0) s.orb.applyImpulse({ x: 0, y: -s.lob, z: 0 });
      if (s.age > MAX_ORB_AGE) {
        orbs.delete(id);
        if (s.mode.id === "void") anchorOrb(id, s, loc);
        else detonate(s, loc);
        s.orb.kill();
      }
    } catch (e) {
      orbs.delete(id);
    }
  }
}

function onHit(projectile, location) {
  let id;
  try {
    id = projectile.id;
  } catch (e) {
    return;
  }
  const s = orbs.get(id);
  if (!s) return;
  orbs.delete(id);
  const at = location ?? s.last;
  if (s.mode.id === "void") anchorOrb(id, s, at);
  else detonate(s, at);
  try {
    projectile.kill();
  } catch (e) {}
}

export function registerHits() {
  world.afterEvents.projectileHitBlock.subscribe((ev) => onHit(ev.projectile, ev.location));
  world.afterEvents.projectileHitEntity.subscribe((ev) => onHit(ev.projectile, ev.location));
}

const MID = "aln:ss_mid";
const BIG = "aln:ss_big";
const PULL_HAND = "aln:ss_pull_hand";
const PULL_ORB = "aln:ss_pull_orb";
const PULL_VOID = "aln:ss_pull_void";
const PULL_CORE = "aln:ss_pull_core";

export function puff(dimension, id, location, color) {
  try {
    const vars = new MolangVariableMap();
    vars.setColorRGB("variable.color", color);
    dimension.spawnParticle(id, location, vars);
  } catch (e) {}
}

export function sound(dimension, id, location) {
  try {
    dimension.playSound(id, location);
  } catch (e) {}
}

function cross(a, b) {
  return { x: a.y * b.z - a.z * b.y, y: a.z * b.x - a.x * b.z, z: a.x * b.y - a.y * b.x };
}

export function basisOf(view) {
  const rl = Math.hypot(view.z, view.x) || 1;
  const right = { x: -view.z / rl, y: 0, z: view.x / rl };
  const up = cross(right, view);
  return { right, up };
}

export function handPoint(player, view) {
  const loc = player.location;
  const { right } = basisOf(view);
  return {
    x: loc.x + view.x * 0.9 + right.x * 0.4,
    y: loc.y + 1.2 + view.y * 0.9,
    z: loc.z + view.z * 0.9 + right.z * 0.4,
  };
}

function ring(dimension, center, view, radius, count, spin, id, color) {
  const { right, up } = basisOf(view);
  for (let i = 0; i < count; i++) {
    const a = spin + (i * Math.PI * 2) / count;
    const c = Math.cos(a) * radius;
    const s = Math.sin(a) * radius;
    puff(
      dimension,
      id,
      {
        x: center.x + right.x * c + up.x * s,
        y: center.y + right.y * c + up.y * s,
        z: center.z + right.z * c + up.z * s,
      },
      color
    );
  }
}

export function shell(dimension, center, radius, count, id, color) {
  for (let i = 0; i < count; i++) {
    const u = Math.random() * 2 - 1;
    const t = Math.random() * Math.PI * 2;
    const r = Math.sqrt(1 - u * u);
    puff(
      dimension,
      id,
      { x: center.x + Math.cos(t) * r * radius, y: center.y + u * radius, z: center.z + Math.sin(t) * r * radius },
      color
    );
  }
}

export function phaseOf(held) {
  if (held >= OVER_TICKS) return 4;
  if (held >= BURST_TICK) return 3;
  if (held >= 24) return 2;
  return 1;
}

export function renderCharge(player, held, mode) {
  const dimension = player.dimension;
  const view = player.getViewDirection();
  const center = handPoint(player, view);
  const phase = phaseOf(held);
  if (phase === 1) {
    if (held % 2 === 0) ring(dimension, center, view, 0.55, 8, held * 0.25, SMALL, mode.color);
    if (held % 6 === 0) puff(dimension, PULL_HAND, center, mode.color);
  } else if (phase === 2) {
    const k = (held - 24) / (FULL_TICKS - 24);
    ring(dimension, center, view, 0.55 * (1 - k) + 0.04, 6, held * (0.5 + k * 1.5), SMALL, mode.color);
    puff(dimension, MID, center, { red: 1, green: 1, blue: 1 });
    if (held % 2 === 0) puff(dimension, PULL_HAND, center, mode.color);
  } else {
    if (held === BURST_TICK) {
      shell(dimension, center, 0.9, 30, MID, mode.color);
      ring(dimension, center, view, 0.9, 16, 0, BIG, mode.color);
      sound(dimension, "mob.warden.sonic_boom", center);
    }
    puff(dimension, BIG, center, mode.color);
    shell(dimension, center, 0.55, 8, SMALL, mode.color);
    if (phase === 4 && held % 3 === 0) shell(dimension, center, 0.8, 4, MID, { red: 1, green: 1, blue: 1 });
  }
}

export function impactBurst(dimension, center, radius, color) {
  shell(dimension, center, radius * 0.6, 40, MID, color);
  shell(dimension, center, radius * 0.3, 12, BIG, color);
  for (let i = 0; i < 24; i++) {
    const a = (i * Math.PI * 2) / 24;
    puff(dimension, SMALL, { x: center.x + Math.cos(a) * radius, y: center.y + 0.2, z: center.z + Math.sin(a) * radius }, color);
  }
}

export function orbTrail(dimension, center, color, age) {
  puff(dimension, BIG, center, color);
  if (age % 2 === 0) puff(dimension, PULL_ORB, center, color);
  const a = age * 0.9;
  puff(dimension, SMALL, { x: center.x + Math.cos(a) * 0.5, y: center.y + Math.sin(a * 1.3) * 0.5, z: center.z + Math.sin(a) * 0.5 }, color);
  puff(dimension, SMALL, { x: center.x - Math.cos(a) * 0.5, y: center.y - Math.sin(a * 1.3) * 0.5, z: center.z - Math.sin(a) * 0.5 }, color);
}

export function voidSwirl(dimension, center, radius, color, tick) {
  const k = 1 - (tick % 30) / 30;
  const r = radius * k;
  for (let i = 0; i < 8; i++) {
    const a = tick * 0.35 + (i * Math.PI) / 4;
    puff(dimension, SMALL, { x: center.x + Math.cos(a) * r, y: center.y + Math.sin(a * 0.5) * r * 0.4, z: center.z + Math.sin(a) * r }, color);
  }
  puff(dimension, BIG, center, color);
  if (tick % 2 === 0) puff(dimension, PULL_VOID, center, color);
  if (tick > 80) puff(dimension, PULL_CORE, center, color);
}

# ALN:SpiritSphere — Chargeable Elemental Energy Orbs

**By ALNStudios**

[![Minecraft Bedrock](https://img.shields.io/badge/Minecraft%20Bedrock-Stable%20Release-brightgreen?style=flat-square&logo=minecraft)](https://github.com/AllensCreations/MCPE-Curseforges)

**Craft 1 of 5 elemental Spirit Spheres, charge it with a zooming bow-style draw, and fire an orb that blasts harder the longer you hold.**

> Pick an element, charge its sphere in your hand, and throw an energy orb that behaves like an enhanced Ghast fireball.

## Overview

ALN:SpiritSphere adds five craftable Spirit Spheres, one per element, that charge like a bow. While you hold use, the view zooms in, a rising tone plays and energy swirls in your hand through three visual phases. On release it launches the Spirit Orb, a projectile whose speed and explosion size depend on how long you charged.

Each sphere has its own color and impact behavior. There is no switching: carry the elements you want and pick them from the hotbar.

## Key Features

### Five Spirit Spheres
- **What Happens**: Craft the Aero Vortex, Blaze Solar, Frost Nova, Storm Surge and Void Singularity spheres. Each needs an Ender Pearl, an Amethyst Shard and Blaze Powder plus one element item: a Wind Charge or Feather, a Blaze Rod, a Blue Ice, a Lightning Rod or an Obsidian.

### Hold to Charge
- **What Happens**: Hold use with a sphere like a bow. The longer you hold, the faster the orb flies and the larger its blast.

### Zoom and Charge Sound
- **What Happens**: The view zooms in as the charge passes each of the 3 phases and eases back when you release. A tone rises in pitch while you hold.

### Phase 1: Loose Ring
- **What Happens**: For the first 24 ticks (about 1.2 seconds) a wide ring of energy particles swirls around your hand in the color of the active element.

### Phase 2: Compression
- **What Happens**: From tick 24 the ring tightens and spins faster until it is a dense point of light in your palm.

### Phase 3: Expansion
- **What Happens**: At 50 ticks (2.5 seconds) the core bursts into a large glowing sphere with a sonic pulse. Holding to 70 ticks overcharges the shot for a 25 percent larger blast.

### Charge-Scaled Orb
- **What Happens**: Releasing fires the Spirit Orb along your aim. A quick release lobs a slow orb with a small blast, a medium charge flies steadily, and a full charge flies almost straight and fast with a cratering explosion.

### Inward Pull Particles
- **What Happens**: Streams of particles fly inward toward your hand while you charge and toward the orb while it flies. The Void Singularity draws the thickest stream across its full 10 block range and tightens into a dense collapse during its last second.

### Element Colors
- **What Happens**: Each sphere has its own particle color: cyan and white for Aero Vortex, orange and gold for Blaze Solar, icy blue for Frost Nova, purple for Storm Surge and dark magenta for Void Singularity.

### Element Impacts
- **What Happens**: Aero Vortex adds heavy knockback and a fire-free blast. Blaze Solar ignites the area. Frost Nova freezes nearby water and applies Slowness IV. Storm Surge flies 40 percent faster and calls lightning. Void Singularity stops where it lands, hovers for 5 seconds while it pulls every mob within 10 blocks into its core, then collapses in a larger explosion.

## How to Use

1. Craft a sphere from an Ender Pearl, an Amethyst Shard, Blaze Powder and one element item (Wind Charge or Feather for Aero Vortex, then Blaze Rod, Blue Ice, Lightning Rod or Obsidian for the others).
2. Hold use. The view zooms in, a tone rises and the three charge phases build in your hand.
3. Release to fire the orb along your aim. Release early for a slow lob, hold to 50 ticks or more for a fast, large blast.
4. Pick another sphere from the hotbar to change the element. The action bar shows the element while you charge.
