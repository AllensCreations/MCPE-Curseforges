### 1.3 Version Format and Manifests
**Manifest versioning (Bedrock engine format):** `header.version` MUST be a 3-integer array `[X, Y, Z]` (e.g. `[1, 0, 0]`, `[2, 0, 0]`); `metadata.version` MUST be the string `"X.Y.Z"` (e.g. `"1.0.0"`). The Bedrock engine rejects non-array values or strings like `"vX"` in manifests. NEVER use `vX` syntax inside any `manifest.json` field.
**Per-pack user-facing format:** Every user-visible reference to a version uses `vX` (a single whole number): pack title suffix `(vX)`, changelog headings `## [vX]`, package filenames `(Shortcut VX.ext)`, README download links, CurseForge/MCPEDL release names, snapshot folder prefix `V`. The two formats are strictly separate: manifests = `[X, 0, 0]` / `"X.0.0"`, everything the user sees = `vX`.
- Version = `vX` format (single whole number, e.g. `v2`, `v3`; Bedrock `header.version` maps to `[X, 0, 0]`; legacy `X.Y.Z` supported). NEVER `X.Y.Z.A`. No fourth part, no Alpha. Same version in `metadata.version`, `(vX)` titles, changelog headings, package names, README links, snapshots.

- Update: X+1 (v1 -> v2, v2 -> v3; legacy 1.2.3 converts to v2). Manifest title suffix equals version (e.g. `(v2)`).
- Manifest title = `Add-on Name (vX)` (e.g. `Vanilla Quality of Life (v2)`). Exactly one terminal suffix, equals `header.version` (or major integer), BP/RP match. NEVER duplicate suffixes. `scripts/validate_manifest_titles.py [--project <path>]` fails the job on violation (also notes non-fail: format_version != 2, missing/zero `min_engine_version`, missing `metadata.authors`).

- `header.description` contains `by ALNStudios` exactly once. NEVER attribution in title.
- NEVER change pack UUIDs or world storage keys to rename a title. NEVER regenerate header UUIDs (breaks worlds).
- Build sync: every processed project aligns all source manifests to one highest `X.Y.Z`: `header.version`, `metadata.version`, title suffix, module versions, same-project BP/RP deps. FORCES `metadata.authors` = `["ALNStudios"]` and `metadata.product_type` = `"addon"` in EVERY BP and RP manifest (new packs, updates, builds; NEVER another author or type), optional `metadata.license`. `product_type` `"addon"` is what keeps achievements allowed (owner-confirmed in game). The Bedrock Wiki says Mojang removed this in game 26.50 (MCPE-242529): if a newer game version shows achievements disabled, report it, do not hide it.
- Snapshots: `builds/<pack>/versions/V<X.Y.Z>/` (packages, `source.zip`, `source.sha256`, `build_info.json`). Refreshed when source/packages differ. Last 5 kept.
- NOTHING auto-bumps. The new version is written in CHANGELOG.md AND, in the same update script, into every source manifest with `python3 scripts/manifest_tools.py --project <path> --set vX` (header.version, metadata.version, title suffix, module and dependency versions; UUIDs untouched; never lowers)
, so every update changes the build. Publish to CurseForge uploads the newest changelog version as written and groups every entry since the last publish. The passive build (`Build Changed Packs & Sync Catalogs`) aligns each pack to its highest existing version and rebuilds. `--bump` / `AUTO_BUMP_MANIFEST=true` remain in `scripts/auto_bump_and_build.py` for manual use only.
- Package name: **`(<Shortcut> VX.<ext>)`** (example **`(MiningHelmet V1.mcaddon)`**, or legacy **`(<Shortcut> VX.Y.Z.<ext>)`**). Always format name references in bold with parentheses. Shortcut = short, letters and digits only (NEVER `-`, `_`, spaces, `by ALNStudios`), close to the add-on name, kept in `scripts/pack_shortcuts.json` by project folder (fallback: folder name joined). Custom via `metadata.package_filename` or `PACK_FILENAME_TEMPLATE`; MUST contain `V{version}` and no parenthesis in the file name itself, else the default is used. CurseForge upload copy uses the same name. `python3 scripts/rename_packages.py --check|--apply` renames old packages and repairs references.
- Creator name `ALNStudios`. `python3 scripts/rename_brand.py --apply` migrates old name. NEVER rename lowercase namespaces (`allenscreations:`).
- Tools: `python3 scripts/manifest_tools.py --project <path> --check|--align|--bump` (`--all --check`). `sync_manifest_versions.py`: deps and `min_engine_version` maintenance; set `min_engine_version` by hand after lookup. `sync_project_docs.py` NOT in build: edit DESCRIPTION/CHANGELOG deliberately. `sync_readme_links.py [--check]` repairs README links (runs after every build).
- LOCK: every `MCPEDL/Addons/` project has `LOCK` at root starting `ALNStudios Add-on Lock v1`. Importer creates it, build enforces it. Missing/invalid = release-blocking: report path, NEVER call build-ready. Safeguard only, not encryption.

### 1.12 Vanilla Limits and Workarounds
Applies to every addon, map, script, minigame, item, entity, block, trade, recipe and enchantment, new or updated.
- A hardcoded vanilla limit blocks the requested mechanic (examples: mutually exclusive enchantments, item, entity or component caps, trade or recipe limits) AND the standard approach (behavior JSON, commands, crafting, enchanting) fails: NEVER drop the feature silently. The standard approach works: use it, no workaround.
- Lightest workaround first. 1) Data-driven: custom item, block, entity, recipe, loot, trade, spawn rule, animation controller, tag, component. 2) `@minecraft/server`: custom components, events, ItemStack and Entity APIs, dynamic properties, tags or scoreboard for state. 3) Structural: helper or proxy entity, swapped or replaced item or entity, tiered item variants, `.mcstructure` or template placement, function-driven effects.
- NEVER invent an API, component, event or behavior. Use only what the looked-up stable version (1.2) provides and the repo scripts accept. Cannot verify: say so in DESCRIPTION.md.
- Modular: one small file per workaround with one entry point (script: `behavior_pack/scripts/lib/<name>.js` imported relatively; data: its own function file, entity or item definition). Reuse an existing module. NEVER copy the logic per feature.
- Safe: idempotent setup, caps and cleanup for spawned entities and loops, nothing that corrupts worlds or other packs.
- Conflict Prevention & Isolation:
  1. Custom namespace isolation: Always prefix custom items, blocks, and entities with `aln:<name>` (e.g. `aln:<minigame_name>_controller`).
  2. Avoid Vanilla Entity Overrides: Overriding vanilla entity JSON files (e.g. `entities/zombie.json`) completely wipes out other addons modifying the same entity in Bedrock's load order. Whenever possible, hook into vanilla entity mechanics using `@minecraft/server` Script API event subscriptions (`world.afterEvents.entityDie`, `playerInteractWithEntity`, `entityHurt`, etc.) rather than replacing the vanilla entity JSON.
- Docs (`DOCS_RULES.md`): player-facing result only, no code or API names; the trade-off under Good To Know. State achievement and experiment impact per 1.2.

### 1.3 Version Format and Manifests
**Manifest versioning (Bedrock engine format):** `header.version` MUST be a 3-integer array `[X, Y, Z]` (e.g. `[1, 0, 0]`, `[2, 0, 0]`); `metadata.version` MUST be the string `"X.Y.Z"` (e.g. `"1.0.0"`). The Bedrock engine rejects non-array values or strings like `"vX"` in manifests. NEVER use `vX` syntax inside any `manifest.json` field.
**Per-pack user-facing format:** Every user-visible reference to a version uses `vX` (a single whole number): pack title suffix `(vX)`, changelog headings `## [vX]`, package filenames `(Shortcut VX.ext)`, README download links, CurseForge/MCPEDL release names, snapshot folder prefix `V`. The two formats are strictly separate: manifests = `[X, 0, 0]` / `"X.0.0"`, everything the user sees = `vX`.
- Version = `vX` format (single whole number, e.g. `v2`, `v3`; Bedrock `header.version` maps to `[X, 0, 0]`; legacy `X.Y.Z` supported). NEVER `X.Y.Z.A`. No fourth part, no Alpha. Same version in `metadata.version`, `(vX)` titles, changelog headings, package names, README links, snapshots.

- Update: X+1 (v1 -> v2, v2 -> v3; legacy 1.2.3 converts to v2). Manifest title suffix equals version (e.g. `(v2)`).
- Manifest title = `Add-on Name (vX)` (e.g. `Vanilla Quality of Life (v2)`). Exactly one terminal suffix, equals `header.version` (or major integer), BP/RP match. ### 4.13 Pixel textures (custom item and block art)

- One texture: `{"name": "shepherds_pie", "size": 64, "palette": {"0": "#00000000", "1": "#3d2817"}, "pixels": [[0, 0, 1, ...], ...]}`
- `name`: lowercase letters, digits, `_`. It is the PNG name, the key in `resource_pack/textures/item_texture.json` and the item's `minecraft:icon`. ALWAYS register it there.
- `size`: 64 standard for richer detail and styling freedom (16, 32 or 128 allowed when requested). `pixels` = exactly `size` rows of exactly `size` palette indexes.
- `palette`: keys are numbers in quotes, `"0"` = `#00000000` (transparent). Values `#RRGGBB` or `#RRGGBBAA`. Every index used MUST exist in the palette. Max 12 colors.
- Optional `folder`: `items` (default), `blocks` or `items/<sub>`. The PNG goes to `resource_pack/textures/<folder>/<name>.png`.
- Style: Minecraft pixel art, clean outlines, depth, light from the top left, no gradients, no blurry anti-aliasing, styled for 64x64 high detail. Recolors share one grid with a different palette.

- Edition tags `[BE only]`/`[JE only]`. NEVER document a Java-only item as available (Spectral Arrow is not Bedrock).

- Wiki sprite names: `Invicon_<Title_Case_Name>.png`, `ItemSprite_<lowercase-hyphenated-name>.png`. Look up by Wiki name, NEVER identifier. Fetch with available web tool; shell blocked: report, NEVER route around, fall back to Samples. Image license rules: 1.5.

- Content changes per release: ALWAYS verify checked-out version, confirm each path exists. NEVER hardcode values (armor defense, durability) from memory.
- Ids != texture filenames. Inventory all recipes, map every ingredient, report unresolved together. NEVER placeholder.

function damageOffhand(p, amount = 1) {
  try {
    const eq = p.getComponent("minecraft:equippable");
    if (!eq) return;
    const item = eq.getEquipment(EquipmentSlot.Offhand);
    if (!item) return;
    const dur = item.getComponent("minecraft:durability");
    if (!dur) return;
    
    // Honor Unbreaking (script damage bypasses vanilla handling): 1/(level+1) chance to take damage.
    try {
      const ench = item.getComponent("minecraft:enchantable");
      const ub = ench && ench.getEnchantment("unbreaking");
      if (ub && ub.level > 0 && Math.random() >= 1 / (ub.level + 1)) return;
    } catch (err) {}
    if (dur.damage + amount >= dur.maxDurability) {
      // Break the item
      eq.setEquipment(EquipmentSlot.Offhand, undefined);
      p.playSound("random.break");
      p.onScreenDisplay.setActionBar("§cYour Grimoire has shattered!");
      particle(p.dimension, "minecraft:item_break", { x: p.location.x, y: p.location.y + 1, z: p.location.z });
    } else {
      dur.damage += amount;
      eq.setEquipment(EquipmentSlot.Offhand, item);
    }
  } catch (err) {}
}

  - **Solar Dawn**: Saturation + Regeneration I during open Overworld daylight.
  - **Verdant Druid**: Poison immunity + passive fertilization of crops and saplings within 3 blocks.
  - **Frost Weaver**: Frost Walker II water freezing underfoot + powder snow freezing immunity.
  - **Stormcaller**: Speed III outdoors in rain/thunder + 15% retaliatory lightning strike against melee attackers.
  - **Deep Delver**: Permanent Haste II + automatic light in dark areas under Y=55 in the dark.
  - **Void Phantom**: Emergency surface and The End spawn platform (100, 49, 0) void rescue with Slow Falling.
  - **Iron Golem**: 4 Absorption hearts every 30s + melee launch knockback.
  - **Venom Hydra**: Poison and Wither immunity + melee Poison II infliction.
  - **Cursed Alchemist**: Infinite duration preservation and refreshing of all active beneficial potion effects.
  - **Radiant Seraph**: Permanent Regeneration II + Blindness and Nausea immunity.
  - **Arcane Scholar**: Triples all experience gained from mob drops, mining, and orbs.
  - **Mirror Trickster**: 25% evasive damage negation with a 3-block backward blink through smoke.
  - **Cataclysm Dragon**: Strength II, Resistance I, and complete immunity to explosions and dragon breath.

  - Each relic features **100 Max Durability** (durability).
  - **Event-Only Wear**: Passive stat buffs do not consume durability. Durability is deducted only when active abilities, combat procs, or emergency rescues trigger.
  - **Enchanting & Mending**: Compatible with Enchanting Tables and Anvils (enchanting), supporting **Mending**, **Efficiency**, and **Unbreaking**.
  - **Anvil Repairing**: Repairable by combining matching tomes or using vanilla **Books** (Book) at a strict 1:1 ratio (1 durability restored per book) repairable.
  - **Shatter Audio & Particles**: Plays authentic item breaking sound, spawns break particles, and notifies the player on shatter.

  - 6 tomes are designated as uncraftable **Ancient Relics** obtainable only through rare exploration chests:
    - Ancient Cities: *Void Phantom* & *Mirror Trickster* (replaces enchanted golden apple rolls).

    - Dungeon Monster Rooms: *Blood Vampire* (replaces enchanted golden apple rolls).

  - 14 craftable tomes surrounding a central Book in a shaped Crafting Table grid.
  - Generated pixel-art crafting recipe diagrams using vanilla Bedrock sample item textures.

  - **Elemental Visuals:** Added distinct halo effects to reflect each tome's elemental identity.

# Grimoire Relics V2

**By ALNStudios**

[![Minecraft Bedrock](https://img.shields.io/badge/Minecraft%20Bedrock-Stable%20Release-brightgreen?style=flat-square&logo=minecraft)](https://github.com/AllensCreations/MCPE-Curseforges)
[![Format](https://img.shields.io/badge/Format-.MCPACK%20%7C%20.MCADDON%20%7C%20.MCWORLD-blue?style=flat-square)](https://github.com/AllensCreations/MCPE-Curseforges)

Equip one of 20 magical grimoires in your offhand to gain its distinct passive effects, combat abilities, environmental powers, or subtle particle aura. Fourteen tomes are craftable; six Ancient Relics are found through exploration.

---

## Overview

Grimoire Relics V2 adds a collection of magical tomes to Minecraft Bedrock Edition. Each tome has its own effect and is active while equipped in the offhand. Switching away from a tome stops its relic-specific effects.

---

## The 20 Grimoire Relics

### **Infernal Phoenix**
- **Abilities & Mechanics**: Permanent Fire Resistance. Attackers that melee hit you are set on fire for 5s; targets you melee hit burn for 5s.
- **Acquisition**: **Ancient Relic (Loot Only)**: Bastion Treasure

### **Abyssal Tide**
- **Abilities & Mechanics**: Permanent Water Breathing. Night Vision while underwater. Dolphin's Grace while swimming.
- **Acquisition**: Craftable; also found in Shipwreck Treasure

### **Zephyr Wind**
- **Abilities & Mechanics**: Speed II + Jump Boost I. Auto Slow Falling when plunging (while falling quickly). Fall damage is healed back right after it lands; a fatal fall is not prevented.
- **Acquisition**: Craftable

### **Necrotic Lich**
- **Abilities & Mechanics**: Melee strikes inflict Wither II for 3s on victims.
- **Acquisition**: **Ancient Relic (Loot Only)**: Bastion Treasure

### **Mountain Titan**
- **Abilities & Mechanics**: Permanent Resistance II and Slowness I. Complete knockback immunity (cancels knockback velocity on damage).
- **Acquisition**: Craftable

### **Blood Vampire**
- **Abilities & Mechanics**: Life Leech: Every successful melee strike restores 1 full heart (2 HP).
- **Acquisition**: **Ancient Relic (Loot Only)**: Dungeon Monster Rooms

### **Lunar Eclipse**
- **Abilities & Mechanics**: Nocturnal Blessing: Invisibility and Strength I during nighttime in the Overworld.
- **Acquisition**: Craftable

### **Solar Dawn**
- **Abilities & Mechanics**: Solar Nourishment: Saturation and Regeneration I under open daylight skies in the Overworld.
- **Acquisition**: Craftable

### **Verdant Druid**
- **Abilities & Mechanics**: Poison immunity. Naturally fertilizes crops and advances saplings within a 3-block radius.
- **Acquisition**: Craftable

### **Frost Weaver**
- **Abilities & Mechanics**: Frost Walker II (freezes water underfoot into frosted ice, unless sneaking). Powder snow freezing damage is healed back right after it lands.
- **Acquisition**: Craftable

### **Stormcaller**
- **Abilities & Mechanics**: Speed III outdoors during rain or thunderstorms. 15% chance to strike melee attackers with real lightning.
- **Acquisition**: Craftable

### **Deep Delver**
- **Abilities & Mechanics**: Permanent Haste II. Places a light block at your feet while you are below Y=55 and not under open sky.
- **Acquisition**: Craftable; also found in Dungeon Monster Rooms

### **Void Phantom**
- **Abilities & Mechanics**: In The End, the first void rescue triggers a brief 2-second upward lift, followed by a 1-second Slow Falling cushion when safe ground is detected during descent. The rescue continues if you remove the tome from your offhand. After safe touchdown, the activated Void Phantom is consumed from your offhand or inventory if it can be found. Only one rescue can activate per player session.
- **Acquisition**: **Ancient Relic (Loot Only)**: Ancient Cities

### **Iron Golem**
- **Abilities & Mechanics**: Fortified Armor: Grants 4 Absorption hearts every 30s. Melee strikes launch enemies upward into the air.
- **Acquisition**: Craftable

### **Venom Hydra**
- **Abilities & Mechanics**: Full immunity to Poison and Wither. Melee attacks inflict Poison II (5s).
- **Acquisition**: Craftable

### **Cursed Alchemist**
- **Abilities & Mechanics**: Potion Mastery: Keeps active beneficial potion effects from expiring while the tome is equipped.
- **Acquisition**: Craftable; also found in Stronghold Libraries

### **Radiant Seraph**
- **Abilities & Mechanics**: Permanent Regeneration II. Complete immunity to Blindness and Nausea.
- **Acquisition**: Craftable

### **Arcane Scholar**
- **Abilities & Mechanics**: Arcane Intellect: Triples all experience gained from mob drops, mining, and orbs.
- **Acquisition**: Craftable; also found in Stronghold Libraries

### **Mirror Trickster**
- **Abilities & Mechanics**: Elusive Phase: 25% chance upon taking damage to heal that damage back and blink 3 blocks backward through smoke. A fatal hit is not prevented.
- **Acquisition**: **Ancient Relic (Loot Only)**: Ancient Cities

### **Cataclysm Dragon**
- **Abilities & Mechanics**: Strength II and Resistance I. Dragon breath and explosion damage is healed back right after it lands; a fatal hit is not prevented.
- **Acquisition**: **Ancient Relic (Loot Only)**: End Cities

## Durability, Enchanting & World Generation

### Durability, Enchanting, and Repairing
- **100 durability points**: Each Grimoire possesses a durability health bar.
- **Event-Only Wear**: Passive stat buffs (such as Water Breathing, Speed, or Haste) do **not** drain durability. Durability is consumed strictly upon active mechanical execution:
  - *Combat triggers* (e.g. Phoenix burn on hit/hurt, Vampire life-steal, Iron Golem absorption & launch, Hydra poison, Lich wither): 1 durability per event.
  - *Environmental abilities* (e.g. Druid crop boost, Stormcaller lightning strike, Mirror Trickster blink): 1 to 2 durability per event. Frost Weaver costs 1 durability for every 4 times it freezes water underfoot.
  - *Emergency Lifesavers* (Void Phantom): single use; the relic is consumed after a safe touchdown.
- **Enchanting Table & Anvil Compatible**:
  - Can be enchanted via the Enchanting Table or Anvil with enchantments like **Mending**, **Efficiency**, and **Unbreaking**.
  - **Mending** restores tome durability automatically as you collect experience orbs.
- **Anvil Repairing**:
  - Combine two of the same tomes on an Anvil to restore their remaining durability.
  - Can also be repaired on an Anvil using standard **Books** at a strict **1:1 ratio** (1 book restores 1 durability point).
- **Shatter**: If durability reaches 0 without being repaired or protected, the tome shatters with an item break sound and particles and is removed from your equipment.

### World Chest Distribution
The pack includes exploration loot entries for Ancient Relics. Their intended locations are:
- **Ancient Cities**: Chance for **Void Phantom** and **Mirror Trickster**.
- **Bastion Remnants (Treasure)**: **Infernal Phoenix** and **Necrotic Lich**.
- **End Cities**: **Cataclysm Dragon**.
- **Stronghold Libraries**: **Arcane Scholar** and **Cursed Alchemist**.
- **Shipwreck Treasuries**: **Abyssal Tide**.
- **Monster Rooms / Simple Dungeons**: **Blood Vampire** and **Deep Delver**.
- **Enchanted Golden Apples**: No longer appear in Ancient City and Bastion Treasure chests; the tomes take their place.
