### 1.3 Version Format and Manifests
**Manifest versioning (Bedrock engine format):** `header.version` MUST be a 3-integer array `[X, Y, Z]` (e.g. `[1, 0, 0]`, `[2, 0, 0]`); `metadata.version` MUST be the string `"X.Y.Z"` (e.g. `"1.0.0"`). The Bedrock engine rejects non-array values or strings like `"vX"` in manifests. NEVER use `vX` syntax inside any `manifest.json` field.
**Per-pack user-facing format:** Every user-visible reference to a version uses `vX` (a single whole number): pack title suffix `(vX)`, changelog headings `## [vX]`, package filenames `(Shortcut VX.ext)`, README download links, CurseForge/MCPEDL release names, snapshot folder prefix `V`. The two formats are strictly separate: manifests = `[X, 0, 0]` / `"X.0.0"`, everything the user sees = `vX`.
- Version = `vX` format (single whole number, e.g. `v2`, `v3`; Bedrock `header.version` maps to `[X, 0, 0]`; legacy `X.Y.Z` supported). NEVER `X.Y.Z.A`. No fourth part, no Alpha. Same version in `metadata.version`, `(vX)` titles, changelog headings, package names, README links, snapshots.

- Update: X+1 (v1 -> v2, v2 -> v3; legacy 1.2.3 converts to v2). Manifest title suffix equals version (e.g. `(v2)`).
- Manifest title = `Add-on Name (vX)` (e.g. `Vanilla Quality of Life (v2)`). Exactly one terminal suffix, equals `header.version` (or major integer), BP/RP match. NEVER duplicate suffixes. `scripts/validate_manifest_titles.py [--project <path>]` fails the job on violation (also notes non-fail: format_version != 2, missing/zero `min_engine_version`, missing `metadata.authors`).

- `header.description` contains `by ALNStudios` exactly once. NEVER attribution in title.
- NEVER change pack UUIDs or world storage keys to rename a title. NEVER regenerate header UUIDs (breaks worlds).
- Build sync: every processed project aligns all source manifests to one highest `X.Y.Z`: `header.version`, `metadata.version`, title suffix, module versions, same-project BP/RP deps. FORCES `metadata.authors` = `["ALNStudios"]` and `metadata.product_type` = `"addon"` in EVERY BP and RP manifest (new packs, updates, builds; NEVER another author or type), optional `metadata.license`. `product_type` `"addon"` is what keeps achievements allowed (owner-confirmed in game). The Bedrock Wiki says Mojang removed this in game 26.50 (MCPE-242529): if a newer game version shows achievements disabled, report it, do not hide it.
- Snapshots: `builds/<pack>/versions/V<X.Y.Z>/` (packages, `source.zip`, `source.sha256`, `build_info.json`). Refreshed when source/packages differ. Last 5 kept.
- NOTHING auto-bumps. The new version is written in CHANGELOG.md AND, in the same update script, into every source manifest with `python3 scripts/manifest_tools.py --project <path> --set vX` (header.version, metadata.version, title suffix, module and dependency versions; UUIDs untouched; never lowers)
, so every update changes the build. Publish to CurseForge uploads the newest changelog version as written and groups every entry since the last publish. The passive build (`Build Changed Packs & Sync Catalogs`) aligns each pack to its highest existing version and rebuilds. `--bump` / `AUTO_BUMP_MANIFEST=true` remain in `scripts/auto_bump_and_build.py` for manual use only.
- Package name: **`(<Shortcut> VX.<ext>)`** (example **`(MiningHelmet V1.mcaddon)`**, or legacy **`(<Shortcut> VX.Y.Z.<ext>)`**). Always format name references in bold with parentheses. Shortcut = short, letters and digits only (NEVER `-`, `_`, spaces, `by ALNStudios`), close to the add-on name, kept in `scripts/pack_shortcuts.json` by project folder (fallback: folder name joined). Custom via `metadata.package_filename` or `PACK_FILENAME_TEMPLATE`; MUST contain `V{version}` and no parenthesis in the file name itself, else the default is used. CurseForge upload copy uses the same name. `python3 scripts/rename_packages.py --check|--apply` renames old packages and repairs references.
- Creator name `ALNStudios`. `python3 scripts/rename_brand.py --apply` migrates old name. NEVER rename lowercase namespaces (`allenscreations:`).
- Tools: `python3 scripts/manifest_tools.py --project <path> --check|--align|--bump` (`--all --check`). `sync_manifest_versions.py`: deps and `min_engine_version` maintenance; set `min_engine_version` by hand after lookup. `sync_project_docs.py` NOT in build: edit DESCRIPTION/CHANGELOG deliberately. `sync_readme_links.py [--check]` repairs README links (runs after every build).

### 1.12 Vanilla Limits and Workarounds
Applies to every addon, map, script, minigame, item, entity, block, trade, recipe and enchantment, new or updated.
- A hardcoded vanilla limit blocks the requested mechanic (examples: mutually exclusive enchantments, item, entity or component caps, trade or recipe limits) AND the standard approach (behavior JSON, commands, crafting, enchanting) fails: NEVER drop the feature silently. The standard approach works: use it, no workaround.
- Lightest workaround first. 1) Data-driven: custom item, block, entity, recipe, loot, trade, spawn rule, animation controller, tag, component. 2) `@minecraft/server`: custom components, events, ItemStack and Entity APIs, dynamic properties, tags or scoreboard for state. 3) Structural: helper or proxy entity, swapped or replaced item or entity, tiered item variants, `.mcstructure` or template placement, function-driven effects.
- NEVER invent an API, component, event or behavior. Use only what the looked-up stable version (1.2) provides and the repo scripts accept. Cannot verify: say so in DESCRIPTION.md.
- Modular: one small file per workaround with one entry point (script: `behavior_pack/scripts/lib/<name>.js` imported relatively; data: its own function file, entity or item definition). Reuse an existing module. NEVER copy the logic per feature.
- Safe: idempotent setup, caps and cleanup for spawned entities and loops, nothing that corrupts worlds or other packs.
- Conflict Prevention & Isolation:
  1. Custom namespace isolation: Always prefix custom items, blocks, and entities with `aln:<name>` (e.g. `aln:<minigame_name>_controller`).
  2. Avoid Vanilla Entity Overrides: Overriding vanilla entity JSON files (e.g. `entities/zombie.json`) completely wipes out other addons modifying the same entity in Bedrock's load order. Whenever possible, hook into vanilla entity mechanics using `@minecraft/server` Script API event subscriptions (`world.afterEvents.entityDie`, `playerInteractWithEntity`, `entityHurt`, etc.) rather than replacing the vanilla entity JSON.
- Docs (`DOCS_RULES.md`): player-facing result only, no code or API names; the trade-off under Good To Know. State achievement and experiment impact per 1.2.

### 1.3 Version Format and Manifests
**Manifest versioning (Bedrock engine format):** `header.version` MUST be a 3-integer array `[X, Y, Z]` (e.g. `[1, 0, 0]`, `[2, 0, 0]`); `metadata.version` MUST be the string `"X.Y.Z"` (e.g. `"1.0.0"`). The Bedrock engine rejects non-array values or strings like `"vX"` in manifests. NEVER use `vX` syntax inside any `manifest.json` field.
**Per-pack user-facing format:** Every user-visible reference to a version uses `vX` (a single whole number): pack title suffix `(vX)`, changelog headings `## [vX]`, package filenames `(Shortcut VX.ext)`, README download links, CurseForge/MCPEDL release names, snapshot folder prefix `V`. The two formats are strictly separate: manifests = `[X, 0, 0]` / `"X.0.0"`, everything the user sees = `vX`.
- Version = `vX` format (single whole number, e.g. `v2`, `v3`; Bedrock `header.version` maps to `[X, 0, 0]`; legacy `X.Y.Z` supported). NEVER `X.Y.Z.A`. No fourth part, no Alpha. Same version in `metadata.version`, `(vX)` titles, changelog headings, package names, README links, snapshots.

- Update: X+1 (v1 -> v2, v2 -> v3; legacy 1.2.3 converts to v2). Manifest title suffix equals version (e.g. `(v2)`).
- Manifest title = `Add-on Name (vX)` (e.g. `Vanilla Quality of Life (v2)`). Exactly one terminal suffix, equals `header.version` (or major integer), BP/RP match. NEVER duplicate suffixes. `scripts/validate_manifest_titles.py [--project <path>]` fails the job on violation (also notes non-fail: format_version != 2, missing/zero `min_engine_version`, missing `metadata.authors`).

- `header.description` contains `by ALNStudios` exactly once. NEVER attribution in title.
- NEVER change pack UUIDs or world storage keys to rename a title. NEVER regenerate header UUIDs (breaks worlds).
- Build sync: every processed project aligns all source manifests to one highest `X.Y.Z`: `header.version`, `metadata.version`, title suffix, module versions, same-project BP/RP deps. FORCES `metadata.authors` = `["ALNStudios"]` and `metadata.product_type` = `"addon"` in EVERY BP and RP manifest (new packs, updates, builds; NEVER another author or type), optional `metadata.license`. `product_type` `"addon"` is what keeps achievements allowed (owner-confirmed in game). The Bedrock Wiki says Mojang removed this in game 26.50 (MCPE-242529): if a newer game version shows achievements disabled, report it, do not hide it.
- Snapshots: `builds/<pack>/versions/V<X.Y.Z>/` (packages, `source.zip`, `source.sha256`, `build_info.json`). Refreshed when source/packages differ. Last 5 kept.
- NOTHING auto-bumps. The new version is written in CHANGELOG.md AND, in the same update script, into every source manifest with `python3 scripts/manifest_tools.py --project <path> --set vX` (header.version, metadata.version, title suffix, module and dependency versions; UUIDs untouched; never lowers)
, so every update changes the build. Publish to CurseForge uploads the newest changelog version as written and groups every entry since the last publish. The passive build (`Build Changed Packs & Sync Catalogs`) aligns each pack to its highest existing version and rebuilds. `--bump` / `AUTO_BUMP_MANIFEST=true` remain in `scripts/auto_bump_and_build.py` for manual use only.
- Package name: **`(<Shortcut> VX.<ext>)`** (example **`(MiningHelmet V1.mcaddon)`**, or legacy **`(<Shortcut> VX.Y.Z.<ext>)`**). Always format name references in bold with parentheses. Shortcut = short, letters and digits only (NEVER `-`, `_`, spaces, `by ALNStudios`), close to the add-on name, kept in `scripts/pack_shortcuts.json` by project folder (fallback: folder name joined). Custom via `metadata.package_filename` or `PACK_FILENAME_TEMPLATE`; MUST contain `V{version}` and no parenthesis in the file name itself, else the default is used. CurseForge upload copy uses the same name. `python3 scripts/rename_packages.py --check|--apply` renames old packages and repairs references.
- Creator name `ALNStudios`. `python3 scripts/rename_brand.py --apply` migrates old name. NEVER rename lowercase namespaces (`allenscreations:`).
- Tools: `python3 scripts/manifest_tools.py --project <path> --check|--align|--bump` (`--all --check`). `sync_manifest_versions.py`: deps and `min_engine_version` maintenance; set `min_engine_version` by hand after lookup. `sync_project_docs.py` NOT in build: edit DESCRIPTION/CHANGELOG deliberately. `sync_readme_links.py [--check]` repairs README links (runs after every build).
- LOCK: every `MCPEDL/Addons/` project has `LOCK` at root starting `ALNStudios Add-on Lock v1`. Importer creates it, build enforces it. Missing/invalid = release-blocking: report path, NEVER call build-ready. Safeguard only, not encryption.

### 4.13 Pixel textures (custom item and block art)
- The ONLY way to draw new art: pixel JSON, rendered to PNG by `scripts/pixel_json_to_png.py`. NEVER AI-generated images, NEVER copied or guessed art. A vanilla look = use the real vanilla texture name instead. NEVER for `script` projects (no resource_pack).

- One texture: `{"name": "shepherds_pie", "size": 64, "palette": {"0": "#00000000", "1": "#3d2817"}, "pixels": [[0, 0, 1, ...], ...]}`
- `name`: lowercase letters, digits, `_`. It is the PNG name, the key in `resource_pack/textures/item_texture.json` and the item's `minecraft:icon`. ALWAYS register it there.
- `size`: 64 standard for richer detail and styling freedom (16, 32 or 128 allowed when requested). `pixels` = exactly `size` rows of exactly `size` palette indexes.
- `palette`: keys are numbers in quotes, `"0"` = `#00000000` (transparent). Values `#RRGGBB` or `#RRGGBBAA`. Every index used MUST exist in the palette. Max 12 colors.
- Optional `folder`: `items` (default), `blocks` or `items/<sub>`. The PNG goes to `resource_pack/textures/<folder>/<name>.png`.
- Style: Minecraft pixel art, clean outlines, depth, light from the top left, no gradients, no blurry anti-aliasing, styled for 64x64 high detail. Recolors share one grid with a different palette.
- RUN `python3 pixel_json_to_png.py build/<Name>` BEFORE `make_pack_script.py` (4.8): it checks every texture, lists every problem together and writes the PNGs. Fix, rerun. NEVER hand-write a PNG or base64.

export function ensureOneBlock(dimension) {
  try {
    const dimKey = getDimKey(dimension.id);
    if (activeCountdowns.get(dimKey)) return;

    // Bedrock foundation guarantee at (0, 63, 0)
    if (system.currentTick % 20 === 0) {
      const bedrockPos = { x: ONEBLOCK_POS.x, y: ONEBLOCK_POS.y - 1, z: ONEBLOCK_POS.z };
      try {
        const bFloor = dimension.getBlock(bedrockPos);
        if (bFloor && bFloor.typeId !== "minecraft:bedrock") {
          bFloor.setType("minecraft:bedrock");
        }
      } catch (bfe) {}
    }

    const block = dimension.getBlock(ONEBLOCK_POS);
    const isLiquid = block && (block.typeId === "minecraft:water" || block.typeId === "minecraft:flowing_water" || block.typeId === "minecraft:lava" || block.typeId === "minecraft:flowing_lava");
    const stuckBedrock = !!block && block.typeId === "minecraft:bedrock";
    const isMissing = !block || block.isAir || block.typeId === "minecraft:air" || isLiquid || stuckBedrock;

    // A block that vanished without any break/explosion handler counting it within 3 ticks
    // (piston, plant pop, decay) counts as progress once. Player breaks are never double counted.
    const pend = mainPending.get(dimKey);
    if (pend !== undefined && system.currentTick - pend >= 3) {
      mainPending.delete(dimKey);
      if ((lastProgressTick.get(dimKey) ?? -99) < pend) incrementDimensionCount(dimKey, dimension);
    }

    if (isMissing) {
      if (block && !stuckBedrock && lastKnownOneBlockType[dimKey] && !mainPending.has(dimKey)) {
        mainPending.set(dimKey, system.currentTick);
      }
      renewOneBlock(dimension);
    } else if (block) {
      lastKnownOneBlockType[dimKey] = block.typeId;
    }
  } catch (err) {}
}

  const active = getPlayerDims();
  for (const [key, dimId] of [["overworld", "overworld"], ["nether", "nether"], ["end", "the_end"]]) {

    } catch (e) {}
  }

import json
import os
import shutil
import sys
import tempfile
import zipfile

HERE = os.path.dirname(os.path.abspath(__file__))
MODES = (("creative", "Creative"), ("survival", "Survival"))


def main():
    out = sys.argv[1] if len(sys.argv) > 1 else HERE
    os.makedirs(out, exist_ok=True)
    with open(os.path.join(HERE, "behavior_pack", "manifest.json"), encoding="utf-8") as f:
        header = json.load(f)["header"]
    version = header["version"]
    full = ".".join(str(n) for n in version)
    short = ".".join(str(n) for n in version[:2])
    for mode, label in MODES:
        tmp = tempfile.mkdtemp()
        try:
            world = os.path.join(tmp, "world")
            shutil.copytree(os.path.join(HERE, "world"), world)
            pack = os.path.join(world, "behavior_packs", "OneBlockVoid")
            shutil.rmtree(pack)
            shutil.copytree(os.path.join(HERE, "behavior_pack"), pack)
            with open(os.path.join(pack, "scripts", "lib", "mode.js"), "w", encoding="utf-8") as f:
                f.write('export const WORLD_MODE = "%s";\n' % mode)
            with open(os.path.join(world, "world_behavior_packs.json"), "w", encoding="utf-8") as f:
                json.dump([{"pack_id": header["uuid"], "version": version}], f, indent=2)
                f.write("\n")
            with open(os.path.join(world, "levelname.txt"), "w", encoding="utf-8") as f:
                f.write("OneBlock Void Survival %s v%s [ALNStudios]\n" % (label, short))
            name = "OneBlock Void Survival %s by ALNStudios (V%s).mcworld" % (label, full)
            target = os.path.join(out, name)
            with zipfile.ZipFile(target, "w", zipfile.ZIP_DEFLATED) as z:
                for root, _, files in os.walk(world):
                    for fn in sorted(files):
                        full_path = os.path.join(root, fn)
                        z.write(full_path, os.path.relpath(full_path, world))
            print("Built " + target)
        finally:
            shutil.rmtree(tmp, ignore_errors=True)


main()

## Key Features

### Progressive OneBlock Phases
- **What Happens:** The central block renews when mined and advances through phases. Phase length depends on the phase number: phases 1-5 are 50 blocks, phases 6-10 are 100, and phases 11+ are 150 (Overworld 1,500 blocks in total, Nether 450, End 200).

- **Exploration:** Discover 33 islands in the Overworld, seven in the Nether, and three in The End as you reach progression milestones. Each island has its own mini OneBlock core of 30 to 50 blocks. Finishing the core removes the bedrock around it and reveals a treasure chest, and a message tells you how many of the 43 islands you have completed. Grassy and forest islands grow extra trees, and several farm and nature islands come with animals.

### Starter Platform and Supply Chest
- **What Happens:** A 15-block guided tutorial teaches the basics (platform, wood, stone, coal) while the starting platform grows. At the 15-block milestone a Starter Gift Chest appears with 2 ice blocks and a lava bucket for creating water and cobblestone generators.

- **What Happens:** From Phase 5 of the Overworld (and in the Nether and End), mining in the middle of a phase can trigger mystery supply chests, mob spawns, a Lucky Rush (10 seconds of ore spawns), a Void Surge (a short wave of hostile mobs), or a rare Jackpot chest.

### Dimension Shifter Merchant
- **Trading:** The Dimension Shifter visits each dimension for 3 minutes every 8 to 20 minutes (in the Overworld from Phase 5). Each visit offers 5 randomly rolled items by rarity tier, paid in iron, gold, diamonds, or netherite. Stock is shared between players and he leaves if attacked.

### Two Worlds
- **Creative:** Every player starts in Creative mode and nothing is locked.
- **Survival:** Every player is kept in Survival mode, because the pack switches anyone back to Survival within a second. Difficulty is not locked, and normal respawning applies.

import { ItemStack, system, world } from "@minecraft/server";
import { getPhaseLength, ONEBLOCK_POS } from "./config.js";
import { ONEBLOCK_PROGRESSION_POOLS } from "./Oneblock_Progression.js";
import { RARITY_TIERS } from "./rarities.js";

// Derive dimension-specific phase arrays from the shared progression foundation.
// phases 1-19 = overworld, 20-22 = nether, 23+ = the end (matching Oneblock_Progression.js ordering).
export const OVERWORLD_PHASES = ONEBLOCK_PROGRESSION_POOLS.filter(p => p.phase <= 19);
export const NETHER_PHASES    = ONEBLOCK_PROGRESSION_POOLS.filter(p => p.phase >= 20 && p.phase <= 22);
export const END_PHASES       = ONEBLOCK_PROGRESSION_POOLS.filter(p => p.phase >= 23);

export function rollRarityTier() {
  const total = 100.0;
  let rand = Math.random() * total;
  for (let i = 0; i < RARITY_TIERS.length; i++) {
    if (rand < RARITY_TIERS[i].weight) {
      return i;
    }
    rand -= RARITY_TIERS[i].weight;
  }
  return 0;
}

export function pickWeighted(items) {
  const total = items.reduce((sum, item) => sum + (item.weight || 1), 0);
  let random = Math.random() * total;
  for (const item of items) {
    if (random < item.weight) return item;
    random -= item.weight;
  }
  return items[0];
}

export function getDimKey(dimensionId) {
  if (dimensionId.includes("nether")) return "nether";
  if (dimensionId.includes("the_end") || dimensionId.includes("end")) return "end";
  return "overworld";
}

export function getPhasesForDim(dimKey) {
  switch (dimKey) {
    case "nether": return NETHER_PHASES;
    case "end": return END_PHASES;
    default: return OVERWORLD_PHASES;
  }
}

// Computes progressive phase index and progress from block count
export function getDimensionState(dimKey) {
  const countProp = `ob_${dimKey}_count`;
  const count = world.getDynamicProperty(countProp) ?? 0;
  const phases = getPhasesForDim(dimKey);

  let accumulated = 0;
  let phaseIndex = 0;
  let progressInPhase = 0;
  let currentPhaseLength = getPhaseLength(0);

  for (let i = 0; i < phases.length; i++) {
    const len = getPhaseLength(i);
    if (accumulated + len > count || i === phases.length - 1) {
      phaseIndex = i;
      progressInPhase = Math.max(0, count - accumulated);
      currentPhaseLength = len;
      break;
    }
    accumulated += len;
  }

  return {
    count,
    phaseIndex,
    phase: phases[phaseIndex],
    progressInPhase,
    currentPhaseLength
  };
}

export function getCardinalFromCoords(dx, dz) {
  try {
    const deg = ((Math.atan2(dz, dx) * 180) / Math.PI + 360) % 360;
    const directions = ["East", "South-East", "South", "South-West", "West", "North-West", "North", "North-East"];
    const cardinalIdx = Math.round(deg / 45) % 8;
    return directions[cardinalIdx];
  } catch (e) {
    return "North";
  }
}

export function buildTradeStacks(itemId, count) {
  const stacks = [];
  try {
    const maxAmount = Math.max(1, new ItemStack(itemId, 1).maxAmount);
    let left = count;
    while (left > 0) {
      const amount = Math.min(left, maxAmount);
      stacks.push(new ItemStack(itemId, amount));
      left -= amount;
    }
  } catch (err) {
    return [];
  }
  return stacks;
}

// Spawns a real Minecraft Chest block ABOVE ONEBLOCK_POS at (0, 65, 0) and populates it with items
export function spawnOneBlockChest(dimension, items = []) {
  try {
    const chestPos = { x: ONEBLOCK_POS.x, y: ONEBLOCK_POS.y + 1, z: ONEBLOCK_POS.z };

    // Remove any lingering chest_minecart entities around OneBlock
    try {
      const existing = dimension.getEntities({
        type: "minecraft:chest_minecart",
        location: { x: chestPos.x + 0.5, y: chestPos.y + 0.5, z: chestPos.z + 0.5 },
        maxDistance: 2.5
      });
      for (const ent of existing) ent.remove();
    } catch (ee) {}

    const block = dimension.getBlock(chestPos);
    if (block) {
      if (block.typeId !== "minecraft:chest") {
        if (!block.isAir) {
          // Never destroy a player-built block: drop the loot instead
          for (const it of items) {
            try { if (it instanceof ItemStack) dimension.spawnItem(it, { x: chestPos.x + 0.5, y: chestPos.y + 0.2, z: chestPos.z + 0.5 }); } catch (se) {}
          }
          return;
        }
        block.setType("minecraft:chest");
      }

      // Populate chest inventory container on next tick once block entity is instantiated
      system.runTimeout(() => {
        try {
          const cb = dimension.getBlock(chestPos);
          if (cb && cb.typeId === "minecraft:chest") {
            const chestComp = cb.getComponent("minecraft:inventory");
            if (chestComp && chestComp.container) {
              spawnScatteredLootInChest(chestComp.container, items);
            }
          }
        } catch (ie) {}
      }, 1);

      dimension.spawnParticle("minecraft:totem_particle", { x: chestPos.x + 0.5, y: chestPos.y + 0.5, z: chestPos.z + 0.5 });
      dimension.playSound("random.chestopen", chestPos, { volume: 1.0, pitch: 1.0 });
    }
  } catch (e) {}
}

// Scatters loot across random single-chest slots (0-26) with realistic splitting, like vanilla structure loot chests
export function spawnScatteredLootInChest(container, chestItems = []) {
  try {
    if (!container || !chestItems || chestItems.length === 0) return;

    // Available slot indices [0..container.size - 1] (single chest: 0..26)
    const availableSlots = [];
    for (let s = 0; s < container.size; s++) {
      availableSlots.push(s);
    }
    // Fisher-Yates shuffle
    for (let i = availableSlots.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [availableSlots[i], availableSlots[j]] = [availableSlots[j], availableSlots[i]];
    }

    // Deconstruct chest items into smaller stacks if count > 4 for authentic structure chest distribution
    const itemsToPlace = [];
    for (const entry of chestItems) {
      if (!entry) continue;
      if (entry instanceof ItemStack) {
        itemsToPlace.push(entry);
        continue;
      }
      let itemId = typeof entry === "string" ? entry : (entry.id || entry.typeId);
      let count = entry.count || entry.amount || 1;
      if (!itemId) continue;

      if (count > 4 && Math.random() < 0.75) {
        const half = Math.floor(count / 2);
        const rem = count - half;
        try { itemsToPlace.push(new ItemStack(itemId, half)); } catch (e) {}
        try { itemsToPlace.push(new ItemStack(itemId, rem)); } catch (e) {}
      } else {
        try {
          itemsToPlace.push(new ItemStack(itemId, count));
        } catch (e) {}
      }
    }

    // Place into randomized slots
    for (const stack of itemsToPlace) {
      if (availableSlots.length === 0) break;
      const slot = availableSlots.pop();
      try {
        if (container.getItem(slot)) container.addItem(stack); else container.setItem(slot, stack);
      } catch (e) {
        try { container.addItem(stack); } catch (e2) {}
      }
    }
  } catch (err) {}
}

// Finds players who broke the block or are near the island (radius 48 blocks) for clean multiplayer notifications
export function getNearbyIslandPlayers(dimension, loc, maxDistance = 48, breakerPlayer = null) {
  const nearby = new Set();
  if (breakerPlayer) nearby.add(breakerPlayer);
  try {
    for (const p of world.getAllPlayers()) {
      if (p.dimension.id === dimension.id) {
        const dx = p.location.x - loc.x;
        const dy = p.location.y - loc.y;
        const dz = p.location.z - loc.z;
        const dist = Math.sqrt(dx * dx + dy * dy + dz * dz);
        if (dist <= maxDistance) {
          nearby.add(p);
        }
      }
    }
  } catch (e) {}
  return Array.from(nearby);
}

let playerDimsTick = -1;
let playerDimsCache = null;

export function getPlayerDims() {
  const now = system.currentTick;
  if (playerDimsCache && now >= playerDimsTick && now - playerDimsTick < 5) return playerDimsCache;
  const active = { overworld: false, nether: false, end: false };
  try {
    for (const p of world.getAllPlayers()) {
      try { active[getDimKey(p.dimension.id)] = true; } catch (e) {}
    }
  } catch (e) {}
  playerDimsTick = now;
  playerDimsCache = active;

export function getIslandLocation(index, total, theme, lastPos = null) {
  const targetDim = (theme && theme.dimension) || "overworld";

  let distance;

    let slotIdx = -1;

      slotIdx = OVERWORLD_ISLAND_ORDER.indexOf(theme.id);
    }

      slotIdx = index % 33;
    }

      // Ring 1: 6 islands @ 72m (Offset 0°: 0°, 60°, 120°, 180°, 240°, 300° -> 0% diagonals, min diff 26m)
      distance = 72;

    } else if (slotIdx < 14) {

      distance = 125;
      angle = 22.5 + (slotIdx - 6) * (360 / 8);

      distance = 180;

    } else {
      // Ring 4: 9 islands @ 240m (Offset 0°: 0°, 40°, 80°, 120°... -> 0% diagonals, min diff 30m)

      angle = (slotIdx - 24) * (360 / 9);
    }

    const netherThemes = ISLAND_THEMES.filter(t => t.dimension === "nether");
    let nIdx = theme ? netherThemes.findIndex(t => t.id === theme.id) : index;
    if (nIdx < 0) nIdx = index % 7;

  } else {
    // The End (3 islands: end_city_tower, void_gateway_outpost, elytra_hangar @ 30°, 150°, 270°)
    const endThemes = ISLAND_THEMES.filter(t => t.dimension === "the_end");
    let eIdx = theme ? endThemes.findIndex(t => t.id === theme.id) : index;
    if (eIdx < 0) eIdx = index % 3;
    distance = 85;
    angle = 30 + eIdx * 120;
  }

  const rad = (angle * Math.PI) / 180;
  const cx = Math.round(distance * Math.cos(rad));
  const cz = Math.round(distance * Math.sin(rad));

  // Thematic Y Level: Skyblock height kept accessible (Y=60 to Y=72)
  const cy = (theme && typeof theme.y === "number") ? Math.min(72, Math.max(60, theme.y)) : 64;

  let cardinal = "North";
  if (Math.abs(cx) > Math.abs(cz)) {
    cardinal = cx > 0 ? "East" : "West";
  } else {
    cardinal = cz > 0 ? "South" : "North";
  }

  return {
    center: { x: cx, y: cy, z: cz },
    distance,
    cardinal: `${cardinal} (X: ${cx}, Z: ${cz})`
  };

    const stuckBedrock = !!block && block.typeId === "minecraft:bedrock";
    const isMissing = !block || block.isAir || block.typeId === "minecraft:air" || isLiquid || stuckBedrock;

    // A block that vanished without any break/explosion handler counting it within 3 ticks
    // (piston, plant pop, decay) counts as progress once. Player breaks are never double counted.
    const pend = mainPending.get(dimKey);
    if (pend !== undefined && system.currentTick - pend >= 3) {
      mainPending.delete(dimKey);
      if ((lastProgressTick.get(dimKey) ?? -99) < pend) incrementDimensionCount(dimKey, dimension);
    }

    if (isMissing) {
      if (block && !stuckBedrock && lastKnownOneBlockType[dimKey] && !mainPending.has(dimKey)) {
        mainPending.set(dimKey, system.currentTick);
      }
      renewOneBlock(dimension);
    } else if (block) {
      lastKnownOneBlockType[dimKey] = block.typeId;
    }
  } catch (err) {}
}

## Notes (AI review)

Island completion state: `island_ob_completed_<id>` = every core block mined, `island_ob_done_<id>` = floor, chest and message finished (set last, retried until it works), `island_ob_final_<id>` = kept for the Islands completed counter. Islands finished by an older version without `island_ob_done_` are checked once on load and repaired when the core still holds a mineable block or bedrock.

Background loops (`oneBlockRenewTick`, `islandHealthTick`, nether and end particles) skip dimensions without players. Island core positions are cached in memory and finished islands are only re-checked every 5 seconds, so `island_ob_x/y/z_<id>` must not be edited by hand while the script runs. The `getPlayerDims` helper in `lib/helpers.js` is memoized for 5 ticks.

function generateRandomTrades(dimKey) {
  const pool = DIMENSION_TRADE_POOLS[dimKey] || DIMENSION_TRADE_POOLS.overworld;

  for (let slot = 0; slot < 5; slot++) {
    const tierIdx = rollRarityTier();
    const tier = RARITY_TIERS[tierIdx];
    const itemData = pool[tierIdx];

    const cost = Math.floor(Math.random() * (tier.costMax - tier.costMin + 1)) + tier.costMin;
    const stock = tierIdx >= 16 ? 1 : Math.floor(Math.random() * 2) + 2;

    if (tierIdx >= 18) {
      hasMythicOrFabled = true;
    }

    trades.push({
      tierIdx,
      tierName: tier.name,
      tierColor: tier.color,
      currency: tier.currency,
      cost,
      itemId: itemData.id,
      itemCount: itemData.count,
      stock
    });
  }

}

      return;

    if (!selectedTrade) return;

      return;

      const item = inv.getItem(slot);

      player.sendMessage(`§c[Dimension Shifter] You need §e${selectedTrade.cost}x ${currName}§c, but you only have §e${availableCurrency}§c!`);

    player.dimension.spawnParticle("minecraft:totem_particle", player.location);
  });
