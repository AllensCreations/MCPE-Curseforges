### 1.3 Version Format and Manifests
**Manifest versioning (Bedrock engine format):** `header.version` MUST be a 3-integer array `[X, Y, Z]` (e.g. `[1, 0, 0]`, `[2, 0, 0]`); `metadata.version` MUST be the string `"X.Y.Z"` (e.g. `"1.0.0"`). The Bedrock engine rejects non-array values or strings like `"vX"` in manifests. NEVER use `vX` syntax inside any `manifest.json` field.
**Per-pack user-facing format:** Every user-visible reference to a version uses `vX` (a single whole number): pack title suffix `(vX)`, changelog headings `## [vX]`, package filenames `(Shortcut VX.ext)`, README download links, CurseForge/MCPEDL release names, snapshot folder prefix `V`. The two formats are strictly separate: manifests = `[X, 0, 0]` / `"X.0.0"`, everything the user sees = `vX`.
- Version = `vX` format (single whole number, e.g. `v2`, `v3`; Bedrock `header.version` maps to `[X, 0, 0]`; legacy `X.Y.Z` supported). NEVER `X.Y.Z.A`. No fourth part, no Alpha. Same version in `metadata.version`, `(vX)` titles, changelog headings, package names, README links, snapshots.

- Update: X+1 (v1 -> v2, v2 -> v3; legacy 1.2.3 converts to v2). Manifest title suffix equals version (e.g. `(v2)`).
- Manifest title = `Add-on Name (vX)` (e.g. `Vanilla Quality of Life (v2)`). Exactly one terminal suffix, equals `header.version` (or major integer), BP/RP match. NEVER duplicate suffixes. `scripts/validate_manifest_titles.py [--project <path>]` fails the job on violation (also notes non-fail: format_version != 2, missing/zero `min_engine_version`, missing `metadata.authors`).

- `header.description` contains `by ALNStudios` exactly once. NEVER attribution in title.
- NEVER change pack UUIDs or world storage keys to rename a title. NEVER regenerate header UUIDs (breaks worlds).
- Build sync: every processed project aligns all source manifests to one highest `X.Y.Z`: `header.version`, `metadata.version`, title suffix, module versions, same-project BP/RP deps. FORCES `metadata.authors` = `["ALNStudios"]` and `metadata.product_type` = `"addon"` in EVERY BP and RP manifest (new packs, updates, builds; NEVER another author or type), optional `metadata.license`. `product_type` `"addon"` is what keeps achievements allowed (owner-confirmed in game). The Bedrock Wiki says Mojang removed this in game 26.50 (MCPE-242529): if a newer game version shows achievements disabled, report it, do not hide it.
- Snapshots: `builds/<pack>/versions/V<X.Y.Z>/` (packages, `source.zip`, `source.sha256`, `build_info.json`). Refreshed when source/packages differ. Last 5 kept.
- NOTHING auto-bumps. The new version is written in CHANGELOG.md AND, in the same update script, into every source manifest with `python3 scripts/manifest_tools.py --project <path> --set vX` (header.version, metadata.version, title suffix, module and dependency versions; UUIDs untouched; never lowers)
, so every update changes the build. Publish to CurseForge uploads the newest changelog version as written and groups every entry since the last publish. The passive build (`Build Changed Packs & Sync Catalogs`) aligns each pack to its highest existing version and rebuilds. `--bump` / `AUTO_BUMP_MANIFEST=true` remain in `scripts/auto_bump_and_build.py` for manual use only.
- Package name: **`(<Shortcut> VX.<ext>)`** (example **`(MiningHelmet V1.mcaddon)`**, or legacy **`(<Shortcut> VX.Y.Z.<ext>)`**). Always format name references in bold with parentheses. Shortcut = short, letters and digits only (NEVER `-`, `_`, spaces, `by ALNStudios`), close to the add-on name, kept in `scripts/pack_shortcuts.json` by project folder (fallback: folder name joined). Custom via `metadata.package_filename` or `PACK_FILENAME_TEMPLATE`; MUST contain `V{version}` and no parenthesis in the file name itself, else the default is used. CurseForge upload copy uses the same name. `python3 scripts/rename_packages.py --check|--apply` renames old packages and repairs references.
- Creator name `ALNStudios`. `python3 scripts/rename_brand.py --apply` migrates old name. NEVER rename lowercase namespaces (`allenscreations:`).
- Tools: `python3 scripts/manifest_tools.py --project <path> --check|--align|--bump` (`--all --check`). `sync_manifest_versions.py`: deps and `min_engine_version` maintenance; set `min_engine_version` by hand after lookup. `sync_project_docs.py` NOT in build: edit DESCRIPTION/CHANGELOG deliberately. `sync_readme_links.py [--check]` repairs README links (runs after every build).
- LOCK: every `MCPEDL/Addons/` project has `LOCK` at root starting `ALNStudios Add-on Lock v1`. Importer creates it, build enforces it. Missing/invalid = release-blocking: report path, NEVER call build-ready. Safeguard only, not encryption.

### 1.12 Vanilla Limits and Workarounds
Applies to every addon, map, script, minigame, item, entity, block, trade, recipe and enchantment, new or updated.
- A hardcoded vanilla limit blocks the requested mechanic (examples: mutually exclusive enchantments, item, entity or component caps, trade or recipe limits) AND the standard approach (behavior JSON, commands, crafting, enchanting) fails: NEVER drop the feature silently. The standard approach works: use it, no workaround.
- Lightest workaround first. 1) Data-driven: custom item, block, entity, recipe, loot, trade, spawn rule, animation controller, tag, component. 2) `@minecraft/server`: custom components, events, ItemStack and Entity APIs, dynamic properties, tags or scoreboard for state. 3) Structural: helper or proxy entity, swapped or replaced item or entity, tiered item variants, `.mcstructure` or template placement, function-driven effects.
- NEVER invent an API, component, event or behavior. Use only what the looked-up stable version (1.2) provides and the repo scripts accept. Cannot verify: say so in DESCRIPTION.md.
- Modular: one small file per workaround with one entry point (script: `behavior_pack/scripts/lib/<name>.js` imported relatively; data: its own function file, entity or item definition). Reuse an existing module. NEVER copy the logic per feature.
- Safe: idempotent setup, caps and cleanup for spawned entities and loops, nothing that corrupts worlds or other packs.
- Conflict Prevention & Isolation:
  1. Custom namespace isolation: Always prefix custom items, blocks, and entities with `aln:<name>` (e.g. `aln:<minigame_name>_controller`).
  2. Avoid Vanilla Entity Overrides: Overriding vanilla entity JSON files (e.g. `entities/zombie.json`) completely wipes out other addons modifying the same entity in Bedrock's load order. Whenever possible, hook into vanilla entity mechanics using `@minecraft/server` Script API event subscriptions (`world.afterEvents.entityDie`, `playerInteractWithEntity`, `entityHurt`, etc.) rather than replacing the vanilla entity JSON.
- Structural NBT & .mcstructure: When a mechanic requires pre-built templates or saved blocks/entities, place `.mcstructure` and `.nbt` files strictly under `behavior_pack/structures/` (or an optional namespace subfolder like `behavior_pack/structures/aln/<name>.mcstructure`). These files must be generated only by code or exported from Bedrock tools (never hand-written arbitrary bytes). Shipped files must contain no comments, obey the 2 MB per-file size cap, and be stated as "not tested in game" until verified in Minecraft.

- Docs (`DOCS_RULES.md`): player-facing result only, no code or API names; the trade-off under Good To Know. State achievement and experiment impact per 1.2.

After the update script runs, the user runs: `python3 <project>/sound_sources/make_sounds.py`, then `git add`, `commit`, `push`.

### 1.16 Bedrock Developer Role and Trusted Sources
- Role: expert Minecraft Bedrock Add-on and Script API developer. Build and maintain complete Behavior Packs, Resource Packs and Script API modules. - Version = `vX` format (single whole number, e.g. `v2`, `v3`; Bedrock `header.version` maps to `[X, 0, 0]`; legacy `X.Y.Z` supported). NEVER `X.Y.Z.A`. No fourth part, no Alpha. Same version in `metadata.version`, `(vX)` titles, changelog headings, package names, README links, snapshots.

### 4.13 Pixel textures (custom item and block art)
- The ONLY way to draw new art: pixel JSON, rendered to PNG by `scripts/pixel_json_to_png.py`. NEVER AI-generated images, NEVER copied or guessed art. A vanilla look = use the real vanilla texture name instead. NEVER for `script` projects (no resource_pack).
- Source: `texture_sources/<any>.json` = array of textures. NEVER inside `resource_pack/`. No comments.
- One texture: `{"name": "shepherds_pie", "size": 64, "palette": {"0": "#00000000", "1": "#3d2817"}, "pixels": [[0, 0, 1, ...], ...]}`
- `name`: lowercase letters, digits, `_`. It is the PNG name, the key in `resource_pack/textures/item_texture.json` and the item's `minecraft:icon`. ALWAYS register it there.
- `size`: 64 standard for richer detail and styling freedom (16, 32 or 128 allowed when requested). `pixels` = exactly `size` rows of exactly `size` palette indexes.
- `palette`: keys are numbers in quotes, `"0"` = `#00000000` (transparent). Values `#RRGGBB` or `#RRGGBBAA`. Every index used MUST exist in the palette. Max 12 colors.
- Optional `folder`: `items` (default), `blocks` or `items/<sub>`. The PNG goes to `resource_pack/textures/<folder>/<name>.png`.
- Style: Minecraft pixel art, clean outlines, depth, light from the top left, no gradients, no blurry anti-aliasing, styled for 64x64 high detail. Recolors share one grid with a different palette.
- RUN `python3 pixel_json_to_png.py build/<Name>` BEFORE `make_pack_script.py` (4.8): it checks every texture, lists every problem together and writes the PNGs. Fix, rerun. NEVER hand-write a PNG or base64.
- Ship the JSON AND the PNGs. The JSON is the source: later changes edit the JSON and rerun the script, NEVER the PNG. `--preview [file]` writes a review sheet outside the project: NEVER ship it.

### 4.14 Custom Sounds
- Audio files cannot travel inside a spec or pack script. A project that needs custom sounds keeps a pure-Python synthesizer at `<project>/sound_sources/make_sounds.py` (reference: `MCPEDL/Addons/ALNSpiritSphere/sound_sources/make_sounds.py`). It writes `.ogg` files into `<project>/resource_pack/sounds/` and needs ffmpeg (Termux: `pkg install ffmpeg`).
- An update that adds sounds uses `@@ create` for `make_sounds.py` and `resource_pack/sounds/sound_definitions.json` (`format_version` 1.14.0, one event per sound, sound paths without extension, category neutral). After the update script runs, the user runs: `python3 <project>/sound_sources/make_sounds.py`, then `git add`, `commit`, `push`.
- Sound event ids use the pattern `aln.<project>.<element>.<kind>` and are played from scripts with `playSound`. NEVER guess vanilla sound ids; use only ids verified through Context7.
- New sound files need a full Minecraft client restart to load. Say so in the handoff.
- `.ogg` is the only audio type allowed. `DESCRIPTION.md` must describe sounds in player terms and never name the script, ffmpeg or file names.

export function poolFor(d) {
  const pool = [];
  for (const L of LICENSES) {
    if (!hasLic(d, L.id)) continue;
    for (const [b, w] of Object.entries(L.blocks)) {
      if (usable(full(b)) && w > 0) pool.push([full(b), w]);
    }
  }
  if (!pool.length) return [["minecraft:dirt", 1]];
  // Dirt floor: keep Dirt at a minimum share so rarer blocks cannot crowd it out.
  const i = pool.findIndex((e) => e[0] === "minecraft:dirt");
  if (i >= 0) {
    const others = pool.reduce((s, e, k) => (k === i ? s : s + e[1]), 0);
    pool[i][1] = Math.max(pool[i][1], Math.ceil((others * DIRT_SHARE) / (1 - DIRT_SHARE)));
  }
  return pool;
}

  return pool[0][0];
}

  core.jackpot = false;
  let chest = false, bonus = false;
  if (d && !auto && d.bonus) {
    // Milestone reward: the next OneBlock is a bonus loot chest.
    chest = true; bonus = true;
    d.bonus = false;
    savePlayer(player, d);
  } else if (d && !auto && Math.random() < JACKPOT_CHANCE) {
    id = "minecraft:gold_block";
    core.jackpot = true;
  } else if (d && d.con.includes("basic") && Math.random() < BASIC_CHEST_CHANCE * ((d.up && d.up.basic) || 1)) {
    // Basic Supply Chest contract: the OneBlock sometimes turns into a loot chest instead of a block.
    chest = true;
  }
  if (chest) id = "minecraft:chest";
  try { b.setType(id); } catch (e) {
    chest = false; bonus = false; core.jackpot = false;
    try { b.setType("minecraft:dirt"); } catch (e2) { return false; }
  }
  if (chest) { try { fillOneBlockChest(b, d, bonus); } catch (e) { console.warn("[SovereignMarket] oneblock chest: " + e); } }
  if (core.jackpot && player) { try { player.onScreenDisplay.setActionBar("\u00a76JACKPOT block! Break it for coins."); } catch (e) { /* ignore */ } }
  core.armed = true;
  core.pending = false;
  return true;
}

// Fills a chest-shaped OneBlock. Bonus chests roll the loot of every contract the player's licenses allow.
function fillOneBlockChest(block, d, bonus) {
  let entries, rolls;
  if (bonus) {
    entries = CONTRACTS.flatMap((c) => c.loot).filter((x) => hasLic(d, x[4]) && BlockOrItemOk(x[0]));
    rolls = rnd(6, 8);
  } else {
    const C = CONTRACTS.find((c) => c.id === "basic");
    const lvl = (d.up && d.up.basic) || 1;
    entries = C.loot.filter((x) => hasLic(d, x[4]) && BlockOrItemOk(x[0]));
    rolls = rnd(C.rolls[0] + lvl - 1, C.rolls[1] + lvl - 1);
  }
  const cont = block.getComponent("minecraft:inventory")?.container;
  if (!cont || !entries.length) return;
  const total = entries.reduce((sum, e) => sum + e[1], 0);
  for (let r = 0; r < rolls; r++) {
    let pick = Math.random() * total, e = entries[0];
    for (const c of entries) { pick -= c[1]; if (pick < 0) { e = c; break; } }
    const slot = rnd(0, cont.size - 1);
    if (cont.getItem(slot)) continue;
    cont.setItem(slot, new ItemStack(full(e[0]), rnd(e[2], e[3])));
  }
}

// Recovery: re-arm after reloads, regenerate if the core vanished (only once a player finished setup).
export function coreWatch() {
  const ready = world.getAllPlayers().some((p) => p.hasTag("void_cleaned") && p.dimension.id === "minecraft:overworld");
  if (!ready) return;
  const b = dimOf().getBlock(CORE);
  if (!b) return;
  if (!b.isAir) { core.armed = true; core.pending = false; return; }
  if (!core.pending) {
    core.pending = true;
    system.run(() => {
      let ok = false;
      try { ok = regenerate(null); } catch (e) { console.warn("[SovereignMarket] regenerate: " + e); }
      if (!ok) core.pending = false;
    });
  }
}


// ---- Auto-Miner (permanent levels, 2 minutes per Minecraft day) ----
const currentDay = () => world.getDay();

// Cached record: undefined = not loaded yet, null = not owned. The per-tick check reads only this variable.
let autoCache;
let autoWait = 0; // ticks since the last Auto-Miner break; a missed break is retried on the next tick
function autoState() {
  if (autoCache === undefined) {
    const a = loadWorld().autoMine;
    autoCache = a && a.lvl ? a : null;
  }
  return autoCache;
}
function persistAuto() {
  const w = loadWorld();
  w.autoMine = autoCache || null;
  saveWorld(w);
}
function rolloverAuto(a) {
  const day = currentDay();
  if (a.day === day) return;
  a.day = day; a.used = 0; a.msg = false; a.full = false;
  persistAuto();
}

export function autoStatus() {
  const a = autoState();
  if (a) rolloverAuto(a);
  const level = a ? a.lvl : 0;
  const used = a ? a.used || 0 : 0;
  return {
    level,
    on: !!a && a.on !== false,
    step: level ? AUTO_LEVELS[level - 1].step : 0,
    next: AUTO_LEVELS[level] || null,
    leftSecs: Math.ceil(Math.max(0, AUTO_DAILY_TICKS - used) / 20),
  };
}

export function buyAutoLevel(p) {
  const a = autoState();
  const level = a ? a.lvl : 0;
  const nxt = AUTO_LEVELS[level];
  if (!nxt) return { ok: false, msg: "The Auto-Miner is already at the maximum level." };
  const d = loadPlayer(p);
  if (!spend(d, nxt.cost)) return { ok: false, msg: "Not enough " + CURRENCY + ". You need " + nxt.cost + ", you have " + d.coins + "." };
  autoCache = { lvl: level + 1, on: a ? a.on !== false : true, day: a ? a.day : currentDay(), used: a ? a.used || 0 : 0, msg: a ? !!a.msg : false, full: false };
  log(d, "Bought " + nxt.name + " Auto-Miner for " + nxt.cost);
  savePlayer(p, d);
  persistAuto();
  return { ok: true, msg: nxt.name + " Auto-Miner ready: it breaks the OneBlock every " + nxt.step + " tick" + (nxt.step === 1 ? "" : "s") + ", about 2 minutes per Minecraft day. Balance: " + d.coins + " " + CURRENCY };
}

export function toggleAuto(p) {
  const a = autoState();
  if (!a) return { ok: false, msg: "You do not own the Auto-Miner yet." };
  a.on = a.on === false;
  persistAuto();
  if (a.on) {
    // Break the OneBlock right away so the player sees it start.
    rolloverAuto(a);
    // The instant break uses the same daily time as a normal break, so toggling cannot give free breaks.
    if ((a.used || 0) < AUTO_DAILY_TICKS) {
      let broke = false;
      try { broke = mineOnce(p, a, true); } catch (e) { /* ignore */ }
      if (broke) {
        autoWait = 0;
        a.used = Math.min(AUTO_DAILY_TICKS, (a.used || 0) + AUTO_LEVELS[a.lvl - 1].step);
        persistAuto();
      }
    }
  }
  return { ok: true, msg: "Auto-Miner is now " + (a.on ? "ON" : "OFF") + "." };
}

function storeAutoDrop(container, blockId) {
  let stack;
  try { stack = new ItemStack(AUTO_DROPS[blockId] || blockId, 1); } catch (e) { return true; } // no item form: skip it so the miner never stalls
  for (let i = 0; i < container.size; i++) {
    const old = container.getItem(i);
    if (old && old.typeId === stack.typeId && old.amount < old.maxAmount) {
      const moved = Math.min(stack.amount, old.maxAmount - old.amount);
      old.amount += moved;
      stack.amount -= moved;
      container.setItem(i, old);
      if (stack.amount <= 0) return true;
    }
  }
  for (let i = 0; i < container.size; i++) {
    if (!container.getItem(i)) { container.setItem(i, stack); return true; }
  }
  return false;
}

// Moves everything from a chest-shaped OneBlock into the collection chest. False if the collection chest is full.
function moveChestLoot(coreBlock, dest) {
  const inv = coreBlock.getComponent("minecraft:inventory")?.container;
  if (!inv) return true;
  for (let i = 0; i < inv.size; i++) {
    const it = inv.getItem(i);
    if (!it) continue;
    const left = dest.addItem(it);
    inv.setItem(i, left);
    if (left) return false;
  }
  return true;
}

// Break animation: a real "destroy" setblock plays the crack particles and sound. Its item drops are removed,
// because what the OneBlock held was already stored in the collection chest.
function breakEffect(dim) {
  try { dim.runCommand("setblock " + CORE.x + " " + CORE.y + " " + CORE.z + " air destroy"); } catch (e) { return; }
  const sweep = () => {
    try {
      for (const e of dim.getEntities({ type: "minecraft:item", location: { x: CORE.x + 0.5, y: CORE.y + 0.5, z: CORE.z + 0.5 }, maxDistance: 1.5 })) e.remove();
    } catch (e) { /* ignore */ }
  };
  sweep();
  system.run(sweep);
}

let lastHint = -1000;
function hint(player, text) {
  if (system.currentTick - lastHint < 100) return;
  lastHint = system.currentTick;
  try { player.onScreenDisplay.setActionBar("\u00a7c" + text); player.sendMessage("\u00a7c" + text); } catch (e) { /* ignore */ }
}

function mineOnce(player, a, fx) {
  if (core.pending) return; // works on whatever block is at the OneBlock position, no earlier hand break needed
  const dim = dimOf();
  let chestBlock = dim.getBlock({ x: CORE.x, y: CORE.y + 1, z: CORE.z });
  if (!chestBlock) return;
  if (chestBlock.typeId !== "minecraft:chest") {
    if (!chestBlock.isAir) { hint(player, "Auto-Miner: the block above the OneBlock must be empty so the collection chest can go there. Remove it."); return; }
    try { chestBlock.setType("minecraft:chest"); } catch (e) { return; }
    chestBlock = dim.getBlock({ x: CORE.x, y: CORE.y + 1, z: CORE.z });
  }
  const container = chestBlock?.getComponent("minecraft:inventory")?.container;
  const coreBlock = dim.getBlock(CORE);
  if (!container || !coreBlock || coreBlock.isAir) return;
  const stored = coreBlock.typeId === "minecraft:chest" ? moveChestLoot(coreBlock, container) : storeAutoDrop(container, coreBlock.typeId);
  if (!stored) {
    if (!a.full) {
      a.full = true;
      persistAuto();
      try { player.sendMessage("Auto-Miner paused: the collection chest above the OneBlock is full. Empty it to resume."); } catch (e) { /* ignore */ }
    }
    return;
  }
  a.full = false;
  core.armed = false;
  core.pending = true;
  if (fx) breakEffect(dim);
  if (!regenerate(player, true)) { core.pending = false; return false; }
  return true;
}

function announceExhausted(player, a) {
  a.msg = true;
  persistAuto();
  try {
    player.sendMessage("\u00a7cAuto-mining is exhausted. It recharges when the next Minecraft day begins.");
    player.onScreenDisplay.setActionBar("\u00a7cAuto-mining exhausted");
  } catch (e) { /* ignore */ }
}

export function autoMineTick() {
  const a = autoState();
  if (!a || a.on === false) return; // idle: no world read, no player scan
  rolloverAuto(a);
  if ((a.used || 0) >= AUTO_DAILY_TICKS && a.msg) return;
  // Any player in the Overworld is enough: the miner works on whatever OneBlock is there, no setup tag needed.
  const player = world.getAllPlayers().find((p) => p.dimension.id === "minecraft:overworld");
  if (!player) return;
  if ((a.used || 0) >= AUTO_DAILY_TICKS) { announceExhausted(player, a); return; }
  if (a.full) {
    // Paused because the collection chest is full: mining time does not run, and the next break happens the moment there is room.
    if (mineOnce(player, a, true)) autoWait = 0;
    return;
  }
  a.used = (a.used || 0) + 1;
  if (a.used % 20 === 0) persistAuto();
  const step = AUTO_LEVELS[a.lvl - 1].step;
  if (a.used % 10 === 1) { try { player.onScreenDisplay.setActionBar("\u00a7b" + AUTO_LEVELS[a.lvl - 1].name + " Auto-Miner   " + Math.ceil((AUTO_DAILY_TICKS - a.used) / 20) + "s left"); } catch (e) { /* ignore */ } }
  // Every break plays the block-destroy effect.
  autoWait++;
  if (autoWait >= step && mineOnce(player, a, true)) autoWait = 0;
  if (a.used >= AUTO_DAILY_TICKS) announceExhausted(player, a);
}

// Called for every hand break of the OneBlock. Dirt no longer pays: items are sold at the market.
// Handles the jackpot block and the milestone bonus.
export function onHandBreak(p, typeId) {
  const d = loadPlayer(p);
  d.mined += 1;
  const tier = highestTier(d);
  const notes = [];
  if (core.jackpot && typeId === "minecraft:gold_block") {
    const amt = rnd(JACKPOT_MIN_PER_TIER * tier, JACKPOT_MAX_PER_TIER * tier);
    addCoins(d, amt);
    log(d, "Jackpot block: +" + amt);
    notes.push("\u00a76JACKPOT! +" + amt + " " + CURRENCY);
  }
  if (d.mined % MILESTONE_EVERY === 0) {
    const c = MILESTONE_COINS_PER_TIER * tier;
    addCoins(d, c);
    d.bonus = true;
    log(d, "Milestone " + d.mined + " breaks: +" + c);
    notes.push("\u00a7aMilestone: " + d.mined + " breaks! +" + c + " " + CURRENCY + ". Your next OneBlock is a bonus chest.");
  }
  savePlayer(p, d);
  for (const n of notes) { try { p.sendMessage(n); p.onScreenDisplay.setActionBar(n); } catch (e) { /* ignore */ } }
}

// ---- Selling ----
const plain = (it) => !it.nameTag && it.getLore().length === 0;
export function inventoryCounts(p) {
  const c = p.getComponent("minecraft:inventory").container;
  const m = new Map();
  for (let i = 0; i < c.size; i++) {
    const it = c.getItem(i);
    if (it && ITEMS.has(it.typeId) && plain(it)) m.set(it.typeId, (m.get(it.typeId) || 0) + it.amount);
  }
  return m;
}
function removeItems(p, id, qty) {
  const c = p.getComponent("minecraft:inventory").container;
  let left = qty;
  for (let i = 0; i < c.size && left > 0; i++) {
    const it = c.getItem(i);
    if (!it || it.typeId !== id || !plain(it)) continue;
    const take = Math.min(left, it.amount);
    if (take === it.amount) c.setItem(i, undefined);
    else { it.amount -= take; c.setItem(i, it); }
    left -= take;
  }
  return qty - left;
}
export function sell(p, id, qty) {
  const it = ITEMS.get(id);
  const d = loadPlayer(p);
  if (!it) return { ok: false, msg: "The market does not buy that item." };
  if (!hasLic(d, it.lic)) return { ok: false, msg: "You need " + LICENSES.find((l) => l.id === it.lic).name + " to trade this item." };
  if (!Number.isSafeInteger(qty) || qty < 1) return { ok: false, msg: "Invalid quantity." };
  const have = inventoryCounts(p).get(id) || 0;
  if (have < qty) return { ok: false, msg: "You only have " + have + " of that item now. Nothing was sold." };
  const removed = removeItems(p, id, qty);
  if (removed < 1) return { ok: false, msg: "Could not remove items. Nothing was sold." };
  const w = loadWorld();
  const q = quote(w, id, removed);
  const before = q.unit;
  addCoins(d, q.total);
  recordSale(w, id, removed);
  const after = quote(w, id, 1).unit;
  log(d, "Sold " + removed + " " + nice(id) + " for " + q.total);
  d.sold = (d.sold || 0) + removed;
  if (d.sold >= 1000) grantAch(p, d, "sell_1000");
  savePlayer(p, d);
  saveWorld(w);
  return { ok: true, msg: "Receipt: sold " + removed + " " + nice(id) + " for " + q.total + " " + CURRENCY + ".\nMarket price: " + Math.round(before * 10) / 10 + " -> " + Math.round(after * 10) / 10 + " each.\nBalance: " + d.coins + " " + CURRENCY };
}

// ---- Island expansion ----
export function buyIsland(p, targetIdx) {
  const w = loadWorld();
  const d = loadPlayer(p);
  const cur = Math.min(Math.max(0, w.lvl | 0), ISLAND_LEVELS.length - 1);
  if (targetIdx !== cur + 1 || !ISLAND_LEVELS[targetIdx]) return { ok: false, msg: "That permit is no longer available. Nothing was charged." };
  const N = ISLAND_LEVELS[targetIdx];
  const O = ISLAND_LEVELS[cur];
  if (!canAfford(d, N.cost)) return { ok: false, msg: "Not enough " + CURRENCY + ". You need " + N.cost + ", you have " + d.coins + "." };
  const dim = dimOf();
  // Every block of the new border must be loaded, or the ring would be drawn only in part after the coins are taken.
  for (let i = N.min - 1; i <= N.max + 1; i++) {
    if (![[i, N.min - 1], [i, N.max + 1], [N.min - 1, i], [N.max + 1, i]].every(([x, z]) => dim.getBlock({ x, y: FLOOR_Y, z }))) return { ok: false, msg: "The new area is not loaded. Stand near the OneBlock and try again. Nothing was charged." };
  }
  // Only the border is drawn: the old border is removed and a new ring is placed just outside the new area.
  // Nothing inside the area is filled, so players build their own land.
  // o = 1 gives the ring just outside the permitted area, where players cannot break or place blocks.
  const edges = (L, o = 0) => { const lo = L.min - o, hi = L.max + o; return [[lo, lo, hi, lo], [lo, hi, hi, hi], [lo, lo + 1, lo, hi - 1], [hi, lo + 1, hi, hi - 1]]; };
  for (const [x1, z1, x2, z2] of [...edges(O), ...edges(O, 1)]) {
    try { dim.runCommand("fill " + x1 + " " + FLOOR_Y + " " + z1 + " " + x2 + " " + FLOOR_Y + " " + z2 + " air replace " + BORDER_BLOCK); } catch (e) { /* no old border here */ }
  }
  for (const [x1, z1, x2, z2] of edges(N, 1)) {
    for (const under of ["air", "grass_block"]) {
      try { dim.runCommand("fill " + x1 + " " + FLOOR_Y + " " + z1 + " " + x2 + " " + FLOOR_Y + " " + z2 + " " + BORDER_BLOCK + " replace " + under); } catch (e) { /* nothing to replace */ }
    }
  }
  spend(d, N.cost);
  w.lvl = targetIdx;
  log(d, "Bought " + N.name + " (" + N.size + "x" + N.size + ") for " + N.cost);
  if (targetIdx === ISLAND_LEVELS.length - 1) grantAch(p, d, "island_max");
  savePlayer(p, d);
  saveWorld(w);
  return { ok: true, msg: N.name + " granted. Your island may now be built on up to " + N.size + " x " + N.size + " blocks around the OneBlock. Balance: " + d.coins + " " + CURRENCY };
}

// ---- Loot contracts ----
export function buyContract(p, id) {
  const C = CONTRACTS.find((c) => c.id === id);
  const d = loadPlayer(p);
  if (!C) return { ok: false, msg: "Unknown contract." };
  if (d.con.includes(id)) return { ok: false, msg: C.name + " is already active. You were not charged." };
  if (!hasLic(d, C.req)) return { ok: false, msg: "Requires " + LICENSES.find((l) => l.id === C.req).name + "." };
  if (!spend(d, C.cost)) return { ok: false, msg: "Not enough " + CURRENCY + ". You need " + C.cost + ", you have " + d.coins + "." };

  grantAch(p, d, "first_contract");
  savePlayer(p, d);
  nextAt.set(p.id + ":" + id, Date.now() + C.intervalMs);
  return { ok: true, msg: C.name + " is active. Chests will appear on your island over time. Balance: " + d.coins + " " + CURRENCY };
}
export function cancelContract(p, id) {
  const d = loadPlayer(p);
  if (!d.con.includes(id)) return { ok: false, msg: "That contract is not active." };
  d.con = d.con.filter((c) => c !== id);
  log(d, "Cancelled " + CONTRACTS.find((c) => c.id === id).name);
  savePlayer(p, d);
  return { ok: true, msg: "Contract cancelled. No refund is issued." };
}

const nextAt = new Map();
function trySpawn(p, C, d) {
  const dim = dimOf();
  const w = loadWorld();
  // Drop records for chests that no longer exist; keep records whose area is unloaded.
  w.chests = w.chests.filter((r) => { const b = dim.getBlock({ x: r.x, y: r.y, z: r.z }); return !b || b.typeId === "minecraft:chest"; });
  if (w.chests.filter((r) => r.o === p.id).length >= MAX_CHESTS_PER_PLAYER) { saveWorld(w); return false; }
  const L = ISLAND_LEVELS[islandLevel()];
  const options = (C.biomes ? C.biomes : [{ name: C.name, loot: C.loot }]).map((b) => ({ b, e: b.loot.filter((x) => hasLic(d, x[4]) && BlockOrItemOk(x[0])) })).filter((o) => o.e.length);
  if (!options.length) return false;
  const pick = options[rnd(0, options.length - 1)];
  const entries = pick.e;
  const label = C.biomes ? pick.b.name + " Biome Chest" : C.name;
  for (let t = 0; t < 40; t++) {
    const x = rnd(L.min, L.max), z = rnd(L.min, L.max);
    if (x === CORE.x && z === CORE.z) continue;
    const floor = dim.getBlock({ x, y: FLOOR_Y, z });
    const spot = dim.getBlock({ x, y: FLOOR_Y + 1, z });
    const above = dim.getBlock({ x, y: FLOOR_Y + 2, z });
    if (!floor || !spot || !above) continue;

// Alias for backward compatibility
export const ONEBLOCK_PROGRESSION = ONEBLOCK_PROGRESSION_POOLS;

/** Unlock mode: share of total weight given to the newest phase. Ramps from START (phase 2) to END (last phase). */
const CURRENT_SHARE_START = 0.4;
const CURRENT_SHARE_END = 0.6;

/** Mob tags skipped by default when sampling mobs. Pass { excludeTags: [] } to allow everything. */
const DEFAULT_MOB_EXCLUDE_TAGS = ["aquatic", "boss"];

/**
 * Pure Data Pool Accessor
 * Only provides sampling and lookup against the pools.
 * Pack rules (spawn rates, mechanics) are implemented by the pack.
 */
export class OneblockPoolProvider {
  /**
   * @param {PhaseDataPool[]} [pools]
   */
  constructor(pools = ONEBLOCK_PROGRESSION_POOLS) {
    this.pools = pools;
    this._unlockCache = new Map();
  }

  /**
   * Get phase data pool by 1-based number
   * @param {number} phaseNumber
   * @returns {PhaseDataPool}
   */
  getPhasePool(phaseNumber) {
    const clampedIndex = Math.max(1, Math.min(phaseNumber, this.pools.length)) - 1;
    return this.pools[clampedIndex];
  }

  /**
   * Calculate milestone phase from broken block count
   * @param {number} totalBreaks
   * @returns {{ phase: PhaseDataPool, phaseIndex: number, phaseBreaks: number, isLastPhase: boolean }}
   */
  getPhaseFromBreaks(totalBreaks) {
    let accumulated = 0;
    for (let i = 0; i < this.pools.length; i++) {
      const p = this.pools[i];
      if (totalBreaks < accumulated + p.blocksRequired) {
        return {
          phase: p,
          phaseIndex: i + 1,
          phaseBreaks: totalBreaks - accumulated,
          isLastPhase: false
        };
      }
      accumulated += p.blocksRequired;
    }
    const last = this.pools[this.pools.length - 1];
    return {
      phase: last,
      phaseIndex: this.pools.length,
      phaseBreaks: totalBreaks - accumulated,
      isLastPhase: true
    };
  }

  /**
   * Pick random item from a weighted pool
   * @template {{ weight: number }} T
   * @param {T[]} pool
   * @returns {T}
   */
  static sampleWeighted(pool) {
    const totalWeight = pool.reduce((sum, item) => sum + item.weight, 0);
    let rand = Math.random() * totalWeight;
    for (const item of pool) {
      if (rand < item.weight) return item;
      rand -= item.weight;
    }
    return pool[pool.length - 1];
  }

  /**
   * Cumulative "unlock" pool: everything introduced in phases 1..phaseNumber.
   * The current phase gets `currentShare` of the total weight so new content
   * feels fresh; the remainder is split evenly across earlier phases.
   * Duplicate ids are merged. Returns new objects; shared pools are never mutated.
   * @param {number} phaseNumber - 1-based phase (clamped; also valid past the last phase)
   * @param {"blocks"|"chests"|"mobs"} kind
   * @param {number} [currentShare] - 0..1 share for the current phase
   * @returns {Array<{ id: string, weight: number, min?: number, max?: number }>}
   */
  getUnlockedPool(phaseNumber, kind, currentShare) {
    const upto = Math.max(1, Math.min(Math.floor(phaseNumber) || 1, this.pools.length));
    if (currentShare === undefined) {
      const t = (upto - 1) / Math.max(1, this.pools.length - 1);
      currentShare = CURRENT_SHARE_START + (CURRENT_SHARE_END - CURRENT_SHARE_START) * t;
    }
    const key = `${kind}:${upto}:${currentShare}`;
    const cached = this._unlockCache.get(key);
    if (cached) return cached;

    const merged = new Map();
    for (let i = 0; i < upto; i++) {
      const list = this.pools[i][kind];
      const sum = list.reduce((s, e) => s + e.weight, 0);
      const share = upto === 1 ? 1 : (i === upto - 1 ? currentShare : (1 - currentShare) / (upto - 1));
      for (const e of list) {
        const w = (e.weight / sum) * share * 100;
        const prev = merged.get(e.id);
        if (!prev) {
          merged.set(e.id, { ...e, weight: w });
        } else {
          prev.weight += w;
          if (kind === "chests") {
            prev.min = Math.min(prev.min, e.min);
            prev.max = Math.max(prev.max, e.max);
          }
        }
      }
    }
    const out = [...merged.values()];
    this._unlockCache.set(key, out);
    return out;
  }

  /**
   * Resolve the pool to sample from.
   * Default = unlock mode (earlier phases stay available). `exclusive: true` = this phase only.
   */
  _resolvePool(phaseNumber, kind, options = {}) {
    const pool = options.exclusive
      ? this.getPhasePool(phaseNumber)[kind]
      : this.getUnlockedPool(phaseNumber, kind, options.currentShare);
    if (kind !== "mobs") return pool;
    const skip = options.excludeTags ?? DEFAULT_MOB_EXCLUDE_TAGS;
    if (!skip.length) return pool;
    const allowed = pool.filter((m) => !(m.tags ?? []).some((t) => skip.includes(t)));
    return allowed.length ? allowed : pool;
  }

  /** Sample a block (unlock mode by default) */
  sampleBlock(phaseNumber, options) {
    return OneblockPoolProvider.sampleWeighted(this._resolvePool(phaseNumber, "blocks", options));
  }

  /** Sample a chest item (unlock mode by default) */
  sampleChestItem(phaseNumber, options) {
    return OneblockPoolProvider.sampleWeighted(this._resolvePool(phaseNumber, "chests", options));
  }

  /** Sample a mob (unlock mode by default) */
  sampleMob(phaseNumber, options) {
    return OneblockPoolProvider.sampleWeighted(this._resolvePool(phaseNumber, "mobs", options));
  }
}

// Backward-compatible alias
export const OneBlockProgressionManager = OneblockPoolProvider;

const decayed = (rec, now) => (rec ? rec.s * Math.pow(0.5, Math.max(0, (now - rec.t) / (C.halfLifeMin * 60000))) : 0);

export function demandState(cat, now = Date.now()) {
  const b = Math.floor(now / C.rotateMs);
  const hot = CATS[(b * 5 + 3) % CATS.length];
  let cold = CATS[(b * 7 + 1) % CATS.length];
  if (cold === hot) cold = CATS[(b * 7 + 2) % CATS.length];
  if (cat === hot) return { m: C.hot, label: "High" };
  if (cat === cold) return { m: C.cold, label: "Low" };
  return { m: 1, label: "Normal" };
}

const unit = (it, S, dm) => Math.min(it.max, Math.max(it.min, (it.base * dm) / (1 + S / C.depth)));

// Marginal pricing: each extra unit is priced at higher supply, so splitting a sale never beats one big sale.
export function quote(w, itemId, qty, now = Date.now()) {
  const it = ITEMS.get(itemId);
  if (!it || !Number.isSafeInteger(qty) || qty < 1) return null;
  const S = decayed(w.market[itemId], now);
  const dm = demandState(it.cat, now).m;
  let sum = 0;
  for (let i = 0; i < qty; i++) sum += unit(it, S + i, dm);
  return { total: Math.max(1, Math.floor(sum)), unit: unit(it, S, dm) };
}

export function recordSale(w, itemId, qty, now = Date.now()) {
  const it = ITEMS.get(itemId);
  const S = Math.min(C.maxSupply, decayed(w.market[itemId], now) + qty);
  w.market[itemId] = { s: Math.round(S * 100) / 100, t: now, p: Math.round(unit(it, S, demandState(it.cat, now).m) * 100) / 100 };
}

export function snapshot(w, itemId, now = Date.now()) {
  const it = ITEMS.get(itemId);
  const rec = w.market[itemId];
  const S = decayed(rec, now);
  const dem = demandState(it.cat, now);
  const price = unit(it, S, dem.m);
  const supply = S < 15 ? "Low" : S < C.depth ? "Moderate" : "High";
  let dir = "Stable";
  if (rec && price > rec.p * 1.02) dir = "Rising";
  else if (rec && price < rec.p * 0.98) dir = "Falling";
  const drop = Math.round((1 - 1 / (1 + S / C.depth)) * 100);
  const why = (S < 1 ? "No recent sales." : "Recent sales cut the price by " + drop + " percent, easing as supply clears.") +
    (dem.label === "High" ? " Demand is high (+25 percent)." : dem.label === "Low" ? " Demand is low (-15 percent)." : "");
  return { price, supply, demand: dem.label, dir, why };
}

## Overview

OneBlock Sovereign Market places you on an initial 9x9 void island with a single regenerative block. Mine the block to gather baseline materials, sell your yield through the Trader's Ledger for currency, and unlock progressively advanced resources. As your economy grows, purchase island expansion permits to push your territorial borders outward and set up automated harvesters that continue extraction without manual grinding.

Every transaction interacts with an active supply-and-demand curve. Liquid hazards and void falls are cleanly managed by built-in cleanup routines, ensuring reliable performance in both single-player survival and multiplayer worlds.

## Key Features

### Trader's Ledger & Market Economy
- **What Happens**: Access the centralized market directly from your inventory using the Trader's Ledger. Sell items for currency, purchase block licenses, activate resource contracts, and acquire island expansion permits.
- **Dynamic Pricing**: Market prices adjust dynamically based on recent sales and scheduled demand shifts, encouraging diverse resource production.

### Progressive Resource Licenses
- **What Happens**: Ten progressive license tiers expand the generation pool of your OneBlock.
- **Resource Variety**: Unlock natural ores, logs, stone variants, Nether materials, and End resources. Rare blocks maintain authentic rarity, while destructive liquids are filtered out.

### Island Expansion & Boundary Permits
- **What Happens**: Purchase island permits to expand your building boundaries from the initial 9x9 plot to 17x17, 33x33, 65x65, and incrementally up to a 129x129 domain.
- **Visual Boundaries**: Clear border markers indicate permitted territory, protecting your world while you build outward.

### Automated Harvester
- **What Happens**: Deploy the tool-tiered Auto-Miner (Wooden through Diamond) to automatically break the OneBlock at accelerated intervals.
- **Collection Vault**: Extracted items are deposited directly into a designated collection chest, featuring automatic shut-off when capacity is reached.

### Natural Loot Contracts & Jackpots
- **What Happens**: Activate resource contracts that spawn periodic bonus supply caches on your island. Every 100th block break awards a coin bonus and triggers a lucky chest.
