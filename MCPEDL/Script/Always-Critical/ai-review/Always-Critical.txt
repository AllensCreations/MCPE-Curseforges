## FILE: MCPEDL/Script/Always-Critical/behavior_pack/scripts/main.js (32 lines, 857 bytes)

```
import { world, system, EntityDamageCause } from "@minecraft/server";

const CRIT_MULTIPLIER = 1.5;
const CRIT_PARTICLE = "minecraft:critical_hit_emitter";

function isVanillaCrit(player) {
  return (
    player.isFalling &&
    !player.isOnGround &&
    !player.isInWater &&
    !player.isClimbing
  );
}

world.beforeEvents.entityHurt.subscribe(
  (event) => {
    const attacker = event.damageSource.damagingEntity;
    if (!attacker || attacker.typeId !== "minecraft:player") return;
    if (isVanillaCrit(attacker)) return;
    const target = event.hurtEntity;
    event.damage = event.damage * CRIT_MULTIPLIER;
    system.run(() => {
      try {
        target.dimension.spawnParticle(CRIT_PARTICLE, target.getHeadLocation());
      } catch (error) {
        return;
      }
    });
  },
  { allowedDamageCauses: [EntityDamageCause.entityAttack] }
);
```

**Every melee hit you land deals 1.5 times damage with critical hit sparks, no jumping required.**

> Always Critical gives every player melee hit the 1.5x damage of a vanilla critical hit.

## Overview

Load the Behavior Pack in a world and fight as usual. Each hit a player lands on a mob or another player deals 1.5 times its normal damage, and the target shows critical hit sparks.

## Key Features

### Always Critical Damage
- **What Happens**: Every melee hit a player lands deals 1.5 times its normal damage, whether you stand, walk, or swing at a target on the ground.
- **Good To Know**: Hits made while falling keep the vanilla critical bonus and are not boosted a second time.

### Critical Hit Sparks
- **What Happens**: Each boosted hit shows the standard critical hit sparks on the target, so you can see the bonus land.

## How to Use

1. Import the pack and add the Behavior Pack to your world.
2. Enter the world and attack any mob with a sword, an axe, or your fist.
3. Watch the critical hit sparks appear on every hit without jumping.
