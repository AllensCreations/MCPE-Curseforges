# Changelog — ALN:MobStacker

## [v2] - 2026-11-17 - Armor Drops and Smoother Loot

### Added
- **Armor Drops**: A Sneak Kill on Zombie and Husk stacks now has a small chance per extra mob to drop a piece of armor.

### Improved & Balanced
- **Smoother Loot**: Sneak Kill drops now appear over a few ticks instead of all at once, and a single kill spawns at most 256 item piles.
- **Baby Farm Stacks**: Baby farm animal stacks now keep their original mob, so its growth timer is no longer reset when the stack forms.

<details>
<summary><b>1.0.x</b> (5 releases)</summary>

### [1.0.4] - 2026-11-17 - Separate Baby Stacks

#### Improved & Balanced
- **Baby and Adult Stacks**: Babies and adults of every mob type stay in separate stacks again, and a killed stack mob is replaced by the same kind.
- **Zombie Variants**: Zombies, Husks, Drowned and Zombified Piglins each keep their own stack, and armored ones stay separate again.

#### Fixed
- **Random Babies**: Adult stacks no longer turn into random baby mobs when a mob is killed.

### [1.0.3] - 2026-11-17 - Mixed Zombie Stacks

#### Added
- **Random Spawn Stacks**: Zombie, Husk, Drowned and Zombified Piglin stacks now mix babies and adults, and each mob that replaces a killed one is a fresh random spawn that can be a baby or wear armor like a normal spawn.

#### Improved & Balanced
- **Mixed Merging**: These four mobs now merge even when wearing armor or holding items, so their gear is not kept.
- **Sneak Kill Experience**: A Sneak Kill on these four mobs now counts about one baby in twenty for the baby experience bonus.

### [1.0.2] - 2026-11-16 - Persistent Stacks

#### Added
- **Rare Drops**: A Sneak Kill now rolls the rare drops of Rabbits (Rabbit's Foot), Zombies (Iron Ingot, Carrot or Potato), Zombified Piglins (Gold Ingot) and Drowned (Copper Ingot) at their vanilla chances, raised by Looting.

#### Improved & Balanced
- **Persistent Stacks**: Merged stacks are now spawned to stay in the world, so they should not despawn when you walk away.
- **Batched Merging**: Merging is now done in small batches and skips dimensions with no players, so large farms should cause less stutter.

#### Fixed
- **Guardian Drops**: A Sneak Kill on a stack of Guardians now includes Raw Fish and Prismarine Crystals.

### [1.0.1] - 2026-11-16 - Gear Safe Stacking

#### Added
- **Cooked Meat Drops**: A Sneak Kill on a burning stack of Cows, Pigs, Sheep, Chickens, Rabbits or Mooshrooms now drops cooked meat.

#### Improved & Balanced
- **Gear Safe Stacking**: Mobs wearing armor or holding items are no longer merged, so their gear is never lost. Skeletons, Strays and Boggeds holding only their bow still stack.

#### Fixed
- **Sheep Mutton Drops**: A Sneak Kill on a stack of Sheep now drops Raw Mutton.

### [1.0.0] - 2026-11-16 - First Release

#### Added
- **Mob Merging**: Identical farm animals and grinder mobs within 4 blocks merge into one mob with a gold count label and no stack size limit.
- **One-by-One Unpeeling**: Killing a stacked mob removes one from the stack and keeps the rest in place.
- **Sneak Kill**: Sneaking during a kill clears the whole stack with drops and experience scaled by Looting.

</details>

import {

  LOOT,
  PERSISTENT_TAG,

const SAMPLE_LIMIT = 200;
const MAX_ITEM_ENTITIES = 256;
const ITEMS_PER_TICK = 32;

function randomInt(min, max) {
  return min + Math.floor(Math.random() * (max - min + 1));
}

function lootMultiplier(looting) {
  return 1 + Math.floor(Math.random() * (looting + 1));
}

function addTotal(totals, id, amount) {
  if (id && amount > 0) totals.set(id, (totals.get(id) ?? 0) + amount);
}

function pickWeighted(entries) {
  let sum = 0;
  for (const entry of entries) sum += entry[3];
  let roll = Math.random() * sum;
  for (const entry of entries) {
    roll -= entry[3];
    if (roll < 0) return entry;
  }
  return entries[entries.length - 1];
}

function rollUnit(typeId, def, meta, looting, totals) {
  for (const [id, min, max] of def.drops) {
    addTotal(totals, id, randomInt(min, max) * lootMultiplier(looting));
  }
  if (def.rolled) {
    const rolls = randomInt(def.rolled.rolls[0], def.rolled.rolls[1]);
    for (let r = 0; r < rolls; r++) {
      const entry = pickWeighted(def.rolled.entries);
      addTotal(totals, entry[0], randomInt(entry[1], entry[2]) * lootMultiplier(looting));
    }
  }
  if (def.gear && Math.random() < GEAR_DROP_CHANCE) {
    addTotal(totals, GEAR_DROP_ITEMS[randomInt(0, GEAR_DROP_ITEMS.length - 1)], 1);
  }
  if (def.rare) {
    for (const rare of def.rare) {
      if (Math.random() < rare.chance + rare.bonus * looting) {
        addTotal(totals, rare.ids[randomInt(0, rare.ids.length - 1)], 1);
      }
    }
  }
  if (typeId === "minecraft:sheep" && !meta.sheared) {
    const wool = WOOL_BY_COLOR[meta.color] ?? WOOL_BY_COLOR[0];
    addTotal(totals, wool, 1);
  }
}

  const sampled = Math.min(units, SAMPLE_LIMIT);
  const scale = units / sampled;
  for (let i = 0; i < sampled; i++) {
    xp += rollExperience(def, meta);
    if (!isBabyAnimal) rollUnit(typeId, def, meta, looting, totals);
  }
  if (scale !== 1) {
    xp = Math.round(xp * scale);
    for (const [id, amount] of totals) totals.set(id, Math.round(amount * scale));
  }
  if (burning) {
    for (const [raw, cooked] of Object.entries(COOKED_BY_RAW)) {
      const amount = totals.get(raw);

      continue;

      const size = Math.min(remaining, maxAmount);

        pending.push(new ItemStack(id, size));
      } catch (error) {
        break;
      }
      remaining -= size;
    }

    for (let n = 0; n < ITEMS_PER_TICK && index < pending.length; n++) {

        dimension.spawnItem(pending[index], location);
      } catch (error) {
        index = pending.length;
      }
      index++;
    }
    if (index >= pending.length) system.clearRun(handle);
  }, 1);

    try {
      dimension.spawnXp(location, xp);
    } catch (error) {
      return;
    }
  }

  } catch (error) {

    }
  }
  for (const group of groups.values()) {
    try {
      mergeGroup(group);
    } catch (error) {
      continue;
    }
  }
}

function buildQueue() {
  if (queue.length > 0) return;
  for (const id of DIMENSION_IDS) {
    try {
      const dimension = world.getDimension(id);
      if (dimension.getPlayers().length === 0) continue;
      for (const typeId of STACKABLE_MOBS) queue.push({ dimension, typeId });
    } catch (error) {
      continue;
    }
  }
}

export function startMerger() {
  system.runInterval(buildQueue, MERGE_INTERVAL_TICKS);

  system.runInterval(() => {
    for (let i = 0; i < JOBS_PER_TICK && queue.length > 0; i++) {
      try {
        runJob(queue.shift());
      } catch (error) {
        continue;
      }
    }
  }, 1);

  world.afterEvents.entityRemove.subscribe((event) => {
    stackCache.delete(event.removedEntityId);
  });
}

# ALN:MobStacker — Lag-Free Farm and Grinder Condenser

**By ALNStudios**

[![Minecraft Bedrock](https://img.shields.io/badge/Minecraft%20Bedrock-Stable%20Release-brightgreen?style=flat-square&logo=minecraft)](https://github.com/AllensCreations/MCPE-Curseforges)
[![Format](https://img.shields.io/badge/Format-.MCPACK%20%7C%20.MCADDON%20%7C%20.MCWORLD-blue?style=flat-square)](https://github.com/AllensCreations/MCPE-Curseforges)

**Merges identical farm animals and grinder mobs within 4 blocks into one counted stack with no size limit.**

> ALN:MobStacker turns 25 supported mob types into single stacked mobs with a gold count label. Farms and AFK grinders keep fewer mobs in the world, and every kill still pays out.

## Overview

Build a farm or grinder as usual. Mobs of the same kind that stand close together merge into one mob labelled with how many it holds. Killing the stack removes one mob at a time, or you can sneak while you strike the final blow to clear the whole stack at once. Looting on your held weapon raises the drops from the cleared stack.

## Key Features

### Mob Merging
- **What Happens**: Identical mobs within 4 blocks of each other merge into one mob about once a second. The merged mob shows a label such as `[x12] Cow` in gold and white.
- **How It Works**: Twenty cows packed in a pen become one Cow labelled `[x20]`. The label appears when you look at the mob.
- **Good To Know**: There is no stack size limit. Mobs absorbed into a stack disappear without dropping anything. Merged stacks are set to stay in the world, so they should not despawn when you walk away. Baby farm animal stacks keep their original mob, so its growth is not reset, but killing one mob of a baby stack spawns a new baby that starts growing from the beginning.

### Supported Mobs
- **What Happens**: Farm animals: Cow, Pig, Sheep, Chicken, Rabbit, Mooshroom, Goat, Frog. Grinder mobs: Zombie, Skeleton, Spider, Cave Spider, Creeper, Drowned, Husk, Stray, Blaze, Magma Cube, Slime, Enderman, Witch, Zombified Piglin, Guardian, Bogged, Breeze.

### Merge Rules
- **What Happens**: Adults merge with adults and babies merge with babies, and the two never share a stack. Zombies, Husks, Drowned and Zombified Piglins each keep their own stacks. Sheep merge only with sheep of the same color and shear state, and slimes and magma cubes merge only with the same size.
- **Good To Know**: Tamed mobs, leashed mobs and mobs you named with a Name Tag never merge into a stack. Mobs wearing armor or holding items stay separate, including armored Zombies. Skeletons, Strays and Boggeds holding only their bow still merge.

### One-by-One Unpeeling
- **What Happens**: Killing a stacked mob normally removes one mob from the stack. The stack stays in place with its count lowered by one, and the mob you killed drops its normal loot.
- **How It Works**: Mobs that die to fall damage, lava, fire or a trident lose one from the stack each time, so a grinder keeps working on the same stack.
- **Good To Know**: A baby stack is replaced by a baby and an adult stack by an adult, so a stack never turns into the other kind.

### Sneak Kill
- **What Happens**: Sneak while you kill a stacked mob and the whole remaining stack is cleared at once. The extra mobs drop their loot and experience together, and an action bar message shows the stack size, mob name and Looting level.
- **Good To Know**: Sneak Kill drops the regular items of each mob type, plus the rare drops of Rabbits, Zombies, Zombified Piglins and Drowned at their vanilla chances. Zombie and Husk stacks also have a small chance of dropping a piece of armor for each extra mob. Cow, Pig, Sheep, Chicken, Rabbit and Mooshroom stacks that are burning when you kill them drop cooked meat. Big piles of drops appear over a few ticks, up to 256 item piles per kill.

### Looting Bonus
- **What Happens**: Looting on the weapon in your main hand, levels 1 to 3, raises the drops of each extra mob in a Sneak Kill. Each extra mob multiplies its drops by a random 1 up to the Looting level plus 1.
- **How It Works**: With Looting III, each extra Zombie in a cleared stack drops its Rotten Flesh multiplied by 1 to 4.

## How to Use

1. Enable the Behavior Pack on your world.
2. Gather several mobs of the same kind within 4 blocks of each other and wait a few seconds until one mob shows a count label.
3. Hit the stack to remove one mob at a time, or sneak while you kill it to clear the whole stack and collect the boosted drops.

## Common Questions

- **Is there a maximum stack size?**: No. A stack can hold any number of mobs.
- **Does it work on pets and named mobs?**: No. Tamed mobs and mobs with a custom name are never merged.
