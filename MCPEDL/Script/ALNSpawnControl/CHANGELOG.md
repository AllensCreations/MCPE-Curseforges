# Changelog — ALN:SpawnControl

---

## [1.0.0] - 2026-11-17 - First Release

### Added
- **Spawn Manager Book**: Right-click a Book or Writable Book renamed to "Spawn Manager" to open the interactive control panel.
- **Categorized Mob Switches**: Toggle individual spawn rules across 58 mobs in 4 groups: Overworld Hostiles, Passive & Neutral Mobs, Nether & End Mobs, and Bosses & Rare Mobs.
- **Quick Presets**: Apply one-tap presets to enable all mobs, disable all hostiles, disable all passives, or disable all mobs.
- **Global Filter Settings**: Configure whether rules affect natural spawns only or all spawn causes including Spawn Eggs, enable an Admin Tag Lock, and trigger an immediate entity purge.
