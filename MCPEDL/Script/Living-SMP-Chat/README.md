# Living SMP Chat

Download the current release of **Living SMP Chat** for Minecraft Bedrock Edition.

## Download

- **Package format:** `.mcpack`
- **Direct download:** [Download Living SMP Chat (.mcpack)](https://github.com/AllensCreations/MCPE-Curseforges/blob/main/MCPEDL/Script/README.md#available-scripts)

## Installation

1. Download the package using the link above.
2. Open the downloaded file with Minecraft to import it.
3. If the package contains a pack that must be enabled separately, activate it in your world's settings.
