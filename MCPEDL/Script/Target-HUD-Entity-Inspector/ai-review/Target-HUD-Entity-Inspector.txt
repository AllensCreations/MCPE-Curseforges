# Changelog — Target HUD Entity Inspector

## [v2] - 2026-11-15

### Added
- **Status Effects**: Key effects on the target, such as Poison II 13s, now show with their level and time left, and Burning shows while the target is on fire.
- **Defeated Flash**: When you finish off a mob or player, Defeated and its name flash on the Action Bar for a moment.

### Improved & Balanced
- **Compact Layout**: When the line is too long for the screen, it switches to a shorter version with a 10-segment bar, shorter names and fewer effects.
- **Gear Reading**: Armor and the held item are now read piece by piece, so one unreadable piece no longer hides the rest.

### Fixed
- **Name Colors**: Mobs renamed with color or format codes no longer recolor or garble the display.
- **Dead Targets**: A target with no health left is no longer shown at 0 health.

<details>
<summary><b>1.1.x</b> (2 releases)</summary>

### [1.1.1] - 2026-11-14

#### Added
- **Held Item**: The item in the target's main hand now appears beside its armor.
- **Armor on Mobs**: Mobs that wear armor now show their armor points, not only players.
- **Pet Owners**: Pets tamed by other players now show as Tamed with the owner's name when that player is online.

#### Improved & Balanced
- **Smooth Health Bar**: The bar now has 20 segments and turns from green to yellow to red as health drops.
- **Adaptive Refresh**: The display updates every tick in a fight, every 2 ticks on a target and every 5 ticks while idle.
- **Steadier Display**: An unchanged line is no longer sent over and over, which removes needless flicker.
- **Absorption Marker**: A gold plus sign appears beside the health numbers when the target has Absorption.
- **More Mobs Recognized**: More vanilla mobs have a type, and unknown mobs use their game family before falling back to Neutral.
- **Any Tamed Animal**: Tamed animals other than Wolves and Cats now show as Tamed.

#### Fixed
- **Hidden Targets**: Invisible mobs, invisible players and players in Spectator mode no longer show their health.

### [1.1.0] - 2026-11-11

#### Added
- **Distance Readout**: The display now ends with how far away the target is, such as 5m.
- **Armor Points**: Players you look at now show their armor points beside their health.
- **Tamed Pets**: Your own tamed Wolves and Cats now show as Tamed instead of Neutral or Passive.

#### Improved & Balanced
- **Lower Minimum Version**: The Behavior Pack now asks for Minecraft 1.26.30 instead of 1.26.50.

</details>

<details>
<summary><b>1.0.x</b> (2 releases)</summary>

### [1.0.1] - 2026-11-11

#### Added
- **Health Bar**: A ten-segment bar such as ||||||.... now sits beside the health numbers, so health reads at a glance during a fight.
- **Aggressive Status**: Neutral mobs you hurt now show as Aggressive for one minute after your last hit, then return to Neutral.

#### Improved & Balanced
- **Cleaner Display**: The Target label and the status effects list are gone, leaving name, health bar, health numbers and type.
- **Colored Types**: Each type has its own color: Player, Hostile, Aggressive, Passive and Neutral.
- **Faster Refresh**: The display updates every 2 ticks instead of every 3.

#### Fixed
- **Lingering Display**: The display is cleared at once when you look away from a mob, instead of fading out slowly.

### [1.0.0] - 2026-11-11

#### Added
- **Entity Inspector**: Look at a mob or player within 16 blocks to see its name, health, type and status effects on the Action Bar.

</details>

function getEffectTags(entity) {

    if (level >= 2) {
      text += ` ${ROMAN[level] ?? level}`;

      text += ` ${formatDuration(effect.duration)}`;
    }
    tags.push(`${bad ? "§c" : "§a"}${text}`);
  }
  return tags;
}

  const until = angryUntil.get(entity.id);
  if (until !== undefined && until > system.currentTick) {
    return "Aggressive";
  }
  return base;
}

function getBarColor(ratio) {
  if (ratio > 0.6) {
    return "§a";
  }
  if (ratio > 0.3) {
    return "§e";
  }
  return "§c";
}

function buildHealthBar(current, max, segments) {
  const ratio = max > 0 ? Math.min(1, Math.max(0, current / max)) : 0;
  let filled = Math.round(ratio * segments);
  if (current > 0 && filled === 0) {
    filled = 1;
  }
  return `${getBarColor(ratio)}${"|".repeat(filled)}§8${"|".repeat(segments - filled)}`;
}

function findTarget(player) {
  const hits = player.getEntitiesFromViewDirection({ maxDistance: MAX_DISTANCE });
  if (hits.length === 0) {
    return undefined;
  }

  let blockDistance = Infinity;
  const blockHit = player.getBlockFromViewDirection({
    maxDistance: MAX_DISTANCE,
    includeLiquidBlocks: false,
    includePassableBlocks: false
  });
  if (blockHit) {
    const head = player.getHeadLocation();
    const face = blockHit.faceLocation;
    const dx = face.x - head.x;
    const dy = face.y - head.y;
    const dz = face.z - head.z;
    blockDistance = Math.sqrt(dx * dx + dy * dy + dz * dz);
  }

  for (const hit of hits) {
    const entity = hit.entity;
    if (!entity.isValid || entity.id === player.id) {
      continue;
    }
    if (hit.distance > blockDistance) {
      continue;
    }
    const health = entity.getComponent("minecraft:health");
    if (!health || health.currentValue <= 0) {
      continue;
    }
    if (isHidden(entity)) {
      continue;
    }
    return { entity, distance: hit.distance };
  }
  return undefined;
}

function collectInfo(entity, viewer, distance) {
  const health = entity.getComponent("minecraft:health");
  const isPlayer = entity.typeId === "minecraft:player";
  const tameInfo = getTameInfo(entity, viewer);
  const type = getClassification(entity, tameInfo);
  const armor = getArmorPoints(entity);
  return {
    name: getDisplayName(entity),
    current: Math.ceil(health.currentValue),
    max: Math.ceil(health.effectiveMax),
    absorbed: hasEffect(entity, "absorption") ? " §6+" : "",
    showArmor: isPlayer || armor > 0,
    armor,
    held: getHeldItem(entity),
    effects: getEffectTags(entity),
    type,
    color: TYPE_COLORS[type] ?? "§f",
    owner: tameInfo && !tameInfo.own ? tameInfo.ownerName : undefined,
    distance: Math.round(distance)
  };
}

function formatLine(info, level) {
  const compact = level >= 1;
  const segments = compact ? COMPACT_BAR_SEGMENTS : BAR_SEGMENTS;
  const name = compact ? shorten(info.name, 14) : info.name;
  let line = `§f${name} §8| ${buildHealthBar(info.current, info.max, segments)} §f${info.current}/${info.max}${info.absorbed}`;
  if (info.showArmor) {
    line += compact ? ` §8| §7A §f${info.armor}` : ` §8| §7Armor §f${info.armor}`;
  }
  if (info.held && level < 4) {
    line += compact ? ` §8| §f${shorten(info.held, 12)}` : ` §8| §7Held §f${info.held}`;
  }
  const effects = info.effects.slice(0, EFFECT_LIMITS[level]);
  for (const tag of effects) {
    line += ` §8| ${tag}`;
  }
  let typeLabel = `${info.color}${info.type}`;
  if (!compact && info.owner) {
    typeLabel += ` §7of ${info.owner}`;
  }
  return `${line} §8| ${typeLabel} §8| §7${info.distance}m`;
}

function buildActionBar(entity, viewer, distance) {
  const info = collectInfo(entity, viewer, distance);
  let line = "";
  for (let level = 0; level < EFFECT_LIMITS.length; level++) {
    line = formatLine(info, level);
    if (measureWidth(line) <= MAX_LINE_WIDTH) {
      return line;
    }
  }
  return line;
}

function updatePlayer(player, now) {
  const state = getState(player.id);
  if (now < state.nextRun) {
    return;
  }

  let text;
  if (now < state.flashUntil) {
    text = state.flashText;
  } else {
    try {
      const target = findTarget(player);
      if (target) {
        text = buildActionBar(target.entity, player, target.distance);
      }
    } catch (error) {
      text = undefined;
    }
  }

  if (text !== undefined) {
    if (text !== state.lastText || now - state.lastSent >= REFRESH_TICKS) {
      player.onScreenDisplay.setActionBar(text);
      state.lastText = text;
      state.lastSent = now;
    }
    state.nextRun = now + (now < state.combatUntil ? COMBAT_INTERVAL_TICKS : TRACK_INTERVAL_TICKS);
    return;
  }

  if (state.lastText !== undefined) {
    player.onScreenDisplay.setActionBar(BLANK_BAR);
    state.lastText = undefined;
  }
  state.nextRun = now + (now < state.combatUntil ? COMBAT_INTERVAL_TICKS : IDLE_INTERVAL_TICKS);
}

function pruneAnger() {
  const now = system.currentTick;
  for (const [id, until] of angryUntil) {
    if (until <= now) {
      angryUntil.delete(id);
    }
  }
}

export function startTargetHud() {
  system.runInterval(() => {
    const now = system.currentTick;
    for (const player of world.getAllPlayers()) {
      if (!player.isValid) {
        continue;
      }
      updatePlayer(player, now);
    }
  }, 1);

  system.runInterval(pruneAnger, PRUNE_INTERVAL_TICKS);

  world.afterEvents.entityHurt.subscribe((event) => {
    const victim = event.hurtEntity;
    if (!victim.isValid) {
      return;
    }
    const now = system.currentTick;
    const victimIsPlayer = victim.typeId === "minecraft:player";
    if (victimIsPlayer) {
      markCombat(victim.id, now);
    }
    const attacker = event.damageSource.damagingEntity;
    if (!attacker || !attacker.isValid || attacker.typeId !== "minecraft:player") {
      return;
    }
    markCombat(attacker.id, now);
    if (!victimIsPlayer) {
      angryUntil.set(victim.id, now + ANGER_TICKS);
    }
  });

  world.afterEvents.entityDie.subscribe((event) => {
    const dead = event.deadEntity;
    let label = "Target";
    let deadId;
    try {
      deadId = dead.id;
      label = getDisplayName(dead);
    } catch (error) {
      label = "Target";
    }
    if (deadId !== undefined) {
      angryUntil.delete(deadId);
    }
    try {
      const attacker = event.damageSource.damagingEntity;
      if (attacker && attacker.isValid && attacker.typeId === "minecraft:player" && attacker.id !== deadId) {
        startFlash(attacker.id, label, system.currentTick);
      }
    } catch (error) {
      return;
    }
  });

  world.afterEvents.playerLeave.subscribe((event) => {
    playerStates.delete(event.playerId);
  });
}

# Target HUD Entity Inspector — Health Bar and Mob Type on the Action Bar

> Shows the entity under your crosshair on the Action Bar with a smooth color-changing bar beside the numbers.

## Overview

Aim at a mob or another player and a single line appears on the Action Bar. It disappears as soon as you look away or a block is in the way.

## Key Features

### Health Bar
- **What Happens**: A smooth bar of 20 segments shows how much health the target has left, next to the exact numbers, for example 14/20.
- **Good To Know**: A gold plus sign beside the numbers means the target has Absorption.

### Mob Type
- **What Happens**: The line names the type as Player, Hostile, Passive, Neutral or Aggressive, each in its own color.
- **Good To Know**: Aggressive lasts one minute after your last hit on that mob, then returns to Neutral.

### Distance Readout
- **What Happens**: The line ends with the distance to the target in blocks, for example 5m.

### Armor Points
- **What Happens**: When you look at a player, or at a mob wearing armor, the armor points appear beside the health.
- **Good To Know**: Points are counted from the Leather, Copper, Golden, Chainmail, Iron, Diamond and Netherite armor they wear, plus a Turtle Shell helmet.

### Tamed Pets
- **What Happens**: Tamed animals show as Tamed, in their own color, instead of Neutral or Passive. Pets tamed by other players also show their owner, such as Tamed of Steve.
- **Good To Know**: The owner's name is shown only while that player is online.

### Held Item
- **What Happens**: The item in the target's main hand appears after its armor, with a count when it is a stack, for example Iron Sword.

### Status Effects
- **What Happens**: Key effects on the target appear with their level and time left, for example Poison II 13s. Burning shows while the target is on fire.
- **Good To Know**: Wither, Poison, Slowness, Weakness, Regeneration, Strength, Speed, Resistance and Fire Resistance are shown, up to three at a time and fewer when the line is long. Effects that last an hour or more show no time left.

### Defeated Flash
- **What Happens**: When you finish off a mob or player, Defeated and its name flash on the Action Bar for about a second and a half.

### Compact Layout
- **What Happens**: When the line would be too long for the screen, it switches to a shorter version with a 10-segment bar, shorter names and fewer effects.
- **Good To Know**: If there is still not enough room, the effects and then the held item are dropped.

### Adaptive Refresh
- **What Happens**: The display updates every tick while you are fighting, every 2 ticks while you look at a target and every 5 ticks while nothing is in view.
- **Good To Know**: An unchanged line is sent again only about once a second, so the display stays steady.

### Hidden Targets
- **What Happens**: Invisible mobs, invisible players and players in Spectator mode are not shown. Targets with no health left are not shown either.

1. Enable the Behavior Pack in your world's settings.
2. Look at a mob or player within 16 blocks.
3. Read the name, health bar, health numbers, type and distance on the Action Bar.
