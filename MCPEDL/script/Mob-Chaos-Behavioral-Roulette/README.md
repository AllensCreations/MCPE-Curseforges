# Mob Chaos: Behavioral Roulette

A chaos mini-game by AllensCreations. While it runs, mobs near you are randomly handed another creature's tricks: cows hover and drop beef, sheep catch fire and charge, dogs gain a creeper's fuse, spiders blink behind you. Blood-red glitching warnings flash on your action bar and screen right before a mob mutates.

**Install:** add both packs (behavior and resource) to a world. Use the Controller item you receive on first spawn: **Start**, **Restart**, or **End**. In a void or empty world, bring mobs with spawn eggs.

- Controller: the item is given to each player on first spawn. Right-click it to open the Start / Restart / End form.
- Achievements: Unknown / needs confirmation.
- Experiments: No experiment requirement detected in the inspected files.
- Behavior swaps are approximated with effects, impulses, fire, teleports, sounds, item drops and explosions. Mob AI itself is not rewritten.
- Fuse explosions break blocks by default; this can be switched off in the script settings.
