# Changelog — Team Inventory

---

## [1.0.12] - 2026-10-18

### Fixed
- **Join Notification:** The private syncing message now appears even when the usual notification method is unavailable.

---

## [1.0.11] - 2026-10-18

### Improved
- **In-Game Title:** The add-on title now displays the release version consistently.

---

## [1.0.10] - 2026-10-18

### Fixed
- **Join Notification:** Added a fallback so the private syncing message can still appear when normal delivery fails.

---

## [1.0.9] - 2026-10-18

### Added
- **Private Syncing Message:** Players receive a short shared-inventory syncing message when they join, without repeating it on death respawn.

---

## [1.0.7] - 2026-10-18

### Improved
- **Team Inventory Name:** Updated the in-game add-on name to Team Inventory.

---

## [1.0.6] - 2026-10-18

### Added
- **Persistent Shared Inventory:** Shared inventory state is retained when the world is restarted.
- **Equipment Sharing:** Armor, offhand items, and the selected hotbar slot are included in the shared inventory.
- **Conflict Feedback:** Players receive brief feedback when simultaneous slot changes conflict.

### Improved & Balanced
- **World Settings:** The add-on no longer changes the world's keep-inventory setting.
- **Clearer Status:** Removed the persistent status display and custom command controls.
