# Alphabet Scavenger Hunt Challenge (v1.0.9) — Timed Survival Minigame

**By AllensCreations**

Race against the clock to find, gather, or craft an item whose name begins with the round's target letter. Alphabet Scavenger Hunt turns ordinary survival into a 20-round challenge where quick thinking and inventory management matter.

## Overview

Each round selects a target letter and gives you 60 seconds to find a matching item. Complete a round to earn a 30-second preparation break. Failing a round reduces your maximum health, and penalties build until the run ends or is reset.

## Key Features

### 20-Round Challenge
- **Goal:** Complete all 20 rounds to finish the challenge.

### Timed Letter Hunt
- **Goal:** Find, gather, mine, or craft an item matching the current letter before the 60-second timer expires.

### Preparation Breaks
- **What Happens:** Successful rounds provide a 30-second intermission to organize inventory, prepare materials, or explore nearby areas.

### Inventory Matching
- **What Happens:** The challenge recognizes supported common and formal item names, helping eligible alternate names count for the same item.

### Progressive Failure Penalty
- **Risk:** Failing a round reduces maximum health by two health points. Penalties accumulate during the run.

### On-Screen Progress
- **Feedback:** The display shows the current round, target letter, timer, and penalty state, with audio cues as time runs low.

### Touch-Friendly Controls
- **Controls:** Supported gestures let you activate the challenge using a compass, clock, or stick without needing to type commands.

## How to Play

1. Import and enable the pack in a Minecraft Bedrock world.
2. Start the challenge using its in-game activation method.
3. Find an item matching the target letter before time runs out.
4. Use successful breaks to prepare for the next round.

## Compatibility and Limitations

- Minecraft Bedrock Edition. Check the package listing for the current supported version.
- A failed round applies a lasting maximum-health penalty for the current run.
