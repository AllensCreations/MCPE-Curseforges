# Beacon Effect Halo (v1.0.0)

**By AllensCreations**

Wear an effect-specific angel halo in the helmet slot. Charge a halo through the interface that opens when you interact with a Beacon.

## Halo Catalog

- **Haste Halo** — Haste.
- **Speed Halo** — Speed.
- **Resistance Halo** — Resistance.
- **Jump Boost Halo** — Jump Boost.
- **Strength Halo** — Strength.
- **Regeneration Halo** — Regeneration.

## How It Works

- Each halo must be equipped in the head slot to activate.
- A full charge provides up to 10 minutes of use outside Beacon range.
- Near a qualifying active Beacon, the halo effect continues without draining its charge.
- Effects stop when the halo is removed or its charge runs out outside Beacon range.
- Halo particles are spawned in the shared world for nearby players.

## Compatibility and Testing

Designed for Minecraft Bedrock Edition 1.26.30+ with stable `@minecraft/server` 2.8.0 and `@minecraft/server-ui` 2.1.0 dependencies. Beacon detection uses the stable Script API block-volume query to find nearby Beacons within a 50-block cube, then checks pyramid tiers and a short section of the beam. Only loaded chunks are searched; active-state detection still needs in-game validation. Halo item icons and wearable textures use editable 32×32 pixel-art JSON sources in `resource_pack/pixel_sources/`. The visual halo fit, multiplayer visibility, charging behavior, and performance have not been tested in-game. Achievement compatibility is not guaranteed.
