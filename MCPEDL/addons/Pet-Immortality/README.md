# Pet Immortality - Add-on for Minecraft Bedrock

Creator: AllensCreations

Description: Configurable immortality for cats, wolves, parrots, horses, and all tamed pets.

## Features

- Toggle cat immortality
- Toggle wolf immortality
- Toggle parrot immortality
- Toggle horse immortality
- Toggle immortality for all tamed pets
- Persistent selections

## Requirements

| Requirement | Value |
| --- | --- |
| Behavior pack | `Pet-Immortality BP by AllensCreations` |
| Script API | `@minecraft/server` 1.17.0 |
| Entry point | `scripts/main.js` |
| Minimum engine | 1.26.0 |

## Installation

1. Download the generated package from the repository catalog.
2. Open the package with Minecraft to import it.
3. Activate `Pet-Immortality BP by AllensCreations` in the world's Behavior Packs settings.
4. Enable any additional requirements documented for this add-on.

## Compatibility and known limitations

- Declared minimum engine version: 1.26.0.
- Declared Script API dependency: 1.17.0.
- Runtime compatibility must be verified in the target game version.

- Use the in-game chat commands to change protection selections.
