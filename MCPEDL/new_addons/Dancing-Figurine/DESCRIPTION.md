# Dancing Figurine by AllensCreations

Place the miniature figurine and interact with it to start a 20-second dance party. Nearby mobs hop to the rhythm while hearts and musical notes appear. Players within 12 blocks see rotating, soft color fades and a party message.

## Features

### Interactive Dance Party
- Interact with the figurine to start the party.
- Interact with it again to stop the active party early.
- The party ends automatically after 20 seconds.

### Nearby Mob Effects
- Living mobs within 12 blocks receive gentle hopping pulses.
- Hearts and musical notes appear around nearby mobs.
- Mob behavior and animations still depend on each mob's normal game behavior.

### Colorful Atmosphere
- Nearby players see red, pink, cyan, yellow, and violet camera fades.
- A party message appears while the effect is active.

### Crafting Recipe
Use a crafting table and arrange the ingredients in this 3x3 pattern:

- Top-center: Quartz
- Middle-left: Redstone Dust
- Middle-center: Sugar
- Middle-right: Redstone Dust
- Bottom-center: Quartz

The recipe produces one Dancing Figurine.

## Music

The sound event is configured for a custom cute dance tune. The original OGG audio asset is not included in this source revision, so the custom song will not play until that asset is added to the resource pack. The figurine's other party effects can still run.
