# Dancing Figurine (v1.0.0)

The downloadable package will be listed in the [New Add-ons catalog](https://github.com/AllensCreations/MCPE-Curseforges/blob/main/MCPEDL/new_addons/README.md) after the repository build workflow completes.

**Package format:** Complete Pack (.mcaddon)

## Installation

1. Download the completed package from the catalog.
2. Open the downloaded `.mcaddon` file with Minecraft.
3. Activate the Behavior Pack and Resource Pack in your world's settings.
