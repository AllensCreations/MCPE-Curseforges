# Melody Figurine (v1.0.0)

Download the current release of **Melody Figurine** for Minecraft Bedrock Edition.

## Download

- **Version:** 1.0.0
- **Package format:** `.mcaddon`
- **Direct download:** See the [New Add-ons download catalog](https://github.com/AllensCreations/MCPE-Curseforges/blob/main/MCPEDL/new_addons/README.md) after the package is built.

## Installation

1. Download the package from the catalog.
2. Open the downloaded file with Minecraft to import it.
3. Enable the imported packs in your world's settings if they are not activated automatically.
