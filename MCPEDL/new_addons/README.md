## Contributing and Customizing

Each folder inside `new_addons/` is structured as a standard Minecraft Bedrock add-on:
- `behavior_pack/` or root: Entities, functions, scripts, recipes, and loot tables.
- `resource_pack/`: Textures, client entity definitions, geometry, and language files.
- `manifest.json`: Pack UUIDs, engine versions, module headers, and metadata.
