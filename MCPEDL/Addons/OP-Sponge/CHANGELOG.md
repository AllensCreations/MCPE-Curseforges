# Changelog — OP Sponge

---

## [1.0.0] - 2026-11-11

### Added
- **OP Sponge**: A sponge that absorbs up to 256 water blocks within 16 blocks when placed, then turns into a Water-Filled OP Sponge.
- **OP Lava Sponge**: A matching sponge that absorbs up to 256 lava blocks within 16 blocks when placed, then turns into a Lava-Filled OP Sponge.
- **Filled Sponges**: Water-Filled OP Sponge and Lava-Filled OP Sponge blocks that show a sponge has been used. The lava version gives off light.
- **Recipes**: Craft an OP Sponge from a Sponge and Prismarine Crystals, and an OP Lava Sponge from a Sponge and Magma Cream. Smelt a filled sponge in a furnace to dry it.
