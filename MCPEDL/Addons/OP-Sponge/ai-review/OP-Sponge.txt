# Changelog — OP Sponge

## [v2] - 2026-11-11

### Added
- **Super Sponge I to X**: Ten sponge levels. Super Sponge I absorbs up to 512 water blocks within 18 blocks, and each level adds 256 blocks and 2 blocks of reach, up to 2,816 blocks within 36 blocks at level X.
- **Extreme Sponge I**: A sponge that keeps absorbing connected water until none is left, up to 100,000 water blocks in one use.
- **Sponge Books**: Super Sponge I to X Books and an Extreme Sponge I Book. Craft one with an OP Sponge to get the matching sponge. Two books of the same level combine into one level higher, and two Super Sponge X Books make an Extreme Sponge I Book.
- **Glowing Sponges**: Super Sponges, Extreme Sponges, their filled versions, and the books glow like enchanted items. Placed Super and Extreme Sponges send out sparkles when they absorb water.
- **Book Loot and Trades**: Sponge books can appear in ten kinds of structure chests, and Librarian villagers sell them for Emeralds and a Book.

<details>
<summary><b>1.0.x</b> (1 release)</summary>

### [1.0.0] - 2026-11-11

#### Added
- **OP Sponge**: A sponge that absorbs up to 256 water blocks within 16 blocks when placed, then turns into a Water-Filled OP Sponge.
- **Water-Filled OP Sponge**: A block that shows the sponge has been used. Smelt it in a furnace to get a dry OP Sponge back.
- **Recipe**: Craft an OP Sponge from a Sponge and Prismarine Crystals.

</details>
```

## FILE: MCPEDL/Addons/OP-Sponge/behavior_pack/scripts/main.js (131 lines, 3385 bytes)

```
import { system, world } from "@minecraft/server";

const WATER = new Set(["minecraft:water", "minecraft:flowing_water"]);
const BASE_CAPACITY = 256;
const BASE_RANGE = 16;
const LEVEL_RANGE = 2;
const EXTREME_CAPACITY = 100000;
const EXTREME_RANGE = 2048;
const BATCH = 200;
const SPARKLES = 16;
const NEIGHBORS = [
  { x: 1, y: 0, z: 0 },
  { x: -1, y: 0, z: 0 },
  { x: 0, y: 1, z: 0 },
  { x: 0, y: -1, z: 0 },
  { x: 0, y: 0, z: 1 },
  { x: 0, y: 0, z: -1 },
];

const SPONGES = new Map();

function register(name, capacity, range, sparkle) {
  SPONGES.set(`allenscreations:${name}`, {
    filled: `allenscreations:${name}_wet`,
    capacity,
    range,
    sparkle,
  });
}

register("op_sponge", BASE_CAPACITY, BASE_RANGE, false);
for (let level = 1; level <= 10; level++) {
  register(`super_sponge_${level}`, BASE_CAPACITY * (level + 1), BASE_RANGE + level * LEVEL_RANGE, true);
}
register("extreme_sponge_1", EXTREME_CAPACITY, EXTREME_RANGE, true);

function keyOf(location) {
  return `${location.x},${location.y},${location.z}`;
}

function readBlock(dimension, location) {
  try {
    return dimension.getBlock(location);
  } catch (error) {
    return undefined;
  }
}

function sparkle(dimension, origin) {
  for (let i = 0; i < SPARKLES; i++) {
    try {
      dimension.spawnParticle("minecraft:villager_happy", {
        x: origin.x + Math.random(),
        y: origin.y + Math.random(),
        z: origin.z + Math.random(),
      });
    } catch (error) {
      return;
    }
  }
}

function* absorb(dimension, origin, spongeId, sponge) {
  const found = [];
  const seen = new Set();
  let frontier = [origin];
  let reads = 0;
  for (let distance = 1; distance <= sponge.range && frontier.length > 0 && found.length < sponge.capacity; distance++) {
    const next = [];
    for (const cell of frontier) {
      for (const step of NEIGHBORS) {
        if (found.length >= sponge.capacity) {
          break;
        }
        const location = { x: cell.x + step.x, y: cell.y + step.y, z: cell.z + step.z };
        const key = keyOf(location);
        if (seen.has(key)) {
          continue;
        }
        const block = readBlock(dimension, location);
        reads++;
        if (reads % BATCH === 0) {
          yield;
        }
        if (block && WATER.has(block.typeId)) {
          seen.add(key);
          found.push(location);
          next.push(location);
        }
      }
    }
    frontier = next;
  }
  if (found.length === 0) {
    return;
  }
  const current = readBlock(dimension, origin);
  if (!current || current.typeId !== spongeId) {
    return;
  }
  let removed = 0;
  for (const location of found) {
    const block = readBlock(dimension, location);
    if (block && WATER.has(block.typeId)) {
      block.setType("minecraft:air");
    }
    removed++;
    if (removed % BATCH === 0) {
      yield;
    }
  }
  const after = readBlock(dimension, origin);
  if (!after || after.typeId !== spongeId) {
    return;
  }
  after.setType(sponge.filled);
  if (sponge.sparkle) {
    sparkle(dimension, origin);
  }
}

world.afterEvents.playerPlaceBlock.subscribe((event) => {
  const block = event.block;
  const sponge = SPONGES.get(block.typeId);
  if (!sponge) {
    return;
  }
  const origin = { x: block.location.x, y: block.location.y, z: block.location.z };
  system.runJob(absorb(block.dimension, origin, block.typeId, sponge));
});

# OP Sponge — Enchantable Sponges That Absorb Up to 100,000 Water Blocks

**By ALNStudios**

[![Minecraft Bedrock](https://img.shields.io/badge/Minecraft%20Bedrock-Stable%20Release-brightgreen?style=flat-square&logo=minecraft)](https://github.com/AllensCreations/MCPE-Curseforges)
[![Format](https://img.shields.io/badge/Format-.MCPACK%20%7C%20.MCADDON%20%7C%20.MCWORLD-blue?style=flat-square)](https://github.com/AllensCreations/MCPE-Curseforges)

**Craft Super Sponges that absorb up to 2,816 water blocks, or an Extreme Sponge that clears up to 100,000.**

> Adds the OP Sponge, ten levels of Super Sponge, and an Extreme Sponge, powered up with sponge books from chests, Librarian villagers, or crafting.

## Overview

Craft an OP Sponge, then combine it with a sponge book to make a Super Sponge or an Extreme Sponge. Place the sponge in or next to water and it removes the connected water around it, then turns into its filled version.

## Key Features

### OP Sponge
- **What Happens**: When placed, it absorbs up to 256 connected water blocks that are within 16 blocks of it, then becomes a Water-Filled OP Sponge.
- **Good To Know**: It only absorbs water.

### Super Sponge I to X
- **What Happens**: Each level absorbs more water.
- **Good To Know**: Super Sponges and their filled versions glow like enchanted items in your inventory and hand.

### Extreme Sponge I
- **What Happens**: It keeps absorbing until no connected water is left in reach, up to 100,000 water blocks in one use.
- **Good To Know**: A very large drain is spread over a short time, so the water disappears over a moment instead of all at once.

### Sponge Books
- **What Happens**: There is a Super Sponge Book for each level from I to X, plus an Extreme Sponge I Book.
- **Good To Know**: These are custom books, not vanilla enchantments, so the enchanting table and the anvil do not offer them.

### Finding Books
- **What Happens**: Sponge books can appear in shipwreck treasure chests, buried treasure, big ocean ruins, dungeons, stronghold libraries, ancient cities, desert temples, woodland mansions, jungle temples, and end city chests.
- **Good To Know**: To add the books, this add-on replaces the vanilla loot lists of those chests and the Librarian trade list.

### Filled Sponges
- **What Happens**: Every sponge has a Water-Filled version that you can pick up, carry, and place like any other block.
- **Good To Know**: Filled sponges use the wet Sponge look.

### Crafting
- **What Happens**: The OP Sponge is a Sponge combined with Prismarine Crystals.

## How to Use

1. Craft an OP Sponge from a Sponge and Prismarine Crystals.
2. Find or buy a sponge book, then craft it together with the OP Sponge to make a Super Sponge or an Extreme Sponge.
3. Place the sponge in or next to the water you want to remove, then smelt the filled sponge in a furnace to reuse it.
