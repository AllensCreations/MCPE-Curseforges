# Changelog — Padlock & Key

## [v2] - 2026-11-16

### Improved & Balanced
- **Lighter Lock Checks**: Explosions, Pistons, Hopper Minecart checks and lock cleanup now do far less work. Worlds with many locks or large redstone farms run smoother.

<details>
<summary><b>1.4.x</b> (2 releases)</summary>

### [1.4.2] - 2026-11-11

#### Improved & Balanced
- **Immovable Locks**: Pistons can no longer push or pull a locked block or the block under a locked container. Locked blocks stay where they are.

### [1.4.1] - 2026-11-11

#### Added
- **Hopper Minecart Guard**: A Hopper Minecart that ends up under a locked container is destroyed, so it can no longer pull items from it.

#### Fixed
- **Pistons Keep Locks**: Locked blocks pushed or pulled by a Piston now keep their lock instead of becoming public.

</details>

<details>
<summary><b>1.0.x</b> (7 releases)</summary>

### [1.0.7] - 2026-11-16 - Piston Safety and Iron Door Feel

#### Added
- **Piston Safety**: A Piston cannot be placed aimed at a locked block, and a block cannot be locked while a Piston is aimed at it. If a locked block still gets moved, for example in a Slime Block machine, its lock moves with it and the block stays locked.
- **Lock Cleanup**: Locks left behind by a block that no longer exists are removed automatically, so a new block placed there never inherits an old lock.

#### Improved & Balanced
- **Iron Door Feel**: Locked doors, trapdoors and fence gates cannot be opened by hand, like an Iron Door. If one still opens, it snaps shut again. Redstone can still open them.
- **Protected Door Floor**: The block under a locked door can no longer be broken or blown up until the door is unlocked.

#### Fixed
- **Pistons Unlocked Blocks**: Pushing or pulling a locked block with a Piston no longer leaves it unlocked.
- **Copper Chest Pairs**: A Copper Chest next to a locked Copper Chest now counts as part of the same lock.

  player.playSound("random.orb");
}

function unlockBlock(player, block, lock) {
  releaseLock(player, block.dimension, effectLocation(block, 1.2), lock);
  say(player, "Unlocked! Key dispersed, Padlock returned");
}

function denyAccess(player, block, password) {
  const hint = REVEAL_PASSWORD_ON_DENY
    ? `Locked! Need key named: ${password}`
    : "Locked! Need a key with the correct name";
  say(player, hint);
  player.playSound("break.amethyst_block");
  block.dimension.spawnParticle("minecraft:villager_angry", effectLocation(block, 1.2));
}

function copyKey(player) {
  if (recentKeyBlockUse.get(player.id) >= system.currentTick - 2) return;
  const equippable = player.getComponent("minecraft:equippable");
  if (!equippable) return;
  const key = equippable.getEquipment(EquipmentSlot.Mainhand);
  const nuggetSlot = equippable.getEquipmentSlot(EquipmentSlot.Offhand);
  if (!key || !KEY_IDS.has(key.typeId) || !key.nameTag) return;
  if (!nuggetSlot.hasItem() || nuggetSlot.typeId !== NUGGET_ID) return;
  consumeOne(nuggetSlot);
  giveNamed(player, GLOW_KEY_ID, key.nameTag);
  say(player, `Key copied! Key: ${key.nameTag}`);
  player.playSound("random.orb");
}

  const { player, block, itemStack, isFirstEvent } = event;

  if (!isLockable(block)) return;

    if (itemStack?.typeId !== PADLOCK_ID) return;

      system.run(() => say(player, "Rename the Padlock on an anvil first. The name is the password."));
      return;

    system.run(() => lockBlock(player, block, password));
    return;
  }

  const openable = isOpenable(block);
  const location = block.location;
  const wasOpen = openable ? openState(block) : undefined;

  if (!hasCorrectKey(player, lock.password)) {
    event.cancel = true;
    if (isFirstEvent) {
      system.run(() => {
        denyAccess(player, block, lock.password);
        if (openable) holdShut(block.dimension, location, wasOpen);
      });

    return;

    event.cancel = true;
    if (isFirstEvent) system.run(() => unlockBlock(player, block, lock));
    return;

# Padlock & Key — Password Locks for Chests and Doors

[![Minecraft Bedrock](https://img.shields.io/badge/Minecraft%20Bedrock-Stable%20Release-brightgreen?style=flat-square&logo=minecraft)](https://github.com/AllensCreations/MCPE-Curseforges)

**Craft a Padlock from 1 Iron Ingot and 1 Amethyst Shard, name it on an anvil, and lock any chest or door.**

> Padlock & Key adds a Padlock crafted from 1 Iron Ingot and 1 Amethyst Shard, plus a Key that is handed to you when you lock something.

## Overview

Craft a Padlock, rename it on an anvil, and use it on a supported block. The block locks, the Padlock is used up, and you receive a Key carrying the same name.

## Key Features

### Padlock
- **What Happens**: The Padlock is crafted with 1 Iron Ingot and 1 Amethyst Shard.
- **Good To Know**: An unnamed Padlock does not lock anything.

### Key
- **What Happens**: The Key opens a locked container while it is held in your main hand or your offhand and its name matches the password exactly.
- **How It Works**: Locked doors, trapdoors and fence gates cannot be opened by hand, even with the Key, just like an Iron Door. If one still opens, it snaps shut again.
- **Good To Know**: Without a matching Key, the block stays shut, and you see text above your hotbar with angry villager particles.

### Permanent Unlock
- **What Happens**: Sneak and right-click a locked block while holding the matching Key to remove the lock completely.
- **Good To Know**: A normal right-click with the Key only opens a locked container and never removes the lock.

### Break Protection
- **What Happens**: A locked block cannot be broken unless you hold the matching Key in either hand.
- **Good To Know**: Hoppers cannot be placed directly under a locked block, and a block cannot be locked while a Hopper sits under it. Explosions do not destroy locked blocks, and the block under a locked container or door is protected from breaking and explosions. Redstone can still open a locked door, trapdoor or fence gate, like an Iron Door. Mobs that break doors, such as Zombies, are not stopped.

### Key Copies
- **What Happens**: Hold a Key in your main hand and an Iron Nugget in your offhand, then use the Key to get one extra Key with the same name.
- **Good To Know**: Crafting cannot carry a custom name, so copies are made by using the Key instead of in a crafting grid.

### Lockable Blocks
- **What Happens**: Chest, Trapped Chest, every Copper Chest, Ender Chest, Barrel, every Shulker Box, Furnace, Blast Furnace, Smoker, Hopper, Brewing Stand, Dispenser, Dropper, Crafter, Decorated Pot, every door, every Fence Gate, every Trapdoor, and Chiseled Bookshelf can be locked.
- **Good To Know**: Lock data is saved with the world, and each dimension keeps its own locks. A Piston cannot be placed aimed at a locked block, and a block cannot be locked while a Piston is aimed at it. If a Piston still moves a locked block, for example in a Slime Block machine, the lock moves with it and the block stays locked. Locks left behind by a block that no longer exists are removed automatically.

## How to Use

1. Craft a Padlock with 1 Iron Ingot and 1 Amethyst Shard, then rename it on an anvil to your password.
2. Right-click a Chest, door, or other supported block with the Padlock to lock it and receive a Key.
3. Hold the Key in either hand and right-click a container to open it, or sneak and right-click any locked block to unlock it for good.

## Common Questions

- **Can I break a locked Chest?**: Only while you hold its matching Key in either hand. Breaking it removes the lock, disperses the Key, and returns the Padlock.
- **Does the Padlock work when it has no custom name?**: No. Rename it on an anvil first.
