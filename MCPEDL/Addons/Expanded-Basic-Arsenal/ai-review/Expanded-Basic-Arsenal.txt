```
# Changelog — Expanded Basic Arsenal

## [v2] - 2026-11-15 - First Release

### Added
- **Slingshot**: Pull back in three stages for 2, 4 or 6 damage, firing Flint or Cobblestone from your inventory.
- **Wooden Club**: A 5 damage weapon that pushes targets back and slows them for 1.5 seconds.
- **Flint Spear**: A 5 damage melee weapon that can be thrown for 6 damage and picked up again.
- **Blowgun**: Fires seed darts every 0.5 seconds, with Spider Eye darts that apply Poison I.
- **Copper Dagger**: A 4 damage weapon that deals 50% more damage when hitting from behind.
- **Crafting Recipes**: Recipes for all five weapons use Sticks, String, Stripped Logs, Flint, Bamboo and Copper Ingots.
```

```
import { EntityComponentTypes, EquipmentSlot, GameMode, ItemComponentTypes } from "@minecraft/server";

export function isCreative(player) {
  return player.getGameMode() === GameMode.Creative;
}

function mainHandSlot(player) {
  return player.getComponent(EntityComponentTypes.Equippable)?.getEquipmentSlot(EquipmentSlot.Mainhand);
}

export function heldItem(player) {
  return player.getComponent(EntityComponentTypes.Equippable)?.getEquipment(EquipmentSlot.Mainhand);
}

export function clearHeldItem(player) {
  mainHandSlot(player)?.setItem(undefined);
}

export function inventoryOf(player) {
  return player.getComponent(EntityComponentTypes.Inventory)?.container;
}

export function findAmmo(player, typeIds) {
  const container = inventoryOf(player);
  if (!container) return undefined;
  for (const typeId of typeIds) {
    for (let slot = 0; slot < container.size; slot++) {
      if (container.getItem(slot)?.typeId === typeId) return { slot, typeId };
    }
  }
  return undefined;
}

export function takeOne(player, slot) {
  const container = inventoryOf(player);
  const item = container?.getItem(slot);
  if (!item) return;
  if (item.amount > 1) {
    item.amount -= 1;
    container.setItem(slot, item);
  } else {
    container.setItem(slot, undefined);
  }
}

export function wearHeldItem(player, amount) {
  if (isCreative(player)) return false;
  const slot = mainHandSlot(player);
  const item = slot?.getItem();
  const durability = item?.getComponent(ItemComponentTypes.Durability);
  if (!durability) return false;
  if (durability.damage + amount >= durability.maxDurability) {
    slot.setItem(undefined);
    player.playSound("random.break");
    return true;
  }
  durability.damage += amount;
  slot.setItem(item);
  return false;
}

export function muzzle(player, distance) {
  const head = player.getHeadLocation();
  const dir = player.getViewDirection();
  return { x: head.x + dir.x * distance, y: head.y + dir.y * distance - 0.1, z: head.z + dir.z * distance };
}

export function shoot(projectile, owner, direction, speed) {
  const component = projectile.getComponent("minecraft:projectile");
  component.owner = owner;
  component.shoot({ x: direction.x * speed, y: direction.y * speed, z: direction.z * speed });
}
```

```
    if (!player.isValid || !holdingSlingshot(player)) {
      clearState(id);
      continue;
    }
    const stage = stageOf(now - state.startTick);
    if (stage !== state.stage) {
      state.stage = stage;
      setStateTag(player, stage);
      if (stage === 3) player.playSound("random.click");
      showBar(player, stage);
      state.nextBar = now + BAR_REFRESH;
    } else if (stage > 0 && now >= state.nextBar) {
      showBar(player, stage);
      state.nextBar = now + BAR_REFRESH;
    }
  }
  stopTimerIfIdle();
}

function launch(player, stage) {
  const creative = isCreative(player);
  const ammo = findAmmo(player, [FLINT, COBBLESTONE]);
  if (!ammo && !creative) {
    player.onScreenDisplay.setActionBar("§cNo Flint or Cobblestone");
    player.playSound("random.click");
    return;
  }
  const flint = ammo?.typeId === FLINT;
  const direction = player.getViewDirection();
  const pebble = player.dimension.spawnEntity(PEBBLE, muzzle(player, 0.9));
  try {
    const event = stage === 3 && flint ? FLINT_EVENT : STAGE_EVENT[stage];
    if (event) pebble.triggerEvent(event);
    shoot(pebble, player, direction, STAGE_SPEED[stage]);
  } catch (error) {
    if (pebble.isValid) pebble.remove();
    return;
  }
  if (ammo && !creative) takeOne(player, ammo.slot);
  wearHeldItem(player, 1);
  player.playSound("random.bow");
  system.runTimeout(() => {
    if (pebble.isValid) pebble.remove();
  }, PEBBLE_LIFETIME);
}

world.afterEvents.itemStartUse.subscribe(({ source, itemStack }) => {
  if (itemStack?.typeId !== SLINGSHOT) return;
  clearState(source.id);
  charging.set(source.id, { player: source, startTick: system.currentTick, stage: 0, nextBar: 0 });
  setStateTag(source, 0);
  if (timer === undefined) timer = system.runInterval(tick, 1);
});

world.afterEvents.itemReleaseUse.subscribe(({ source, itemStack }) => {
  const state = charging.get(source.id);
  if (!state || itemStack?.typeId !== SLINGSHOT) return;
  const stage = stageOf(system.currentTick - state.startTick);
  clearState(source.id);
  stopTimerIfIdle();
  if (stage > 0) launch(source, stage);
});
```

```
# Expanded Basic Arsenal — Five early-game weapons for Minecraft Bedrock

**By ALNStudios**

[![Minecraft Bedrock](https://img.shields.io/badge/Minecraft%20Bedrock-Stable%20Release-brightgreen?style=flat-square&logo=minecraft)](https://github.com/AllensCreations/MCPE-Curseforges)
[![Format](https://img.shields.io/badge/Format-.MCPACK%20%7C%20.MCADDON%20%7C%20.MCWORLD-blue?style=flat-square)](https://github.com/AllensCreations/MCPE-Curseforges)

**Five early-game weapons: Slingshot, Wooden Club, Flint Spear, Blowgun and Copper Dagger, crafted from sticks, string, flint, bamboo, logs and copper.**

> Expanded Basic Arsenal adds a three-stage Slingshot, a knockback Wooden Club, a throwable Flint Spear, a Blowgun and a Copper Dagger with a backstab bonus. All five are craftable before iron and suit the first days of a survival world.

## Overview

Craft a weapon from first-day materials, then pick the one that fits the fight. The Slingshot fires Flint or Cobblestone at range, the Wooden Club pushes mobs away and slows them, and the Flint Spear can be thrown and picked up again. The Blowgun fires seeds or poison darts, and the Copper Dagger hits harder from behind. Every weapon wears down with use.

## Key Features

### Slingshot
- **What Happens**: Hold the use button to pull the Slingshot back, then release to fire. A pull under 0.45 seconds deals 2 damage, a pull of 0.45 to 0.9 seconds deals 4, and a full pull of 0.95 seconds or more deals 6.
- **How It Works**: At full pull a click sounds and the Action Bar shows three charge pips. Craft it with 4 Sticks and 1 String: two Sticks on the top corners, String between them, and two Sticks below.
- **Good To Know**: Each shot uses one Flint, or one Cobblestone when no Flint is carried. A full-pull Flint shot deals 2 extra damage for 8 total. Creative mode uses no ammo. Durability is 180 and each shot costs 1.

### Wooden Club
- **What Happens**: Each hit deals 5 damage, pushes the target back farther than a normal hit and applies Slowness for 1.5 seconds.
- **How It Works**: Craft it with 2 Stripped Logs stacked above 1 Stick. Oak, Spruce, Birch, Jungle, Acacia, Dark Oak, Mangrove and Cherry Stripped Logs all work.
- **Good To Know**: Durability is 150.

### Flint Spear
- **What Happens**: As a melee weapon it deals 5 damage. Hold the use button for at least 0.5 seconds and release to throw it. A thrown spear deals 6 damage and flies faster the longer it was held, up to 1.25 seconds.
- **How It Works**: A thrown spear drops as an item where it lands or hits, and you pick it up by walking over it. Craft it with 1 Flint at the top right and 2 Sticks running diagonally below it.
- **Good To Know**: Durability is 120 and each throw costs 1. A spear with no durability left breaks on the throw. Creative mode does not drop a spear after a throw.

### Blowgun
- **What Happens**: Use the Blowgun to fire a dart, with a 0.5 second gap between shots. Each dart deals 1 damage and uses one Wheat, Beetroot, Melon or Pumpkin Seed.
- **How It Works**: A Spider Eye fires a poison dart that applies Poison I for 3 seconds. Sneak while firing to use Spider Eyes before seeds. Craft it with 3 Bamboo in the top row and 1 String below the left end.
- **Good To Know**: Without sneaking, Spider Eyes are used only when no seeds are carried. Durability is 150 and each shot costs 1.

### Copper Dagger
- **What Happens**: Each hit deals 4 damage. Hitting a target from behind, while both of you face roughly the same direction, deals 50% more damage for 6 total and shows critical hit particles.
- **How It Works**: Craft it with 1 Copper Ingot above 1 Stick.
- **Good To Know**: Durability is 190. The backstab bonus depends on the target's facing, so mobs that turn to face you take normal damage.

## How to Use

1. Gather Sticks, String, Flint, Bamboo, Stripped Logs and Copper Ingots.
2. Craft a weapon at a crafting table. All recipes appear in the recipe book from the start.
3. Hold the Slingshot's use button with Flint or Cobblestone in your inventory, release after about one second, and watch the pebble fly.
4. Right-click the Blowgun with seeds in your inventory to fire darts, or hold and release the Flint Spear to throw it.
```
