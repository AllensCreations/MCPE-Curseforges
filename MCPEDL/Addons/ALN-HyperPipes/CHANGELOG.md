# Changelog — ALN HyperPipes

---

## [1.0.0] - 2026-11-26 - First Release

### Added
- **Pipe Network**: Standard, Receiver, Filter and T-Junction Pipes move items through glass tubes, one pipe at a time, into chests, barrels, hoppers and furnaces.
- **Pipe Wrench**: Right-click a pipe to cycle its output face; sneak and right-click to cycle backward.
- **Item Filter**: Right-click a Filter Pipe with an item to make it pass only that item.
- **Crafting**: Recipes for all five items are unlocked from the start.
- **HD Art**: 32x32 textures and a hollow glass tube model with copper and iron brackets.
