**One compass menu for 5 named homes, 3 public warps each and a way back after dying.**

> Use a compass to open a single menu. Save named homes, publish warps for other players, and return to the spot where you last died.

## Overview

Homes, Warps and Back puts travel tools on the compass. Using a compass opens a menu where players save and delete homes, set and use public warps, and teleport to their last death point. Everything is saved with the world, and travel works between dimensions.

## Key Features

### Compass Menu
- **What Happens**: Using a compass opens the menu with homes, warps and the death point button.

### Named Homes
- **What Happens**: Each player saves up to 5 homes with their own names. Saving an existing name replaces that home.

### Home Deletion
- **What Happens**: The home list has a delete option, so a full list can be cleaned up without leaving the menu.

### Public Warps
- **What Happens**: Every player can publish up to 3 warps, with 30 warps in total. Anyone can travel to any warp from the list.

### Warp Ownership
- **What Happens**: A warp shows the name of the player who set it. Only that player can replace or delete it.

### Back to Death Point
- **What Happens**: The place where a player last died is saved, and the menu teleports them back to it.

### Dimension Memory
- **What Happens**: Homes, warps and death points remember their dimension, so travel works between the Overworld, Nether and End.

### World Saved Data
- **What Happens**: Homes, warps and death points stay saved when players leave and when the world restarts.

## How to Use

1. Hold a compass and use it to open the menu.
2. Choose Set Home or Set Warp, type a name of up to 16 characters, and confirm.
3. Choose My Homes or Warps to pick a place and teleport.
4. Use Delete a Home or Delete My Warp in each list to remove an entry.
5. After dying, open the menu and choose Back to Death Point.
6. Names accept letters, numbers, spaces, hyphens, apostrophes and underscores.
