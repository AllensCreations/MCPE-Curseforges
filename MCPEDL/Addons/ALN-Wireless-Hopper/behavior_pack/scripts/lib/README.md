# ALN Wireless Hopper: script notes

Entry point: `scripts/main.ts` (compiled to `main.js`) calls `initRemote()`, `initSenderLoop()` and `initCleanup()` once. Imports used: `@minecraft/server` (manifest dependency 2.11.0) and relative files only. Sources are TypeScript; the `.js` files are generated by the repo compile step.

## Files

- `main.ts`: starts the three modules below.
- `lib/constants.ts`: ids (`minecraft:hopper`, `aln:wireless_remote`, `aln:wireless_remote_linked`), receiver block types, the world dynamic property name, limits (24 receivers per hopper, 64 registered hoppers), the 5-tick send interval, dimension short codes. No dependencies.
- `lib/registry.ts`: stores sender-to-receiver links as one JSON string in a world dynamic property with an in-memory cache. Exports `makeKey`, `blockKey`, `parseKey`, `getReceivers`, `hasLinks`, `linkedHopperKeys`, `isSender`, `isReceiver`, `toggleReceiver`, `dropReceiver`, `dropReceiverEverywhere`, `removeHopper`. Blocks chains: a sender cannot be a receiver and a receiver cannot send. Depends on `constants.ts`.
- `lib/lore.ts`: writes and reads the registered Hopper position in the Linked Wireless Remote's lore. Depends on `registry.ts`.
- `lib/feedback.ts`: action bar messages (green success, yellow warning, red error). No dependencies.
- `lib/distribute.ts`: resolves receiver containers and splits an item stack evenly in rotating order, redistributing what full receivers reject. Skips receivers in unloaded chunks and removes receivers whose block is no longer a Chest, Barrel or Hopper. Depends on `registry.ts`, `constants.ts`.
- `lib/remote.ts`: right-click handling. Remote on a Hopper registers it and becomes the Linked Remote. Linked Remote on a Chest, Barrel or other Hopper links or unlinks it. Linked Remote on its own Hopper turns it back into a blank Remote. Depends on `registry.ts`, `lore.ts`, `feedback.ts`, `constants.ts`.
- `lib/sender_loop.ts`: every 5 ticks, empties each registered Hopper in a loaded chunk into its receivers through `distribute.ts`. Removes a registration when the block is no longer a Hopper. Does nothing when no Hopper is registered. Depends on `distribute.ts`, `registry.ts`, `constants.ts`.
- `lib/cleanup.ts`: breaking a Hopper, Chest or Barrel removes its links. Depends on `registry.ts`, `constants.ts`.

## Ids and events

- Items `aln:wireless_remote` and `aln:wireless_remote_linked`.
- Events: `world.beforeEvents.playerInteractWithBlock`, `world.afterEvents.playerBreakBlock`, `system.runInterval`.
- Dynamic property: world `aln:wh_links`.

## Known limits

- There is no event for items entering a container, so registered Hoppers are checked on a timer.
- A Hopper still pushes items into whatever it faces, which can race with the wireless delivery.
- Receivers in unloaded chunks are skipped.
- Hoppers destroyed by explosions or commands keep their stored links until the position is checked again.
- Both halves of a double chest are separate links.
