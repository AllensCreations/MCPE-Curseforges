# Changelog — ALN:OneClickSort

## [v10] - 2026-11-20 - Restock Get Everything

### Added
- **Get Everything**: A new toggle in the Sort Settings Book makes the Restock Feather pull every matching item from nearby chests, not just one full stack, until your inventory is full. It is off by default.

<details>
<summary><b>9.0.x</b> (1 release)</summary>

### [v9] - 2026-11-20 - Sneak Click Chest Controls

#### Improved & Balanced
- **Chest Sorting**: Sneak and right-click a chest with the Auto-Sort Feather to sort it. Sorting your backpack stays a plain right-click.
- **Stock Chest**: Sneak and right-click a chest with the Restock Feather to stock it with the items your backpack shares with it. Restock stays a plain right-click.
- **Sneak Use**: Sneaking and right-clicking a feather in the air no longer does anything, so Quick Stack is gone.
- **Container Support**: Sorting, stocking and Restock now work with copper chests and every other chest type, as well as barrels and shulker boxes.

</details>

<details>
<summary><b>8.0.x</b> (1 release)</summary>

### [v8] - 2026-11-20 - Feather Only Chest Sorting

#### Improved & Balanced
- **Chest Sorting**: Sneak and right-click now sorts a chest only while you hold the Auto-Sort Feather, so an empty hand no longer sorts it.

</details>

<details>
<summary><b>7.0.x</b> (1 release)</summary>

### [v7] - 2026-11-20 - Restock Stocking

#### Added
- **Restock Stocking**: Sneak and right-click the Restock Feather to quick-stack your items into nearby chests, the same as the Auto-Sort Feather.
- **Leave 1 Item in Chest**: A new toggle in the Sort Settings Book keeps one item of each type in a chest when restocking, so Quick Stack still finds that chest.

</details>

<details>
<summary><b>6.0.x</b> (1 release)</summary>

### [v6] - 2026-11-20 - Add-on Package

#### Improved & Balanced
- **Add-on Package**: The project is now built as a complete add-on with both packs, so it imports as one add-on file.

</details>

<details>
<summary><b>5.0.x</b> (1 release)</summary>

### [v5] - 2026-11-20 - Item Group

#### Added
- **Item Group**: The Auto-Sort Feather, Restock Feather and Sort Settings Book are now grouped together as OneClickSort in the Creative inventory under Items.

</details>

<details>
<summary><b>4.0.x</b> (1 release)</summary>

### [v4] - 2026-11-20 - Crafting Recipes

#### Added
- **Crafting Recipes**: Craft the Auto-Sort Feather from an Emerald, Feather and Hopper, the Restock Feather from a Gold Ingot, Feather and Chest, and the Sort Settings Book from a Book, Lapis Lazuli and Redstone Dust. All recipes are unlocked from the start.

</details>

<details>
<summary><b>3.0.x</b> (1 release)</summary>

### [v3] - 2026-11-20 - Custom Items

#### Added
- **Custom Items**: The Auto-Sort Feather, Restock Feather and Sort Settings Book are now real items found in the Creative inventory under Items, so no Anvil renaming is needed.

#### Improved & Balanced
- **Sort Settings**: Right-click the Sort Settings Book to open the menu.

#### Fixed
- **Sorting**: Sorting a chest or backpack no longer fails when matching stacks merge completely into another stack.
- **Sort Settings**: The settings menu opens again.

</details>

<details>
<summary><b>2.0.x</b> (1 release)</summary>

### [2.0.0] - 2026-11-20 - Pack Variants and Restock

#### Added
- **Pack Variants**: Choose Simple (default) or Normal (with particles) in the pack settings; only Normal shows particles above sorted chests.
- **Restock**: Right-click a Feather renamed Restock to refill partial stacks in your hotbar and backpack from chests, trapped chests and barrels within 6 blocks.

</details>

<details>
<summary><b>1.0.x</b> (1 release)</summary>

### [1.0.0] - 2026-11-20 - First Release

#### Added
- **Backpack Sorting**: Right-click a Feather renamed Auto-Sort to sort the 27 backpack slots while the hotbar stays untouched.
- **Chest Sorting**: Sneak and right-click a chest, trapped chest, barrel or shulker box to sort it without opening it.
- **Quick Stack**: Sneak and right-click the Auto-Sort Feather to move matching items into chests and barrels within 6 blocks.
- **Sort Settings**: Right-click a Book renamed Sort Settings to choose the sort order, hotbar sorting and feedback.

</details>

  const id = shortId(item.typeId);
  if (safeHas(item, "minecraft:durability")) return 0;
  if (id.endsWith("ore") || id.endsWith("ingot") || ORE_EXACT.has(id)) return 1;
  if (safeHas(item, "minecraft:food") || id.endsWith("potion")) return 2;
  if (REDSTONE_KEYS.some((k) => id.includes(k))) return 3;
  return 4;
}

function compareId(a, b) {
  return a.typeId < b.typeId ? -1 : a.typeId > b.typeId ? 1 : 0;
}

function makeComparator(sortMode) {
  if (sortMode === 1) {
    return (a, b) => compareId(a, b) || b.amount - a.amount;
  }
  if (sortMode === 2) {
    return (a, b) => b.amount - a.amount || compareId(a, b);
  }
  return (a, b) =>
    categoryOf(a) - categoryOf(b) || compareId(a, b) || b.amount - a.amount;
}

function consolidate(items) {
  const merged = [];
  for (const source of items) {
    const item = source.clone();
    let left = item.amount;
    for (const target of merged) {
      if (left <= 0) break;
      if (target.amount >= target.maxAmount) continue;
      if (!target.isStackableWith(item)) continue;
      const move = Math.min(target.maxAmount - target.amount, left);
      target.amount += move;
      left -= move;
    }
    if (left > 0) {
      item.amount = left;
      merged.push(item);
    }
  }
  return merged;
}

export function sortContainer(container, startSlot, endSlot, sortMode = 0) {
  const last = Math.min(endSlot, container.size - 1);
  const first = Math.max(0, startSlot);
  if (last < first) return;

  const items = [];
  for (let slot = first; slot <= last; slot++) {
    const item = container.getItem(slot);
    if (item) items.push(item);
  }

  const sorted = consolidate(items).sort(makeComparator(sortMode));

  for (let slot = first, i = 0; slot <= last; slot++, i++) {
    container.setItem(slot, sorted[i]);
  }
}

function pullEverything(backpack, targets, prefs, touched) {
  const templates = [];
  for (let i = 0; i <= 35; i++) {
    const it = backpack.getItem(i);
    if (!it || isAutoSortFeather(it) || isRestockFeather(it) || it.maxAmount <= 1) continue;
    if (!templates.some((tpl) => tpl.isStackableWith(it))) templates.push(it);
  }

  let pulled = 0;
  for (const tpl of templates) {
    let full = false;
    for (let t = 0; t < targets.length && !full; t++) {
      const container = targets[t].container;
      let allowed = prefs.keepOneInChest ? countStackable(container, tpl) - 1 : Infinity;
      for (let s = 0; s < container.size && allowed > 0 && !full; s++) {
        const stored = container.getItem(s);
        if (!stored || !tpl.isStackableWith(stored)) continue;
        const move = Math.min(stored.amount, allowed);
        const piece = stored.clone();
        piece.amount = move;
        let left;
        try {
          left = backpack.addItem(piece);
        } catch {
          full = true;
          continue;
        }
        const added = move - (left ? left.amount : 0);
        if (left) full = true;
        if (added <= 0) continue;
        allowed -= added;
        pulled += added;
        touched.add(t);
        if (stored.amount - added > 0) {
          stored.amount -= added;
          container.setItem(s, stored);
        } else {
          container.setItem(s, undefined);
        }
      }
    }
  }
  return pulled;
}

  const prefs = getPrefs(player);
  const backpack = getBackpack(player);
  const targets = findNearbyContainers(player);
  const slots = [];
  for (let i = 0; i <= 35; i++) slots.push(i);

  let pulledItems = 0;
  const touched = new Set();

  for (const slot of slots) {
    const held = backpack.getItem(slot);
    if (!held || isAutoSortFeather(held) || isRestockFeather(held)) continue;
    let need = held.maxAmount - held.amount;
    if (need <= 0) continue;

    for (let t = 0; t < targets.length && need > 0; t++) {
      const container = targets[t].container;
      let allowed = prefs.keepOneInChest ? countStackable(container, held) - 1 : Infinity;
      for (let s = 0; s < container.size && need > 0 && allowed > 0; s++) {
        const stored = container.getItem(s);
        if (!stored || !held.isStackableWith(stored)) continue;
        const move = Math.min(need, stored.amount, allowed);
        allowed -= move;
        held.amount += move;
        need -= move;
        pulledItems += move;
        touched.add(t);
        if (stored.amount - move > 0) {
          stored.amount -= move;
          container.setItem(s, stored);
        } else {
          container.setItem(s, undefined);
        }
      }
    }
    backpack.setItem(slot, held);
  }

  if (prefs.getEverything) pulledItems += pullEverything(backpack, targets, prefs, touched);

  feedback(
    player,
    prefs,
    `§d[Restock] §fPulled §e${pulledItems} §fitems from §a${touched.size} §fnearby chests!`
  );
}

export function registerTriggers() {
  world.afterEvents.itemUse.subscribe((event) => {
    const player = event.source;
    const item = event.itemStack;
    if (!player || !item) return;

    if (isSettingsBook(item)) {
      openSettings(player);
      return;
    }
    if (!isAutoSortFeather(item) && !isRestockFeather(item)) return;
    if (player.isSneaking) return;

    const last = lastContainerSort.get(player.id);
    if (last !== undefined && system.currentTick - last < 5) return;

    if (isRestockFeather(item)) restock(player);
    else sortBackpack(player);
  });

  world.beforeEvents.playerInteractWithBlock.subscribe((event) => {
    const { player, block, itemStack } = event;
    if (event.isFirstEvent === false) return;
    if (!player.isSneaking) return;
    if (!isSortableContainer(block.typeId)) return;
    const sortChest = isAutoSortFeather(itemStack);
    if (!sortChest && !isRestockFeather(itemStack)) return;

    event.cancel = true;
    lastContainerSort.set(player.id, system.currentTick);
    system.run(() => (sortChest ? sortBlockContainer(player, block) : stockChest(player, block)));
  });

  world.afterEvents.playerLeave.subscribe((e) => lastContainerSort.delete(e.playerId));
}

    .toggle("Audio & Particle Feedback", { defaultValue: prefs.soundFeedback })
    .toggle("Leave 1 Item in Chest When Restocking", { defaultValue: prefs.keepOneInChest })
    .toggle("Get Everything When Restocking (Not Just One Stack)", { defaultValue: prefs.getEverything });

    .show(player)
    .then((res) => {
      if (res.canceled) {
        if (res.cancelationReason === FormCancelationReason.UserBusy && attempt < 10) {
          system.runTimeout(() => openSettings(player, attempt + 1), 20);
        }
        return;

        sortMode: Number(mode),
        includeHotbar: !!hotbar,
        soundFeedback: !!sound,
        keepOneInChest: !!keepOne,
        getEverything: !!getAll,
      });
      player.onScreenDisplay.setActionBar("§a[OneClickSort] §fSettings saved!");
    })
    .catch((e) => console.warn(`[ALN:OneClickSort] Form error: ${e}`));
}
