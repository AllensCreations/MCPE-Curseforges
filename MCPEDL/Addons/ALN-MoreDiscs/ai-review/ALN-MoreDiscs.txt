```
# Changelog — ALN MoreDiscs

## [v3] - 2026-11-18 - Headphones Disc Names

### Improved & Balanced
- **Headphones Naming**: All ten discs now use the music disc naming that ALN Wireless Headphones expects.
- **Craft Again**: Discs from earlier versions in existing worlds no longer work and must be crafted again.

<details>
<summary><b>2.0.x</b> (1 release)</summary>

### [v2] - 2026-11-17 - Disc Group

#### Added
- **Creative Group**: All ten discs now sit together in their own ALN MoreDiscs group in the Items tab of the creative inventory.

#### Fixed
- **Disc Group**: The discs now use their own group name instead of the vanilla music disc group name.

</details>

<details>
<summary><b>1.1.x</b> (1 release)</summary>

### [1.1.0] - 2026-11-16 - Ten Discs

#### Added
- **Five New Discs**: Track 6 Midnight Drive, Track 7 Sunlit Meadow, Track 8 Deepslate Echoes, Track 9 Pixel Parade and Track 10 Golden Hour, each an original track.
- **New Recipes**: The new discs use the same recipe layout with Iron Ingot, Gold Ingot, Emerald, Nether Quartz or Blaze Powder as the accent item.

#### Improved & Balanced
- **Disc Icons**: All ten discs now use a tilted vanilla-style disc icon with a label color of their own.

</details>

<details>
<summary><b>1.0.x</b> (1 release)</summary>

### [1.0.0] - 2026-11-16 - First Release

#### Added
- **Five Music Discs**: Track 1 Neon Horizon, Track 2 Ember Lantern, Track 3 Quiet Tides, Track 4 Crystal Caverns and Track 5 Starlight Express, each an original track.
- **Survival Recipes**: Each disc is crafted from Paper, Coal, Flint, a Note Block and one accent item, and all recipes are unlocked from the start.
- **Jukebox Playback**: Use a disc on a Jukebox to play it, use it again to take the disc out, and see note particles while it plays.
- **Headphones Announcements**: Starting and stopping a disc announces the track number, name and length for ALN Wireless Headphones.

</details>
```

import { world, system } from "@minecraft/server";

const DISCS = {
  "aln:music_disc_neon_horizon": { track: 1, title: "Neon Horizon", seconds: 76, sound: "record.neon_horizon" },
  "aln:music_disc_ember_lantern": { track: 2, title: "Ember Lantern", seconds: 82, sound: "record.ember_lantern" },
  "aln:music_disc_quiet_tides": { track: 3, title: "Quiet Tides", seconds: 85, sound: "record.quiet_tides" },
  "aln:music_disc_crystal_caverns": { track: 4, title: "Crystal Caverns", seconds: 58, sound: "record.crystal_caverns" },
  "aln:music_disc_starlight_express": { track: 5, title: "Starlight Express", seconds: 70, sound: "record.starlight_express" },
  "aln:music_disc_midnight_drive": { track: 6, title: "Midnight Drive", seconds: 75, sound: "record.midnight_drive" },
  "aln:music_disc_sunlit_meadow": { track: 7, title: "Sunlit Meadow", seconds: 55, sound: "record.sunlit_meadow" },
  "aln:music_disc_deepslate_echoes": { track: 8, title: "Deepslate Echoes", seconds: 85, sound: "record.deepslate_echoes" },
  "aln:music_disc_pixel_parade": { track: 9, title: "Pixel Parade", seconds: 71, sound: "record.pixel_parade" },
  "aln:music_disc_golden_hour": { track: 10, title: "Golden Hour", seconds: 84, sound: "record.golden_hour" }
};

const JUKEBOX = "minecraft:jukebox";
const STATE_KEY = "aln_morediscs:active";
const EVENT_STARTED = "aln:disc_started";
const EVENT_STOPPED = "aln:disc_stopped";
const EVENT_QUERY = "aln:disc_query";
const PLAY_FROM_SCRIPT = false;
const CHECK_INTERVAL = 40;
const SETTLE_DELAY = 3;
const SOUND_VOLUME = 4;

const active = new Map();
let loaded = false;

function keyOf(dimensionId, x, y, z) {
  return `${dimensionId}|${x}|${y}|${z}`;
}

function load() {
  if (loaded) return;
  loaded = true;
  try {
    const raw = world.getDynamicProperty(STATE_KEY);
    if (typeof raw !== "string") return;
    for (const entry of JSON.parse(raw)) {
      if (entry && typeof entry.id === "string" && DISCS[entry.disc]) active.set(entry.id, entry);
    }
  } catch (error) {
    active.clear();
  }
}

function save() {
  try {
    world.setDynamicProperty(STATE_KEY, JSON.stringify([...active.values()]));
  } catch (error) {}
}

function send(eventId, payload) {
  try {
    world.getDimension("overworld").runCommand(`scriptevent ${eventId} ${JSON.stringify(payload)}`);
  } catch (error) {}
}

function spawnNotes(dimension, x, y, z) {
  try {
    dimension.spawnParticle("minecraft:note_particle", { x: x + 0.5, y: y + 1.2, z: z + 0.5 });
  } catch (error) {}
}

function stopSound(disc) {
  if (!PLAY_FROM_SCRIPT) return;
  for (const other of active.values()) {
    if (other.disc === disc) return;
  }
  try {
    world.getDimension("overworld").runCommand(`stopsound @a ${DISCS[disc].sound}`);
  } catch (error) {}
}

function stopTrack(id, reason) {
  const entry = active.get(id);
  if (!entry) return;
  active.delete(id);
  save();
  send(EVENT_STOPPED, { id, disc: entry.disc, track: entry.track, reason });
  stopSound(entry.disc);
}

function startTrack(dimension, x, y, z, discId) {
  const disc = DISCS[discId];
  if (!disc) return;
  const id = keyOf(dimension.id, x, y, z);
  const previous = active.get(id);
  if (previous && previous.disc === discId) return;
  if (previous) stopTrack(id, "replaced");
  const entry = {
    id,
    dim: dimension.id,
    x,
    y,
    z,
    disc: discId,
    track: disc.track,
    title: disc.title,
    seconds: disc.seconds,
    startedAt: Date.now(),
  };
  active.set(id, entry);
  save();
  send(EVENT_STARTED, entry);
  if (PLAY_FROM_SCRIPT) {
    try {
      dimension.playSound(disc.sound, { x: x + 0.5, y: y + 1, z: z + 0.5 }, { volume: SOUND_VOLUME, pitch: 1 });
    } catch (error) {}
  }
  spawnNotes(dimension, x, y, z);
}

function settle(dimensionId, location, heldTypeId) {
  load();
  const dimension = world.getDimension(dimensionId);
  const { x, y, z } = location;
  const id = keyOf(dimensionId, x, y, z);
  let block;
  try {
    block = dimension.getBlock(location);
  } catch (error) {
    return;
  }
  if (!block) return;
  if (block.typeId !== JUKEBOX) {
    stopTrack(id, "broken");
    return;
  }
  let known = false;
  let recordId;
  try {
    const player = block.getComponent("minecraft:record_player");
    if (player) {
      const record = player.getRecord();
      recordId = record ? record.typeId : undefined;
      known = true;
    }
  } catch (error) {}
  if (known) {
    if (recordId && DISCS[recordId]) startTrack(dimension, x, y, z, recordId);
    else stopTrack(id, "ejected");
    return;
  }
  if (active.has(id)) stopTrack(id, "ejected");
  else if (heldTypeId && DISCS[heldTypeId]) startTrack(dimension, x, y, z, heldTypeId);
}

function tick() {
  load();
  if (active.size === 0) return;
  const now = Date.now();
  for (const [id, entry] of [...active]) {
    let block;
    try {
      block = world.getDimension(entry.dim).getBlock({ x: entry.x, y: entry.y, z: entry.z });
    } catch (error) {
      continue;
    }
    if (!block) continue;
    if (block.typeId !== JUKEBOX) {
      stopTrack(id, "broken");
      continue;
    }
    if (now - entry.startedAt >= entry.seconds * 1000 + 2000) {
      stopTrack(id, "ended");
      continue;
    }
    spawnNotes(block.dimension, entry.x, entry.y, entry.z);
  }
}

export function getActiveDiscs() {
  load();
  return [...active.values()];
}

export function initDiscJukebox() {
  world.beforeEvents.playerInteractWithBlock.subscribe((event) => {
    const { block, player, itemStack, isFirstEvent } = event;
    if (!isFirstEvent || block.typeId !== JUKEBOX) return;
    if (player.isSneaking && itemStack) return;
    const dimensionId = block.dimension.id;
    const location = { x: block.location.x, y: block.location.y, z: block.location.z };
    const held = itemStack ? itemStack.typeId : undefined;
    system.runTimeout(() => settle(dimensionId, location, held), SETTLE_DELAY);
  });

  world.afterEvents.playerBreakBlock.subscribe((event) => {
    if (event.brokenBlockPermutation.type.id !== JUKEBOX) return;
    const { x, y, z } = event.block.location;
    const id = keyOf(event.block.dimension.id, x, y, z);
    system.run(() => {
      load();
      stopTrack(id, "broken");
    });
  });

  system.afterEvents.scriptEventReceive.subscribe(
    (event) => {
      if (event.id !== EVENT_QUERY) return;
      load();
      for (const entry of active.values()) send(EVENT_STARTED, entry);
    },
    { namespaces: ["aln"] }
  );

  system.runInterval(tick, CHECK_INTERVAL);
}

# ALN:MoreDiscs by ALNStudios

**Craft ten original music discs and play them in a Jukebox in Survival.**

ALN:MoreDiscs adds ten custom music discs with their own tracks. Each disc is crafted in a Crafting Table, plays in a Jukebox, and works with the ALN Wireless Headphones add-on.

## Features

### Ten Original Tracks
Every track is an original, royalty-free piece made for this pack by ALNStudios.

- Track 1: Neon Horizon (1:16)
- Track 2: Ember Lantern (1:22)
- Track 3: Quiet Tides (1:25)
- Track 4: Crystal Caverns (0:58)
- Track 5: Starlight Express (1:10)
- Track 6: Midnight Drive (1:15)
- Track 7: Sunlit Meadow (0:55)
- Track 8: Deepslate Echoes (1:25)
- Track 9: Pixel Parade (1:11)
- Track 10: Golden Hour (1:24)

### Survival Crafting
All ten discs are craftable and their recipes are unlocked from the start.

- Top row: Paper, Coal, Paper
- Middle row: Flint, Note Block, Flint
- Bottom row: Paper, accent item, Paper
- Accent item: Redstone Dust for Track 1, Lapis Lazuli for Track 2, Amethyst Shard for Track 3, Glowstone Dust for Track 4, Copper Ingot for Track 5, Iron Ingot for Track 6, Gold Ingot for Track 7, Emerald for Track 8, Nether Quartz for Track 9, Blaze Powder for Track 10

### Jukebox Playback
Hold a disc and right-click a Jukebox to play it. Right-click again to take the disc out. Note particles rise from the Jukebox while a track plays.

## Compatibility

- Minecraft Bedrock Edition 1.26.60
- No experimental features required in the inspected files.
- Works alongside **ALN Wireless Headphones**: when a disc starts or stops, the add-on announces the track number, track name and length for the headphones to display. This has not been tested together in game.

**By ALNStudios**

**Craft ten original music discs, each with its own 55 to 85 second track, and play them in a Jukebox in Survival.**

> ALN MoreDiscs adds ten music discs, Track 1 to Track 10, each crafted from Paper, Coal, Flint, a Note Block and one accent item. They give a Jukebox new music without any other add-on.

## Overview

Craft a disc at a Crafting Table, put it in a Jukebox and the matching track plays. Every track is an original piece made for this pack, so the ten discs add music to your world without using any existing songs. The discs also announce which track is playing and for how long, so ALN Wireless Headphones can show it.

## Key Features

### Ten Original Tracks
- **What Happens**: The pack adds ten discs with one track each. The track list is below.
- Track 1: Neon Horizon (1:16)
- Track 2: Ember Lantern (1:22)
- Track 3: Quiet Tides (1:25)
- Track 4: Crystal Caverns (0:58)
- Track 5: Starlight Express (1:10)
- Track 6: Midnight Drive (1:15)
- Track 7: Sunlit Meadow (0:55)
- Track 8: Deepslate Echoes (1:25)
- Track 9: Pixel Parade (1:11)
- Track 10: Golden Hour (1:24)
- **Good To Know**: Each disc stacks to 1, like a vanilla music disc.

### Survival Crafting
- **What Happens**: Craft each disc at a Crafting Table. Top row: Paper, Coal, Paper. Middle row: Flint, Note Block, Flint. Bottom row: Paper, the accent item, Paper.
- **How It Works**: The accent item picks the track: Redstone Dust for Track 1, Lapis Lazuli for Track 2, Amethyst Shard for Track 3, Glowstone Dust for Track 4, Copper Ingot for Track 5, Iron Ingot for Track 6, Gold Ingot for Track 7, Emerald for Track 8, Nether Quartz for Track 9, Blaze Powder for Track 10.
- **Good To Know**: All ten recipes are unlocked from the start, so no cheats and no recipe discovery are needed.

### Jukebox Playback
- **What Happens**: Use a disc on a Jukebox to play it, and use the Jukebox again to take the disc back out. Note particles rise from the Jukebox while a track plays.
- **Good To Know**: Breaking the Jukebox or taking the disc out ends the track.

### ALN Wireless Headphones Support
- **What Happens**: When a disc starts or stops, the pack announces the track number, the track name and its length so ALN Wireless Headphones can show them.
- **Good To Know**: This has not been tested together with ALN Wireless Headphones in game.

### Make Your Own Discs
- **What Happens**: The free web tool at https://alnstudios-more-discs.vercel.app is meant to turn your own audio files into a personal pack on your own device.
- **Good To Know**: ALNStudios only distributes the ten original tracks. Audio you convert yourself must be for private, personal play, and you are responsible for having the right to use it.

## How to Use

1. Open the Crafting Table and craft a disc with the recipe above.
2. Right-click a Jukebox while holding the disc.
3. Listen for the track and watch the note particles rise from the Jukebox.
4. Right-click the Jukebox again to take the disc out and stop the track.
