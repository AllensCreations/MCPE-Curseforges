# Changelog — ALN MoreDiscs

---

## [1.0.0] - 2026-11-16 - First Release

### Added
- **Five Music Discs**: Track 1 Neon Horizon, Track 2 Ember Lantern, Track 3 Quiet Tides, Track 4 Crystal Caverns and Track 5 Starlight Express, each an original track.
- **Survival Recipes**: Each disc is crafted from Paper, Coal, Flint, a Note Block and one accent item, and all five recipes are unlocked from the start.
- **Jukebox Playback**: Use a disc on a Jukebox to play it, use it again to take the disc out, and see note particles while it plays.
- **Headphones Announcements**: Starting and stopping a disc announces the track number, name and length for ALN Wireless Headphones.
