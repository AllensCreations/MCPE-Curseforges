# OneBlock Phase Evolution — A cumulative twelve-phase OneBlock map

**Automatic Team Inventory**

The map automatically combines eligible players’ 36-slot inventories, armor, offhand, and Ender Chests into one persistent shared inventory. No Controller item or manual start action is required; sharing starts when the first eligible player is available. Synchronization runs every 2 ticks. Inventory state persists across world restarts. Creative and Spectator players are excluded. If a participating player dies, the shared main inventory and equipment drop once for the team; Ender Chest contents are retained. The selected hotbar slot remains personal to each player.

**A single regenerating block expands into a wider resource pool as you progress.**

OneBlock Phase Evolution is a void-world survival map built around cumulative progression. Break the central block to advance through twelve phases, each adding another family of resources while earlier phases remain available.

## Overview

Start with dirt and grow your resource pool by breaking the OneBlock. Progress is shared by players in the same world and saved with the world, so death and rejoining do not reset the counter.

## Key Features

### Twelve Cumulative Phases
- **What Happens**: Twelve phases unlock at cumulative break milestones from the first block through 5,000 breaks.

### Weighted Resource Pool
- **What Happens**: Every unlocked phase remains eligible, with the newest phase receiving the highest phase-selection weight.

### Resource Rarity
- **What Happens**: Blocks inside each phase have individual weights so common materials appear more often than rare materials.

### Persistent Progression
- **What Happens**: The world stores the total number of OneBlock breaks and restores the correct phase after rejoining.

### Mixed Biome Families
- **What Happens**: Each phase adds resource families from several Overworld biomes or from the Nether and End, rather than locking generation to one biome.

### Natural Special Resources
- **What Happens**: Rare blocks enter the pool at later phases. The map does not force-spawn mobs or fabricate mob drops; mob drops remain tied to naturally available mobs.

### Three World Modes
- **What Happens**: The repository workflow creates Creative, Survival, and Hardcore world variants from their corresponding foundations.

## How to Use

Break the single block at the center of the island. Each successful player break increases the shared counter. At the listed milestones, the next phase unlocks automatically and the resource pool expands. Keep the island safe because generated blocks can include gravel, sand, and other falling materials. The optional setup command requires cheats; using cheats disables achievements in that world.
