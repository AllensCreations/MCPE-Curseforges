# OneBlock Natural Market

Download the current release of **OneBlock Natural Market** for Minecraft Bedrock Edition.

## Download

- **Package format:** `.mcworld`
- **Direct download:** [Browse official map releases](https://github.com/AllensCreations/MCPE-Curseforges/tree/main/MCPEDL/Maps)

## Installation

1. Download the package using the link above.
2. Open the downloaded file with Minecraft to import it.
3. Find the imported world in your Worlds list and open it.
