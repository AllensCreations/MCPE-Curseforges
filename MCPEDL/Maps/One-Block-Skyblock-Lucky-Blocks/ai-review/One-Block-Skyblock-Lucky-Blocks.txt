```
# Changelog — One Block Skyblock Lucky Blocks

## [v2] - 2026-11-10

### Added
- **Starter chest**: A chest on the island corner holds 3 Oak Saplings, 4 Bone Meal, 4 Bread, a Bucket and a Luck Ledger.
- **Luck Ledger**: Use it to see your break count and how many Four-Leaf Fortune or Jinx breaks are left.
- **First-join tip**: A short chat message tells new players to break the lucky block and open the chest.

### Improved & Balanced
- **Building materials first**: Early Common and Uncommon results now lean toward saplings, logs, planks, dirt, seeds and stone, with 8 more good results in total.

### Added
- **Silent progression**: Results now follow a natural playthrough from Plains to the End and beyond, moving up one step every 30 breaks without any announcement.
- **20 tiers per side**: Twenty good tiers and twenty bad tiers, with 112 good results and 81 bad results, each tier with its own results.

### Improved & Balanced
- **70/30 luck**: Every break now has a 70% chance of good luck and a 30% chance of bad luck.
- **Tier odds**: The current tier comes up 50% of the time, with the next tiers up at 25%, 12.5%, 6.25% and 6.25%.
- **Luck changes**: Rabbit's Foot, Four-Leaf Fortune, Golden Horseshoe and Jinx now work on the 70/30 odds.
- **No guaranteed streak**: The first 30 breaks are no longer always good luck.

### Added
- **Lucky block island**: A 3x3 grass island in the void with one central lucky block that returns after every break.
- **30 guaranteed good breaks**: The first 30 breaks always give good luck, followed by an even split between good and bad luck.
- **Luck tiers and 76 results**: Common, Rare and Epic good luck, and Mischief, Bad Luck and Cursed bad luck, each shown with a message, sound and particles.
- **Luck influence**: A Rabbit's Foot in the off hand and the Four-Leaf Fortune, Golden Horseshoe and Jinx results change the odds of the next breaks.

<details>
<summary><b>1.1.x</b> (1 release)</summary>

### [1.1.0] - 2026-11-10

#### Improved & Balanced
- **Luck changes**: The Rabbit's Foot off-hand bonus is removed. Luck now changes only through the Four-Leaf Fortune, Golden Horseshoe and Jinx results, and the good luck chance stays between 50% and 90%.

</details>
```

function windowTier(base) {
  let roll = Math.random() * 100;
  for (let i = 0; i < WINDOW.length; i++) {
    if (roll < WINDOW[i]) return base + i;
    roll -= WINDOW[i];
  }
  return base;
}

function pickOutcome(kind, breaks) {
  const base = Math.min(MAX_BASE, Math.floor((breaks - 1) / STAGE_BREAKS));
  const index = windowTier(base);
  const pool = STAGES[index][kind].filter((o) => o[0] !== lastName);
  const total = pool.reduce((sum, o) => sum + (o[2] ?? 1), 0);
  let roll = Math.random() * total;
  let outcome = pool[pool.length - 1];
  for (const o of pool) {
    roll -= o[2] ?? 1;
    if (roll < 0) {
      outcome = o;
      break;
    }
  }
  lastName = outcome[0];
  return { outcome, index };
}

function rollKind(player) {
  let chance = GOOD_CHANCE;
  const plus = num(BONUS_KEY);
  if (plus > 0) {
    chance += 0.2;
    world.setDynamicProperty(BONUS_KEY, plus - 1);
  }
  const minus = num(JINX_KEY);
  if (minus > 0) {
    chance -= 0.2;
    world.setDynamicProperty(JINX_KEY, minus - 1);
  }
  chance = Math.min(0.95, Math.max(0.2, chance));
  return Math.random() < chance ? "good" : "bad";
}

  } catch (e) {

  }

# One Block Skyblock Lucky Blocks — A single lucky block on a 3x3 void island

**By ALNStudios**

[![Minecraft Bedrock](https://img.shields.io/badge/Minecraft%20Bedrock-Stable%20Release-brightgreen?style=flat-square&logo=minecraft)](https://github.com/AllensCreations/MCPE-Curseforges)

**Break the one lucky block on a 3x3 void island and climb 20 luck tiers, from Plains wood to Mythical netherite.**

> Your rewards follow a natural Minecraft playthrough, moving quietly from wood and dirt to caves, the Nether, the End and beyond as you keep breaking.

## Overview

You start on a 3x3 grass island floating in an empty void, next to a single lucky block in the center. Mine it, and it returns in the same spot with a new result: items, food, tools, friendly animals, potion effects, hostile mobs or short bursts of danger.

## Key Features

### One Central Lucky Block
- **What Happens**: The lucky block sits at the center of the island and is replaced the moment you break it.
- **Good To Know**: If the center spot ever becomes empty, the lucky block is placed there again within about 5 seconds.

### 70/30 Luck
- **What Happens**: Every break has a 70% chance of good luck and a 30% chance of bad luck from the very first block, with no guaranteed good streak.
- **Good To Know**: The good luck chance stays between 50% and 90%, even with every luck change active.

### Silent Progression
- **What Happens**: The results follow a playthrough: Plains, Forest, Stone Age, Farm and Village, Shallow Caves, Iron Age, Deep Caves, Diamond Age, Enchanting, Nether Gate, Nether Wastes, Fortress and Blaze, Ender Prep, Stronghold, Deep Dark, Ancient Wonders, Ocean Depths, End City, Beacon Rise and Mythical.
- **Good To Know**: No message announces a step.

### 20 Tiers of Good Luck and 20 of Bad Luck
- **What Happens**: Good tiers run Common, Uncommon, Good, Nice, Great, Rare, Superb, Excellent, Fantastic, Epic, Heroic, Majestic, Glorious, Radiant, Exalted, Legendary, Ancient, Celestial, Divine and Mythical.
- **Good To Know**: Every tier has its own results, and late bad tiers are severe and can end a run.

### 120 Good Results and 81 Bad Results
- **What Happens**: Early good results are mostly building materials such as Sapling Pack, Dirt Delivery, Oak Logs, Plank Bundle and Stone Delivery.
- **Good To Know**: Explosions from the lucky block do not break the island, but a hit or a blast can still knock you into the void.

### Starter Chest
- **What Happens**: A chest waits on a corner of the island with 3 Oak Saplings, 4 Bone Meal, 4 Bread, a Bucket and a Luck Ledger.
- **Good To Know**: The first time you join, a short chat tip tells you to break the lucky block and open the chest.

### Luck Ledger
- **What Happens**: Use the Luck Ledger to see how many blocks you have broken and how many Four-Leaf Fortune or Jinx breaks are left.
- **Good To Know**: It does not show which progression step you are on.

### Influence Your Luck
- **What Happens**: The Four-Leaf Fortune and Golden Horseshoe results raise the good luck chance by 20 points for the next 5 and 10 breaks.

## How to Use

1. Open the world and wait a moment while the island appears; you spawn on the corner of the 3x3 island.
2. Break the lucky block in the center with any tool or your hand.
3. Read the tier and result on the action bar, then pick up what dropped or deal with what appeared.
4. Open the chest on the corner for your first saplings and tools.

## Common Questions

- **Does the lucky block run out?**: No. It is placed again each time it is broken, so you can keep going without limit.
- **Can I see which step I am on?**: No. Only the tier name and result of each break are shown.
- **What happens after the last step?**: The odds stay there, with tiers from Legendary to Mythical.
