# ALNStudios Minecraft Bedrock Add-ons

ALNStudios makes free Minecraft Bedrock add-ons, maps, script packs and minigames. This repository is where every pack is built and kept. The packs are shared on CurseForge and MCPEDL.

## What You Will Find
- **Add-ons**: Packs that add new things to your world.
- **Maps**: Ready-made worlds you can import.
- **Script Packs**: Script-based packs for your world.
- **Minigames**: Add-ons that add a playable game to your world.

## Where to Download
- [CurseForge Profile](https://www.curseforge.com/members/allenscreations/projects)
- [MCPEDL Profile](https://mcpedl.com/user/alnstudios/)

## Installation
1. Download the pack you want from CurseForge or MCPEDL.
2. Open the downloaded file with Minecraft to import it.
3. If the package contains a pack that must be enabled separately, activate it in your world's settings.
