## Compatibility and Installation

- These downloads are intended for Minecraft Bedrock Edition. Check each project's description and current package details for its specific requirements.
- To install a package, download the appropriate .mcpack, .mcaddon, or .mcworld file and open it with Minecraft.
- If a pack needs to be enabled separately, activate it in the world's settings.
