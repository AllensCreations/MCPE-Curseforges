## 🛠️ Contributing & Customizing
Each folder inside `packs/` is structured as a standard Minecraft Bedrock pack:
- `behavior_pack/`: Entities, functions, items, recipes, loot tables.
- `resource_pack/`: Textures, materials, models, animations, particle emitters, language strings.
- `manifest.json`: Pack UUIDs, engine versions, and module headers.
