◆ About

The host or an operator starts the shared inventory with the ALNStudios Controller. From that moment, anything one player picks up, uses or drops changes it for the whole team. The add-on keeps names, lore, durability and enchantments of items while the world is running. Team Inventory is a drop-in add-on: add it to any world and the Controller gives you the shared inventory, Hard Mode and Personal Layout without any extra setup.

◆ What You Get

 

Shared Inventory
Main inventory, armor and offhand items are shared by every player who takes part.
Simultaneous Changes: When two players change the same stack at once, both changes are combined instead of lost or duplicated.

 

ALNStudios Controller
Only the host or an operator can hold and use the Controller. It offers Start, How to play, the Mode and Layout switches, Hard Health and Hard Hunger, a Team list and, while a game runs, End Game with a confirmation.
Countdown: After Start, a five second countdown shows the chosen Mode and Layout before everyone's items are combined.
Survival: Start uses up the Controller.
Creative: The Controller is kept.
Mode and Layout: Switch the Mode between Normal and Hard and the Layout between Shared and Personal.
Hard Health and Hard Hunger: In Hard Mode, shared health and shared hunger can each be turned off.
Team List: Shows who is sharing, who is online but not sharing, which team members are offline and whose share is waiting.
Before Start: Settings can only be changed before the game starts.

 

Shared Ender Chest
Every player's Ender Chest holds the same items, so something stored by one player can be taken out by another.
Start: Ender Chest items from every player are combined when the game starts.
Deaths: The Ender Chest is not dropped when a player dies.

 

Personal Layout
When the Layout is Personal, the team still shares the same items, but each player arranges their own main inventory and hotbar. New items go into the first free slot.
Armor, Offhand and Ender Chest: These keep the same layout for everyone.
Moving Items: Items that leave a player's inventory for less than a second, such as while moving a stack, are not taken from teammates. A stack held for longer is taken from teammates and returned when it is put back.
Full Inventory: If a player has no free space, the missing items arrive as soon as space is free.

 

Hard Mode
The host or an operator can switch the Mode to Hard before choosing Start. Health and hunger are then shared by every player who takes part, and either one can be turned off in the Controller menu.
Damage and Healing: Damage taken by one player is taken by the whole team. Healing and eating raise the shared value once.
Starting Values: Everyone's health and hunger are set to the lowest among the players when the game starts.
Deaths: When one player dies, every other player who takes part dies too, and chat says who died.

 

Team Deaths
The shared inventory drops once when a player dies and is then emptied for the team.
Keep Inventory: The rule is switched on while sharing runs so nothing drops twice, and restored when sharing ends.

 

Ending the Game
The host or an operator chooses End Game in the Controller menu or uses the function end_game. The shared items are divided between players, the host keeps the armor and the shared Ender Chest items, and everyone else is emptied so items are not duplicated.
Survival: Start uses up the Controller, so run the function give_controller to get a new one before choosing End Game.
Controller Replacement: The host or an operator gets a new Controller when the game ends. The function give_controller also gives one.
Offline Players: Players who are offline when the game ends receive their share of the items the next time they join.
Cheats: The functions need cheats, which disable achievements in that world.

 

Joining Players
Players who join while sharing is running receive the team inventory. Their own items are replaced, so store anything personal before joining.

 

Saving and Limits
The shared inventory is saved with the world and restored after a restart.
After a Restart: Only names, lore, durability and enchantments of items are restored. Shulker box and bundle contents, potion types, dyed colors, banner patterns and maps may be lost.
Too Large to Save: If the shared inventory becomes too large to save, players are warned and the saved copy is cleared until it is smaller.
Creative and Spectator: Players in these modes are not part of the shared inventory.

◆ How to Play

1
Import the pack and enable both the Behavior Pack and the Resource Pack in the settings of any world you want to play.
2
The host or an operator uses the Controller to pick the Mode and Layout, then chooses Start.
3
Play together and coordinate item use with teammates.
4
The host or an operator chooses End Game in the Controller menu, or runs the function end_game, to finish.

◆ Install

1
Download the file from this page and open it with Minecraft.
2
Create or edit a world and turn on the new pack(s) in its settings.
3
Enable any Experimental toggles listed under Compatibility, then play.
