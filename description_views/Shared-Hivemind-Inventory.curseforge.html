  Bedrock: 1.26+  
  Experimental: No  
  Achievements: Likely achievement-friendly; world settings or cheats can disable achievements  

About

The host or an operator starts the shared inventory with the ALNStudios Controller. From that moment, anything one player picks up, uses or drops changes it for the whole team.

What You Get

 

Shared Inventory
Main inventory, armor and offhand items are shared by every player who takes part.

 

ALNStudios Controller
Only the host or an operator can hold and use the Controller.

 

Shared Ender Chest
Every player's Ender Chest holds the same items, so something stored by one player can be taken out by another.

 

Personal Layout
When the Layout is Personal, the team still shares the same items, but each player arranges their own main inventory and hotbar.

 

Hard Mode
The host or an operator can switch the Mode to Hard before choosing Start.

 

Team Deaths
The shared inventory drops once when a player dies and is then emptied for the team.

 

Ending the Game
The host or an operator chooses End Game in the Controller menu or uses the function end_game.

 

Joining Players
Players who join while sharing is running add their own items to the team and receive the team inventory.

Get Started

1
Import the pack and enable both the Behavior Pack and the Resource Pack in the settings of any world you want to play.
2
The host or an operator uses the Controller to pick the Mode and Layout, then chooses Start.
3
Play together and coordinate item use with teammates.
4
The host or an operator chooses End Game in the Controller menu, or runs the function end_game, to finish.

Install

1
Download the file from this page and open it with Minecraft.
2
Create or edit a world and turn on the new pack(s) in its settings.
3
Play. No Experimental toggles needed.
