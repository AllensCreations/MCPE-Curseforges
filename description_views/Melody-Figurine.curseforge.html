About

The Melody Figurine is a small decorative statue with a matching inventory icon and placed-block texture. Choose from four party modes to set the mood for each activation.

How to Play

1
Import the add-on and enable both packs in your world settings.
2
Obtain the Melody Figurine from the Creative inventory.
3
Place it on the ground.
4
Sneak-interact to choose a mode, then interact normally to start the song and effects.

Install

1
Download the file from this page and open it with Minecraft.
2
Create or edit a world and turn on the new pack(s) in its settings.
3
Enable any Experimental toggles listed under Compatibility, then play.
