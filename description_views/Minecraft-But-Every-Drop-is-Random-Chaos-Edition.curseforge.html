Minecraft, But Every Drop is Random

by ALNStudios

Every block and mob drop turns into a different item, and defeating the Ender Dragon wins the run.

This minigame swaps every drop, from Dirt to Rotten Flesh, for another item from a shuffled table. It suits survival challenge runs where nobody knows what the next block will give.


  Bedrock: 1.26+  
  Experimental: No  
  Achievements: Likely achievement-friendly. The optional recovery commands for giving the Controller and ending the game need cheats, and cheats disable achievements in that world  

About

The host opens the Controller and presses Start. From then on, each item that drops from a broken block or a defeated mob is replaced by another item, and the stack size stays the same. The same item always turns into the same replacement during one run, so players can learn the table as they go. The Controller is used up when the game starts, and the run ends when the Ender Dragon falls.

What You Get

 

Randomized Drops
Blocks and mobs drop a different item than normal, and the number of items stays the same. Items that cannot stack as high as the original are split into several stacks.
How It Works: If Oak Log is swapped for a Golden Apple in your run, every Oak Log you break gives Golden Apples for the rest of that run.
Good To Know: Items dropped by players on death are not swapped.

 

Fresh Table Every Run
Pressing Start shuffles a new table, and no item is swapped for itself.
Good To Know: The table cannot be reshuffled while a game is running.

 

Reshuffle Outside a Game
Any player can reshuffle the table while no game is running, by using the command or by sneaking while using a Book.
Good To Know: Starting a game always shuffles a new table anyway.

 

Controller
The host and operators receive the Controller. It opens a menu with Start and How to play.
Good To Know: Start uses up the Controller, except in Creative mode, and a new one is given to the host and operators when the game ends.

Get Started

1
Enable the Behavior Pack and the Resource Pack in a world and take the Controller.
2
Use the Controller and press Start.
3
Break blocks and defeat mobs, then defeat the Ender Dragon to win.

Commands

 
/alnreshuffle`: Reshuffles the random drop table while no game is running.

Commands need cheats enabled. Cheats turn off achievements in that world.

Common Questions

Can I reshuffle during a game?
No. The table stays fixed while a game runs, so each run keeps one set of swaps.

What happens to the Controller when a game starts?
It is used up unless you are in Creative mode, and a new one is given to the host and operators when the game ends.

Install

1
Download the file from this page and open it with Minecraft.
2

3
Play. No Experimental toggles needed.
