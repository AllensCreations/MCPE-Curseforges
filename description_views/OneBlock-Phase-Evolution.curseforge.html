OneBlock Phase Evolution

Automatic Team Inventory

About

Start with dirt and grow your resource pool by breaking the OneBlock. Progress is shared by players in the same world and saved with the world, so death and rejoining do not reset the counter.

What You Get

Twelve Cumulative Phases
Twelve phases unlock at cumulative break milestones from the first block through 5,000 breaks.

Weighted Resource Pool
Every unlocked phase remains eligible, with the newest phase receiving the highest phase-selection weight.

Resource Rarity
Blocks inside each phase have individual weights so common materials appear more often than rare materials.

Persistent Progression
The world stores the total number of OneBlock breaks and restores the correct phase after rejoining.

Mixed Biome Families
Each phase adds resource families from several Overworld biomes or from the Nether and End, rather than locking generation to one biome.

Natural Special Resources
Rare blocks enter the pool at later phases. The map does not force-spawn mobs or fabricate mob drops; mob drops remain tied to naturally available mobs.

Three World Modes
The repository workflow creates Creative, Survival, and Hardcore world variants from their corresponding foundations.

How to Play

Break the single block at the center of the island. Each successful player break increases the shared counter. At the listed milestones, the next phase unlocks automatically and the resource pool expands. Keep the island safe because generated blocks can include gravel, sand, and other falling materials. The optional setup command requires cheats; using cheats disables achievements in that world.

Install

  1. Download the file from this page and open it with Minecraft.
  2. Create or edit a world and turn on the new pack(s) in its settings.
  3. Enable any Experimental toggles listed under Compatibility, then play.
