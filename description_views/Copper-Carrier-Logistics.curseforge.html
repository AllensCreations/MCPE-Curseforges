Copper-Carrier Logistics

by ALNStudios

An Allay carries a Copper Golem and sorts your drops like a Copper Golem that can fly.

Pair an Allay with a Copper Golem to create a flying sorting unit.


  Bedrock: 1.26+  
  Experimental: No  
  Achievements: Likely achievement-friendly  

About

Right-click an Allay with a Copper Ingot to turn it into a flying sorting unit. The Copper Golem is held under the Allay instead of walking.

What You Get

 

Flying Sorting Unit
Right-click an Allay with a Copper Ingot.

 

Copper Golem Style Sorting
The unit delivers each item to a chest or barrel that already holds the same item.

 

54-Slot Memory Buffer
The unit holds collected items in a 54-slot buffer until it delivers them.

 

64-Block Collection Range
Items that drop within 64 blocks of the unit and have matching storage are collected automatically.

 

Fast Sorting Feedback
Spark particles and a note sound play when items are collected and when a delivery is completed.

Get Started

1
Install the add-on and enable the Behavior Pack in your world.
2
Put at least one of each item you want sorted into the chests or barrels near where the unit will work.
3
Right-click an Allay with a Copper Ingot, ideally next to a Copper Golem.
4
Drop or mine matching items near the unit and watch them get sorted.

Install

1
Download the file from this page and open it with Minecraft.
2
Create or edit a world and turn on the new pack(s) in its settings.
3
Play. No Experimental toggles needed.
