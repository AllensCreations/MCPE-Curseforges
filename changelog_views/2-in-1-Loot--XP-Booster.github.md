# Changelog — 2-in-1 Loot & XP Booster

## [1.0.2] - 2026-11-12

### Improved & Balanced
- **Three-button menu**: The Booster menu now has only XP & Loot Booster, About and Exit.
- **One screen, two sliders**: XP & Loot Booster sets both boosters with a Loot slider and an XP slider, saved together with one Apply button. Each slider is labeled with your current tier name, and the new tier names are shown in chat and the Action Bar after Apply.
- **New About screen**: About now introduces ALNStudios and the two packs in this add-on.

### Fixed
- **Menu stays out of the way**: Exit closes the menu without changing your settings.

### [1.0.1] - 2026-11-12 - Redesigned Menu and Tiers

#### Added
- **About button**: The Booster menu now has an About screen explaining each booster.
- **Named tiers**: Loot runs Normal, Quite Good, Great, Amazing, Insane and The Leprechaun. XP adds Legendary and The Sage.
- **Cheatstick menu skin**: The Redesigned UI Resource Pack styles the Booster menus with a dark panel and blue border.

#### Improved & Balanced
- **Fortune-style loot**: Drops roll a random bonus up to the tier's maximum instead of always using it. Loot tops out at 32x.
- **XP maximum**: XP can now reach 64x.
- **Colored text**: Tier names and menu labels use distinct colors.

### [1.0.0] - 2026-11-12 - First Release

#### Added
- **Booster menu**: Rename a Book or a Book and Quill to Booster and right-click to set your Loot Drop and XP Gain multipliers.
- **Loot Drop multiplier**: Blocks you break and mobs you kill drop up to 32 times their normal stacks, except from chests, barrels, ender chests and shulker boxes.
- **XP Gain multiplier**: Nearby XP orbs are multiplied and collected instantly.
- **Redesigned UI**: A Resource Pack with the Cheatstick menu textures.
