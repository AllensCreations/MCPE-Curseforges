# Changelog — Smart Tool Hub

## [1.0.0] - 2026-11-26 - First Release

### Added
- **Tool Hub item**: A custom item, equippable in the offhand, opens a toggle menu for Auto Switch, Tree Capitator and Domino Ore Miner.
- **Offhand Auto Switch**: Auto Switch works on any hotbar slot and only runs while the Tool Hub is in the offhand.
- **32x32 icon**: A resource pack adds a Tool Hub emblem icon with a circle arrow.
