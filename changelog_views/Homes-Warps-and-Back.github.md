# Changelog — Homes Warps and Back

## [1.0.0] - 2026-11-23 - First Release

### Added
- **Compass menu**: Using a compass opens one menu for homes, warps and the death point.
- **Named homes**: Players save up to 5 homes, travel to them and delete them.
- **Public warps**: Players publish up to 3 warps each, with 30 in total, and anyone can travel to them.
- **Back to death point**: The last death location is saved and the menu teleports the player back to it.
