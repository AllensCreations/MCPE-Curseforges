# Changelog — Cheat Stick

## [2.0.1] - 2026-11-11

### Added
- **Difficulty**: Choose Peaceful, Easy, Normal, or Hard from the Gamemode menu.
- **Rename Slot**: Type a name for a saved slot. The name shows in the Save and Load lists.
- **Clear Effects**: Removes every active effect from you.
- **Clear Dropped Items**: Removes items lying on the ground within 32 blocks of you.

### Improved & Balanced
- **Sneak to open**: The menu now opens only when you sneak and use a Stick, so a normal Stick no longer opens it by accident.
- **Set Spawn Here moved**: Set Spawn Here is now in the Travel menu instead of the Survival menu.

### [1.0.3] - 2026-11-11

#### Added
- **Save and Load**: Save your position in one of 5 slots and see its coordinates and dimension. Load a slot to teleport back to it.
- **Colored name**: The menu title and messages now read @ALNStudios Cheatstick in gold and yellow, with green message text.

#### Improved & Balanced
- **Travel menu simplified**: Return to Spawn, Return to World Spawn, Save Home, and Go Home are removed. Back to Death Point stays.
- **Menu name**: The menu is now called @ALNStudios Cheatstick.
- **Saved homes**: Homes saved in the previous version are not carried into the new slots.

### [1.0.2] - 2026-11-11

#### Added
- **Effects menu**: Haste, Speed, Night Vision, Jump Boost, Water Breathing, Fire Resistance, and Regeneration, each lasting 10 minutes.
- **Travel menu**: Return to Spawn, Return to World Spawn, Back to Death Point, Save Home, and Go Home.
- **Clear Nearby Hostile Mobs**: Removes hostile mobs within 32 blocks of you.

#### Improved & Balanced
- **Private action bar messages**: Confirmations now appear above your hotbar and only for the player who used the Stick.
- **Menu reorganized**: Night Vision moved to the Effects menu and Return to Spawn moved to the Travel menu.

### [1.0.1] - 2026-11-11

#### Added
- **Survival menu**: A new Survival category in the @ALNStudio menu with Heal & Feed, Night Vision, Toggle Keep Inventory, Set Spawn Here, and Return to Spawn.

#### Improved & Balanced
- **Normal Stick**: The menu now opens when you use a normal Stick, so no special item is needed.
- **Cheat Stick item removed**: The separate Cheat Stick item and its recipe are gone. Use any Stick instead.
- **Instant open**: The menu opens as soon as you use the Stick. The 1 second hold is no longer needed.

### [1.0.0] - 2026-11-11

#### Added
- **Cheat Stick**: A stick that plays the spyglass hold animation and opens the @ALNStudio menu after a 1 second hold. Craft it from 1 Stick and 1 Redstone Dust.
- **Gamemode choice**: Switch to Survival, Creative, or Hardcore, where Hardcore means Survival on Hard difficulty.
- **Time choice**: Jump to Day, Noon, Sunset, Night, Midnight, or Sunrise.
- **Weather choice**: Set Clear, Rain, or Thunder in your current dimension.
